## 상태

Planned

## 의존성

#365, #366

## 구현 목적

시간을 멈춘 상태에서 그룹 우선권대로 이동시키고 사건과 공통 환경 시간을 순서대로 처리한다.

## 범위

- 계획 식별자: plan-367.
- 그룹 이동과 경로는 사용자가 제출·확정하고, GM은 세계·적 행동과 조우·환경 판정만 맡는다.
- 해당 제품·구조 명세의 이 수용 기준에 직접 필요한 기존 화면, API, 정책, 저장소 경계만 수정한다.

## 수용 기준

- 요구사항 추적: AC-34, AC-35, AC-41, BR-41, BR-42, BR-43, BR-49, G-09, G-10, UC-005.
- 소유 경계: 탐험 순환 조정기(ExplorationCycle)와 기존 그룹 이동 조정; 시행 지점: 그룹 차례·사건 중단·환경 단계 전환을 결정하고 저장.
- 통합 인계: #367의 AdventureController와 CombatStartParticipantFactory는 서버가 소유한 지도 적 토큰→전투 참여자 대응과 적별 인지 상태를 모험 진행 데이터에 저장한다. #368은 이를 전투 전환 경계에서 받아 참여자별 첫 차례 기습 상태를 보존한다. #367에서는 저장·재시도 뒤에도 대응과 인지가 유지되고 현재 전투 참여자에 맞게 적용되는지 검증한다.
- 이동 시작 전 세계 시간을 멈추고 이동 그룹의 우선권을 정한다. 우선권이 같은 그룹의 순서는 무작위로 결정한다.
- 각 그룹은 토큰을 클릭·드래그해 경로를 정하고 확인한 뒤 한 칸씩 이동한다.
- 함정·발견·접촉·기습 등 중단 사건이 발생하면 해당 칸에서 전체 그룹 이동을 멈추고 해결한다.
- 위협 발견은 캐릭터별로 판정하며 발견 사실은 발견자에게만 알려진다. 공유 행동 뒤에만 그룹이 알고, 적에게 들릴지는 GM이 판정한다. 각 캐릭터의 발견 판정에는 대열상 위치, 지각 능력, 이동 방식, 숨김 상태를 반영한다.
- 위협 발견만으로 전투를 자동 시작하지 않는다. 전투 전환은 실제 적대 행동이 시작될 때만 요청한다.
- 적이 먼저 발견하면 GM은 발견한 적의 행동을 플레이어에게 제시하고 다음 플레이어 응답을 기다린다.
- 양측 모두 숨지 않았다면 서로를 자동으로 알아차린다.
- 전투 시작 시 참여자별 인지를 적용한다. 이미 알고 있는 참여자는 첫 차례를 유지하고, 아직 모르는 참여자만 첫 차례를 건너뛴다.
- 환경 단계는 적·순찰 이동과 감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신 순서로 처리하고 중단된 단계부터 이어간다.
- 비전투 사건 뒤에는 해당 그룹의 차례를 종료하고 다음 우선권 그룹부터 진행한다.
- 모든 그룹 차례가 끝나면 환경 시간을 6초 진행하며 적·순찰 이동과 감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신 순서로 처리한다. 저장된 순찰 경로가 없으면 GM이 해당 환경 단계에서 주변 적의 이동과 환경 변화를 판단한다. 단계 도중 중단되면 완료한 단계는 반복하지 않고 중단된 단계부터 이어간다.
- 비전투 사건이 이동 그룹의 차례 중 발생하면 사건을 해결한 뒤 해당 그룹의 차례를 끝내고, 다음 우선권 그룹부터 진행한다. 사건 뒤 같은 그룹의 남은 경로를 자동으로 실행하지 않는다.
- 금지 사례: 사건이 발생한 뒤에도 그룹 이동 또는 6초 환경 처리를 멈추지 않고 계속 진행한다.
- 금지 사례: 환경 처리 순서를 바꾸거나 비전투 사건 그룹의 차례를 끝내지 않고 같은 그룹 이동을 이어간다.
- 환경 처리 순서는 적·순찰 이동·감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신으로 고정한다. 비전투 사건 뒤에는 해당 그룹 차례를 끝내고 다음 우선권 그룹부터 진행한다.

- BR-41 추적: 맵 탐험은 시작부터 세계 시간을 멈추고 그룹별 차례로 진행한다. 그룹은 토큰 경로를 확인해 한 칸씩 이동하며, 한 차례에 경로를 나눠 확정해도 같은 그룹 이동 속도를 공유하고 남은 양을 넘지 않는다. 현재 그룹 차례 완료 뒤에는 그 순환에서 해당 그룹이 더 이동하지 않는다. 모든 그룹 차례 뒤에만 환경 단계를 진행한다. 우선권은 전열 구성원의 최고 우선권으로 정하고, 동률 그룹은 무작위 순서로 정한다. 정한 우선권은 상황 종료 또는 요약 이동 전환까지 유지한다.
- BR-42/BR-43 추적: 순환은 모든 그룹 차례와 환경 6초로 이뤄진다. 환경 순서는 적·순찰 이동 및 감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신이다. 저장된 순찰 경로가 없으면 GM이 각 환경 단계에서 판단한다. 이동 중 멈춰야 하는 사건은 해당 위치에서 전체 이동을 멈추고 해결하며, 비전투 해결 뒤 경로를 자동 재개하지 않고 재확인을 요구한다. 사건을 일으킨 그룹의 차례를 끝내고 다음 우선권 그룹부터 진행한다. 조우로 중단된 환경 단계는 해결 뒤 이어간다.
- 적이 먼저 발견해 플레이어 응답을 기다리는 동안 대기 상태와 적 행동 서술을 모험 진행 데이터에 저장하고 새로고침 뒤에도 유지한다. 질문·메타 입력, 실패·대기 중 입력은 대기를 해제하지 않으며, 정상 확정된 비메타 플레이어 턴에서만 해제한다.
- 위협 인지는 지도 적 토큰별로 인지 캐릭터를 저장한다. 파티 알림을 완료하면 해당 적 토큰마다 알림받은 구성원도 인지자로 추가하며, 전투 진입 시 서버가 만든 적 지도 토큰에서 전투 참여자로의 연결을 사용한다.
- GM이 반환한 인지 결과의 캐릭터·적 토큰 식별자를 현재 파티·지도에 검증하고, 잘못된 식별자는 적용하지 않는다. 명시적 공유 전 발견자 정보는 공개 응답에 포함하지 않는다.
- 전투 시작 시 각 캐릭터와 적의 인지 결과를 보존하고, 미인지 참여자만 첫 차례를 건너뛴다. 이미 인지한 참여자와 적은 첫 차례를 유지한다.
- 금지 사례: 같은 그룹의 나눠 확정한 이동이 이동 속도 합계를 공유하지 않거나 남은 이동량을 초과한다.
- 금지 사례: 현재 그룹 차례 완료 뒤 같은 순환에 그룹이 계속 이동하거나, 전열 최고 우선권·동률 무작위 순서·상황 중 우선권 유지를 어긴다.
- 금지 사례: 공유한 위협 인지가 환경 제안 삭제 또는 재시도 뒤 전투 시작의 캐릭터별 인지 상태에 보존되지 않는다.
- 금지 사례: 적이 먼저 발견한 뒤 새로고침, 질문·메타 입력 또는 실패한 입력만으로 대기가 해제된다.
- 금지 사례: 서로 다른 적 토큰의 인지 캐릭터를 합쳐 적별 인지 관계를 잃거나, 알 수 없는 식별자를 인지 결과에 반영한다.
- 금지 사례: 대열상 위치, 지각 능력, 이동 방식 또는 숨김 상태를 무시해 캐릭터별 위협 발견 결과를 계산한다.
## 테스트 계약

- 단위/정책: 우선권 동점에서 그룹 순서를 무작위로 정하고, 사건 뒤 해당 그룹 차례를 끝낸 다음 다음 우선권 그룹부터 진행하는지 확인한다. 환경 6초의 기대 순서인 적·순찰 이동·감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신과 중단 단계부터의 재개, 사건별 중단·재개, 캐릭터별 인지를 확인한다. 환경 6초 기대 순서 적·순찰 이동·감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신, 단계 중단 뒤 이어서 재개, 비전투 사건 후 해당 그룹 차례 종료와 다음 우선권 그룹 진행을 확인한다. 요구사항 식별자: AC-34, AC-35, AC-41, BR-41, BR-42, BR-43, BR-49, G-09, G-10, UC-005. 소유 경계와 실행 진입점: 탐험 순환 조정기(ExplorationCycle)와 기존 그룹 이동 조정; 그룹 차례·사건 중단·환경 단계 전환을 결정하고 저장. 추적 수용 조건: 이동 시작 전 세계 시간을 멈추고 이동 그룹의 우선권을 정한다. 우선권이 같은 그룹의 순서는 무작위로 결정한다. 반례: 사건이 발생한 뒤에도 그룹 이동 또는 6초 환경 처리를 멈추지 않고 계속 진행한다. 검증 사례: 단위/정책: 우선권 동점·무작위, 사건별 중단/재개, 캐릭터별 인지, 6초 환경 처리 순서.
- AC-41/BR-49 회귀: 위협 발견만으로 전투 전환을 요청하지 않는지, 실제 적대 행동이 있는 경우에만 전환하는지 검증한다. 적이 먼저 발견한 결과에서는 GM의 적 행동 서술을 플레이어 응답에 반환하고 다음 입력 전까지 환경 처리를 이어가지 않는지 확인한다. 양측 모두 숨지 않은 경우 상호 자동 인지를 확인한다. 전투 참여자 중 이미 인지한 캐릭터와 적, 미인지 캐릭터와 적을 함께 두고 이미 인지한 참여자는 첫 차례를 유지하며 미인지 참여자만 첫 차례를 건너뛰는지 검증한다. 캐릭터별 발견 결과가 대열상 위치, 지각 능력, 이동 방식, 숨김 상태를 반영하는지 각 요소를 달리한 사례로 확인한다. 발견한 캐릭터가 파티에 알리면 해당 그룹이 그 적을 인지자로 추가하고, 알림이 적에게 들리는지는 GM 판정에 따라 해당 적의 인지 상태만 갱신하는지 확인한다. 환경 제안 삭제 후 재시도해도 적별 인지 캐릭터와 서버가 만든 지도 적 토큰→전투 참여자 연결이 유지되어 전투 전환에 적용되는지 확인한다.
- BR-41 회귀: 같은 그룹 차례에서 나눠 확정한 이동량 합계가 공유된 이동 속도를 넘지 않고, 현재 그룹 차례 완료 뒤에는 이동이 막히며 모든 차례가 끝난 뒤 환경 6초가 시작되는지 확인한다. 전열 최고 우선권, 동률 그룹의 무작위 순서, 상황 종료/요약 이동까지 우선권 유지도 검증한다.
- BR-42/BR-43 회귀: 이동 사건 위치에서 전체 그룹 이동이 멈추고, 비전투 해결 뒤 경로를 자동 재개하지 않아 재확인이 필요한지, 사건 그룹 차례를 끝내고 다음 우선권 그룹으로 넘어가는지 확인한다. 조우로 멈춘 환경 단계의 재시도에서 완료한 단계가 반복되지 않는지 검증한다.
- 대기 보존 회귀: 적이 먼저 발견해 저장한 응답 대기가 새로고침 뒤에도 유지되고 환경 진행 요청을 거절하는지 확인한다. 메타 질문, 실패 응답, 재시도는 대기를 해제하지 않으며 정상 확정된 비메타 플레이어 턴 뒤에만 해제되는지 검증한다.
- 적별 인지 회귀: 서로 다른 적 토큰에 서로 다른 캐릭터 인지 집합을 보존하고, 서버가 만든 적 지도 토큰에서 전투 참여자로의 연결을 사용해 각 참여자의 첫 차례 기습 여부를 판정하는지 확인한다. 두 명의 플레이어와 두 명의 적을 두어 일부만 인지한 참여자와 모든 위협을 인지한 참여자의 결과를 구분한다.
- 경계 검증: 현재 파티·지도에 없는 캐릭터 또는 적 토큰 식별자를 거부하거나 무시하고, 중복 알림·같은 이벤트 재전달에서도 중복 상태를 만들지 않는지 확인한다. 발견자 정보가 명시적 공유 전 공개 응답에 포함되지 않는지 확인한다.
- 기습 차례 회귀: 전투를 시작한 뒤 미인지 참여자는 첫 차례를 건너뛰고, 인지 참여자는 첫 차례를 유지하며, 기습 상태는 각 참여자의 첫 차례가 끝난 뒤에만 해제되는지 확인한다.
- `ui ~ entity` E2E: 해당 없음 — 그룹 차례와 환경 순서는 정책·통합 검사로 검증하고, 지도 준비부터 실제 사건 후 차례 유지까지 필요한 단일 에이전트 E2E는 모든 선행 계획 완료 뒤 #375에서 한 번 실행한다.
