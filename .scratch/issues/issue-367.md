## 의존성

#365, #366

## 구현 목적

시간을 멈춘 상태에서 그룹 우선권대로 이동시키고 사건과 공통 환경 시간을 순서대로 처리한다.

## 범위

- 계획 식별자: plan-367.
- 그룹 이동과 경로는 사용자가 제출·확정하고, GM은 세계·적 행동과 조우·환경 판정만 맡는다.
- 해당 제품·구조 명세의 이 수용 기준에 직접 필요한 기존 화면, API, 정책, 저장소 경계만 수정한다.

## 수용 기준

- 요구사항 추적: AC-34, AC-35, AC-41, BR-41, BR-42, BR-43, BR-49, G-09, G-10, UC-005.
- 소유 경계: 탐험 순환 조정기(ExplorationCycle)와 기존 그룹 이동 조정; 시행 지점: 그룹 차례·사건 중단·환경 단계 전환을 결정하고 저장.
- 이동 시작 전 세계 시간을 멈추고 이동 그룹의 우선권을 정한다. 우선권이 같은 그룹의 순서는 무작위로 결정한다.
- 각 그룹은 토큰을 클릭·드래그해 경로를 정하고 확인한 뒤 한 칸씩 이동한다.
- 함정·발견·접촉·기습 등 중단 사건이 발생하면 해당 칸에서 전체 그룹 이동을 멈추고 해결한다.
- 위협 발견은 캐릭터별로 판정하며 발견 사실은 발견자에게만 알려진다. 공유 행동 뒤에만 그룹이 알고, 적에게 들릴지는 GM이 판정한다.
- 위협 발견만으로 전투를 자동 시작하지 않는다. 전투 전환은 실제 적대 행동이 시작될 때만 요청한다.
- 적이 먼저 발견하면 GM은 발견한 적의 행동을 플레이어에게 제시하고 다음 플레이어 응답을 기다린다.
- 양측 모두 숨지 않았다면 서로를 자동으로 알아차린다.
- 전투 시작 시 참여자별 인지를 적용한다. 이미 알고 있는 참여자는 첫 차례를 유지하고, 아직 모르는 참여자만 첫 차례를 건너뛴다.
- 환경 단계는 적·순찰 이동과 감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신 순서로 처리하고 중단된 단계부터 이어간다.
- 비전투 사건 뒤에는 해당 그룹의 차례를 종료하고 다음 우선권 그룹부터 진행한다.
- 모든 그룹 차례가 끝나면 환경 시간을 6초 진행하며 적·순찰 이동과 감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신 순서로 처리한다. 저장된 순찰 경로가 없으면 GM이 해당 환경 단계에서 주변 적의 이동과 환경 변화를 판단한다. 단계 도중 중단되면 완료한 단계는 반복하지 않고 중단된 단계부터 이어간다.
- 비전투 사건이 이동 그룹의 차례 중 발생하면 사건을 해결한 뒤 해당 그룹의 차례를 끝내고, 다음 우선권 그룹부터 진행한다. 사건 뒤 같은 그룹의 남은 경로를 자동으로 실행하지 않는다.
- 금지 사례: 사건이 발생한 뒤에도 그룹 이동 또는 6초 환경 처리를 멈추지 않고 계속 진행한다.
- 금지 사례: 환경 처리 순서를 바꾸거나 비전투 사건 그룹의 차례를 끝내지 않고 같은 그룹 이동을 이어간다.
- 환경 처리 순서는 적·순찰 이동·감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신으로 고정한다. 비전투 사건 뒤에는 해당 그룹 차례를 끝내고 다음 우선권 그룹부터 진행한다.

## 테스트 계약

- 단위/정책: 우선권 동점에서 그룹 순서를 무작위로 정하고, 사건 뒤 해당 그룹 차례를 끝낸 다음 다음 우선권 그룹부터 진행하는지 확인한다. 환경 6초의 기대 순서인 적·순찰 이동·감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신과 중단 단계부터의 재개, 사건별 중단·재개, 캐릭터별 인지를 확인한다. 환경 6초 기대 순서 적·순찰 이동·감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신, 단계 중단 뒤 이어서 재개, 비전투 사건 후 해당 그룹 차례 종료와 다음 우선권 그룹 진행을 확인한다. 요구사항 식별자: AC-34, AC-35, AC-41, BR-41, BR-42, BR-43, BR-49, G-09, G-10, UC-005. 소유 경계와 실행 진입점: 탐험 순환 조정기(ExplorationCycle)와 기존 그룹 이동 조정; 그룹 차례·사건 중단·환경 단계 전환을 결정하고 저장. 추적 수용 조건: 이동 시작 전 세계 시간을 멈추고 이동 그룹의 우선권을 정한다. 우선권이 같은 그룹의 순서는 무작위로 결정한다. 반례: 사건이 발생한 뒤에도 그룹 이동 또는 6초 환경 처리를 멈추지 않고 계속 진행한다. 검증 사례: 단위/정책: 우선권 동점·무작위, 사건별 중단/재개, 캐릭터별 인지, 6초 환경 처리 순서.
- AC-41/BR-49 회귀: 위협 발견만으로 전투 전환을 요청하지 않는지, 실제 적대 행동이 있는 경우에만 전환하는지 검증한다. 적이 먼저 발견한 결과에서는 GM의 적 행동 서술을 플레이어 응답에 반환하고 다음 입력 전까지 환경 처리를 이어가지 않는지 확인한다. 양측 모두 숨지 않은 경우 상호 자동 인지를 확인한다. 전투 참여자 중 이미 인지한 캐릭터와 적, 미인지 캐릭터와 적을 함께 두고 이미 인지한 참여자는 첫 차례를 유지하며 미인지 참여자만 첫 차례를 건너뛰는지 검증한다.
- `ui ~ entity` E2E: 해당 없음 — 그룹 차례와 환경 순서는 정책·통합 검사로 검증하고, 지도 준비부터 실제 사건 후 차례 유지까지 필요한 단일 에이전트 E2E는 모든 선행 계획 완료 뒤 #375에서 한 번 실행한다.
