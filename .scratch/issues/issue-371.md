## 상태

Planned

## 의존성

#363, #370

## 구현 목적

주문·기술을 발사하거나 실행하기 전에 중앙 지도에서 사거리와 대상·효과 범위를 확인하게 한다.

## 범위

- 계획 식별자: plan-371.
- 사용자가 배운 능력과 대상·지점을 선택한다. 미리보기는 상태를 바꾸지 않고 GM이 능력을 임의 선택하지 않는다.
- 해당 제품·구조 명세의 이 수용 기준에 직접 필요한 기존 화면, API, 정책, 저장소 경계만 수정한다.

## 수용 기준

- 복수 대상 또는 투사체 배분이 필요한 행동은 미리보기에서 대상과 배분을 선택하게 하고, 선택 완료 뒤 명시적으로 확정할 때만 실행한다. 미리보기만으로 시전하지 않는다. (AC-09, AC-10)
- 방향이 필요한 원뿔·선 효과는 시전자 위치에서 사용자가 가리킨 방향으로 표시하고, 방향 입력이 필요 없는 대상 지정 주문은 현재 조건에서 유효한 대상만 표시한다. (AC-10)
- 사거리, 가시성, 명확한 경로·엄폐, 효과 모양의 장애물 차단·확산을 각각 판정한다. 주문별 예외는 해당 주문 정의에 따라 적용하며, 한 판정 결과로 다른 판정을 대신하지 않는다. (AC-12)
- 범위 안에 아군이 있으면 미리보기에서 경고를 표시하고 별도 추가 확인을 요구하지 않으며, 확정 후 해당 행동의 대상 규칙대로 결과를 판정한다. (AC-13)

- 요구사항 추적: AC-09, AC-10, AC-12, AC-13, AC-14, AC-28, AC-29, AC-30, BR-09, BR-10, BR-11, BR-12, BR-13, BR-30, BR-31, BR-32, EX-05, EX-06, G-04, G-05, G-08, ST-004, UC-002.
- 소유 경계: 능력 정의·전투 미리보기 정책과 전투 지도 서비스의 공개 공간 정보; 시행 지점: 읽기 전용 미리보기에서 사거리·경로·대상·효과 형상을 계산.
- 지도 중앙 작업 영역에서 배운 주문·기술을 선택하고 대상 또는 지도 위치를 지정한다.
- 시전자·사용자 위치 기준 사거리와 유효 경로를 표시하고 경로 칸은 붉게 보여준다.
- 정의에 공간 범위가 있으면 원뿔·선·구 등 실제 효과 모양과 영향을 받을 수 있는 칸·대상을 표시한다.
- 선택 전과 미리보기 중에는 위치·자원·전투 상태를 바꾸지 않고 숨겨진 정보를 노출하지 않는다.
- 자연어로 선언해도 같은 지도 미리보기로 이어져 범위와 대상이 실행 전에 보인다.
- 금지 사례: 미리보기 중 자원을 소모하거나 정의 자료와 다른 효과 범위·대상을 표시한다.

## 테스트 계약

- 개발용 진단 검증 (Architecture Spec §9.1·INV-01): 이 계획이 바꾸는 각 시작·완료·대체 경로·재시도·실패 분기에서 기존 `DevelopmentDiagnostics`(개발 진단 기능)와 `dev_` 개발 로그 형식을 확인한다. `ADVENTURE_RUNTIME_DIAGNOSTICS_ENABLED`(개발용 상세 진단 로그 설정)가 꺼졌을 때 상세 로그가 없고, 켜졌을 때 식별자·입력 크기/개수·기대/실제 값·선택 분기·소요 시간·실패 종류와 다음 복구 동작이 드러나며, 프롬프트·응답·인증 정보·불필요한 플레이어 입력·비공개 지도 정보를 기록하지 않고 실제 동작도 바꾸지 않는지 검사한다.

- 복수 대상/투사체: 복수 대상 선택 및 투사체 배분의 미완료·유효·무효 경우를 확인한다. 미리보기와 선택만으로 전투·자원 상태가 바뀌지 않고, 선택 완료 뒤 명시적 확정에 한 번만 실행되는지 검증한다. (AC-09, AC-10)
- 효과 방향/유효 대상: 방향이 필요한 원뿔·선의 방향을 시전자와 커서 위치로 확인하고, 방향이 불필요한 대상 지정 주문은 유효 대상만 표시하며 범위 밖·조건 불충족 대상은 제외되는지 검증한다. (AC-10)
- 공간 판정 분리: 사거리, 가시성, 명확한 경로·엄폐, 효과 모양의 장애물 차단·확산을 독립적으로 검증한다. 판정 하나만 실패하는 경계 사례와 주문별 예외를 확인해 한 결과가 다른 결과를 대체하지 않는지 검사한다. (AC-12)
- 아군 범위 경고: 효과 범위에 아군이 있을 때 경고가 표시되고 추가 확인 단계 없이 행동별 대상 규칙대로 적용되며, 아군이 없을 때 경고가 없는지 확인한다. (AC-13)

- 단위/정책: 방향이 있는 효과의 방향 계산, 유효 대상 필터, 사거리·가시성·명확한 경로·엄폐·효과 확산의 독립 판정, 공개 정보 필터. 요구사항 식별자: AC-09, AC-10, AC-12, AC-13, AC-14, AC-28, AC-29, AC-30, BR-09, BR-10, BR-11, BR-12, BR-13, BR-30, BR-31, BR-32, EX-05, EX-06, G-04, G-05, G-08, ST-004, UC-002. 소유 경계와 실행 진입점: 능력 정의·전투 미리보기 정책과 전투 지도 서비스의 공개 공간 정보; 읽기 전용 미리보기에서 사거리·경로·대상·효과 형상을 계산. 추적 수용 조건: 지도 중앙 작업 영역에서 배운 주문·기술을 선택하고 대상 또는 지도 위치를 지정한다. 반례: 미리보기 중 자원을 소모하거나 정의 자료와 다른 효과 범위·대상을 표시한다. 검증 사례: 원뿔·선 방향, 유효 대상, 공간 판정 각각의 성공·실패 경계와 주문별 예외.
- `ui ~ entity` E2E: 해당 없음 — 이 계획의 경계는 저비용 정책·단위·통합 검사로 확인하며, 실제 에이전트 포함 경로는 #369에서 한 번 검증한다.
