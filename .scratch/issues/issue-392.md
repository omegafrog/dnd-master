## 구현 목적

일상 동료 대화는 GM이 자연스럽게 만들고, 파티 상태에 영향을 주는 중요한 대화 선택은 사용자가 정하도록 기존 대화 흐름에 연결한다.

## 범위

- 기존 대화 입력·응답을 사용해 GM이 일상 대사와 중요한 선택지를 반환하고, 사용자의 자유 입력도 받는다.
- 전투 행동, 자원 소모, 그룹 분리·합류, 퀘스트·관계 방향을 바꾸는 선택 전에는 파티 상태를 바꾸지 않고 사용자 입력을 기다린다.
- 동료 대화 제안이 현재 맥락에 명시된 해당 동료의 성격·가치관과 충돌할 때만 GM이 이유를 설명하고 그 대화 행동을 실행하지 않는다. 근거가 없는 성격·가치관은 만들지 않는다.
- 일상 대화와 선택지 응답만으로 파티·턴·자원 상태를 바꾸지 않는다. 새 대기 상태, 저장 자료, 대화 요청 경로를 만들지 않는다.
- GM은 세계·NPC·적·판정과 대화를 맡고, 파티의 이동·전투·능력 습득·시트 변경을 선택하거나 실행하지 않는다.

## 수용 기준

- GM이 일상 동료 대사를 생성해도 파티 상태가 바뀌지 않는다.
- 중요한 동료 대화에서는 선택지를 제시하거나 자유 입력을 받고, 사용자 확정 전에는 파티 상태가 바뀌지 않는다.
- 현재 맥락에서 확인되는 동료 성격·가치관과 충돌하는 대화 행동만 설명과 함께 거절하고 다음 기존 대화 입력을 기다린다. 충돌하지 않는 대화는 사용자가 고른 내용으로 진행한다.
- 파티 행동 명령은 인증된 모험 소유자인 사용자가 확정한 것만 통과하고, AI가 대신 만든 파티 행동은 상태 변경 없이 거부한다. GM이 판정한 규칙 결과 반영에는 추가 승인을 요구하지 않는다.
- 중요한 동료 대화를 사용자가 확정한 뒤 GM 판정 결과가 파티 상태에 한 번 반영되고, 결과 반영을 위한 추가 승인을 요구하지 않는다.
- 기존 대화 입력·응답 경로를 재사용하고 별도 선택 대기 저장 상태를 추가하지 않는다.

## 테스트 계약

- 단위/정책: 일상 대화의 무상태성, 중요한 선택의 사용자 대기, 성격 충돌 근거·거부 경로, 파티 명령 주체 검증과 상태 불변을 검증한다.
- 단위/정책: 중요한 동료 대화를 사용자가 확정한 뒤 GM 판정 결과가 파티 상태에 한 번 반영되고, 결과 반영을 위한 추가 승인을 요구하지 않는지 검증한다.
- ui ~ entity E2E: 기존 채팅에서 동료 대화 선택지를 받고 자유 입력·충돌 입력을 각각 제출해 응답을 확인하고, 사용자 확정 전후의 대화·파티 저장 상태를 비교한다. 중요한 선택을 확정한 뒤 판정 결과와 자원 변화가 추가 승인 입력 없이 반영되는지도 확인한다.
