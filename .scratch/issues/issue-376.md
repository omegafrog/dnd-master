## 구현 목적

관리자가 공용 룰북 목록에 등록한 PDF의 전처리 페이지를 확인하고, 원본과 대조해 선택한 읽기 순서 후보를 기록한 다음 필요한 페이지만 재시도할 수 있게 한다. #363에서 실제로 배운 능력의 상세정보를 준비할 때 원문 위치를 정확히 검색하도록 지원한다. 전체 주문을 사전 적재하는 작업은 아니다.

## 재현 근거

제공된 `DnD_BasicRules_2018.pdf` 원본 SHA-256은 `7a0c5d8bf52d15092f156d78418aa3d43307e271f810d2f06bf2f0258e9288a3`이다. 정상 등록 후 180쪽 중 170쪽이 검증되고 23, 31, 35, 48, 51, 52, 55, 57쪽은 열 읽기 순서가 애매하며 111, 178쪽은 배치 검증 실패와 낮은 열 판정 신뢰도로 검토 대기했다. 현재 등록 주체의 내부 소유자와 로그인 관리자의 ID가 달라 기존 문서 조회·페이지 재시도 경로가 403을 반환한다. 목록·업로드·게시 관리 경로에는 페이지 검토가 없다. 선택한 후보의 점수 0.791/0.769는 현행 자동 기준 0.8보다 낮아 실제 PDF와 대조한 수동 확인을 그대로 반영할 수도 없다.

## 범위와 수용 기준

- 인증된 목록 관리자만 해당 목록 등록에 속한 문서의 검토 상태·페이지 후보·원본 미리보기를 읽고, 선택한 후보와 원본 PDF 대조 확인자·후보/추출 버전을 기록하고, 해당 페이지를 재시도한다.
- 일반 사용자의 개인 문서는 기존 소유자만 볼 수 있고, 임의 사용자 ID 대리 입력이나 원본 소유자 변경으로 403을 우회하지 않는다. 기존 개인 문서 검토와 자동 검증도 유지한다.
- 존재하지 않거나 오래된 후보/버전과 다른 등록 문서의 페이지는 거부한다. PDF 원본 바이트·해시·출처/추출 버전 식별자를 보존한다.
- 원본 확인은 애매한 읽기 순서와 낮은 통계 신뢰도만 해소한다. 자동 신뢰도 0.8 기준, 글자 누락·좌표 이상 등 내용 무결성 검사는 낮추거나 건너뛰지 않는다. 실제 내용 오류가 남으면 검토 대기를 유지하고 남은 판단 사항을 표시한다.
- 확인 대상은 PDF 23, 31, 35, 48, 51, 52, 55, 57, 111, 178쪽이다. PDF 87~110쪽의 주문 목록 자체를 변경하는 작업이 아니다.

## 검증

권한 없는 요청 거부, 관리자의 페이지 조회·후보 확인·재시도, 오래된 후보 거부, 내용 무결성 오류 유지, 원본 해시/버전 보존을 회귀 검사한다. 같은 작업 트리에서 실제 등록 → 검토 → 재시도 → 저장 상태를 확인한다.
