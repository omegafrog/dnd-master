## 구현 목적

Skeleton 사이의 non-anchor headings를 다중 evidence로 배치한다. 애매한 관계는 확정하지 않고 unresolved로 보존하며 full canonical tree와 재귀 source spans를 게시한다.

## 구현 범위

- `HierarchyInference`와 confirmed/tentative/unresolved edges.
- confidence evaluator와 canonical validator.
- synthetic `UNRESOLVED` container.
- parser/canonical dual hierarchy.
- immutable leaf span과 recursive parent span union.
- versioned canonical publication.

## 수용 기준

- source range 단독 parent 확정 금지.
- 모든 edge가 evidence/confidence/resolution/resolver version 포함.
- source node/span preservation 100%.
- cycle 0, duplicate ownership 0, deterministic rerun.
- synthetic unresolved node는 semantic hierarchy path에서 제외 가능.

## 테스트 계약

- 정책 단위: ambiguous hierarchy, partial document, neighbor conflicts, confidence gate, recursive span, deterministic ID.
- UI~entity E2E: skeleton → inference → canonical publication → unresolved lookup.
- 회귀: parser hierarchy comparison view.

## 제외 범위

- chunk/index consumer migration.
- Graphify transport.
