# 035-3 게임 준비 팝업과 AI endpoint 사전 확인

- 상태: `completed`
- Issue: [#158](https://github.com/omegafrog/dnd-master/issues/158)
- 의존성: `035-1`, `035-2`
- 대상: `adventure-service`, `web-ui`, AI endpoint integration

## 구현 목적

저장된 모험 자료에서 게임 준비를 팝업으로 실행하고, 실제 준비 작업의 진행 상태를 안정적으로 복구한다. AI endpoint는 자료 저장 단계가 아니라 게임 준비를 시작하는 시점에만 검사한다.

## 범위

- 모험 자료 카드별 `게임 준비` 팝업
- endpoint preflight와 준비 작업 시작 계약
- 컴파일 단계·진행률·완료·실패·재시도 표시
- 팝업을 닫았다 다시 열어도 서버 작업 상태 조회
- Codex OAuth의 로그인 필요/연결됨/만료/실패 상태 표시
- endpoint 미연결 시 설정 화면으로 안내하고 준비 차단
- 준비 완료 후 캐릭터 생성·모험 시작 버튼 연결
- 중복 준비 요청의 멱등성 보장

## 제외 범위

- AI Game Master 서술 품질
- 캐릭터 생성 규칙 변경
- 자료 업로드 처리 자체

## 정책 테스트

- endpoint preflight 실패 시 컴파일이 시작되지 않는지 검증
- 동일 bundle revision에 중복 컴파일이 생성되지 않는지 검증
- 컴파일 실패 시 retryable 여부에 따라 재시도 가능 여부 검증
- 발행된 package만 세션 생성에 사용되는지 검증

## UI ↔ Entity 통합 테스트

- 카드에서 팝업을 열고 준비 시작까지 연결되는지 검증
- 팝업을 닫고 다시 열었을 때 서버 상태가 복원되는지 검증
- endpoint 미연결 상태에서 설정 안내가 표시되는지 검증
- 완료 후 캐릭터 생성/모험 시작 버튼이 활성화되는지 검증

## 완료 조건

- 준비 상태의 source of truth가 서버에 있다.
- 팝업 닫힘이 백엔드 작업을 취소하지 않는다.
- 실패 메시지는 재시도 또는 설정 이동이라는 다음 행동을 제공한다.
- 세션은 준비 완료된 immutable package만 참조한다.
