# 035-2 자료 준비 상태와 진행률

- 상태: `completed`
- Issue: [#157](https://github.com/omegafrog/dnd-master/issues/157)
- 의존성: `035-1`
- 대상: `rule-knowledge-service`, `web-ui`, rule-knowledge 계약

## 구현 목적

파일을 업로드하자마자 완료된 것처럼 보이지 않게 하고, 추출·청킹·임베딩·인덱싱의 비동기 상태를 사용자가 확인할 수 있게 한다. 준비 완료된 파일만 모험 자료 선택과 저장에 사용할 수 있도록 한다.

## 범위

- 문서 처리 상태와 단계별 진행률의 canonical 계약 정의
- 기존 문서와 새 업로드 문서 모두에 대해 비종료 상태 polling 지원
- shadcn `Progress` 컴포넌트로 파일별/전체 진행률 표시
- 처리 중·실패 자료 선택 차단
- 실패 자료 개별 재처리
- 기존 업로드 자료를 스토리북 목록에서 파일별 선택
- 룰북 판본 선택과 스토리북 선택 상태 분리
- 준비 완료 전 모험 자료 저장 버튼 비활성화

## 제외 범위

- bundle 이름·판본 저장 계약 자체
- 게임 준비/컴파일 진행률
- 문서 보관 기능

## 정책 테스트

- `QUEUED → PROCESSING → INDEXED` 상태 전이 검증
- 실패 문서만 재시도되는지 검증
- 새로고침 후에도 비종료 문서가 polling 대상인지 검증
- 준비 완료가 아닌 문서는 bundle 저장 명령에서 거부되는지 검증

## UI ↔ Entity 통합 테스트

- 업로드 후 shadcn Progress와 단계 문구가 표시되는지 검증
- 처리 완료 전 체크박스와 저장 버튼이 비활성화되는지 검증
- 기존 처리 중 파일을 다시 방문했을 때 상태가 갱신되는지 검증
- 파일별 역할과 선택 상태가 저장 요청에 정확히 반영되는지 검증

## 완료 조건

- 상태 API가 서버의 실제 처리 상태를 반영한다.
- 네이티브 progress 대신 shadcn Progress가 사용된다.
- 브라우저 세션을 새로 열어도 처리 상태가 복구된다.
- 준비 완료 자료만 다음 단계로 이동할 수 있다.
