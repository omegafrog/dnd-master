## 구현 목적

여러 evidence를 structural anchor로 결합하고 본문 heading과 다중 신호로 매칭한다. high-confidence anchor만 포함하는 검증 가능한 skeleton tree를 shadow publication한다.

## 구현 범위

- `StructuralAnchor`, `MatchedAnchor`, `AnchorBuilder`, `AnchorMatcher`.
- title/locator/numbering/order/style/neighborhood score.
- direct/offset/segmented-reset/Roman locator resolution.
- `AnchorTreeBuilder`, confidence gate, skeleton validator/report.

## 수용 기준

- title equality 단독으로 match 확정하지 않음.
- 반복 제목과 ambiguous tie를 안전하게 판별 또는 unresolved 처리.
- threshold 미달 anchor는 source identity/evidence와 함께 보존.
- skeleton cycle 0, duplicate ownership 0, stable source order.

## 테스트 계약

- 정책 단위: duplicate title, ambiguous tie, locator offset/reset, malformed anchor, confidence thresholds.
- UI~entity E2E: extracted document → evidence → anchor match → published skeleton/report.
- 회귀: normalized preservation 100%.

## 제외 범위

- non-anchor heading inference.
- RAG/Graphify consumer cutover.
