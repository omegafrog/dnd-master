# 038-4 전술 트리거와 미래 단계 개정

- Issue: [#177](https://github.com/omegafrog/dnd-master/issues/177)
- Parent: [#179](https://github.com/omegafrog/dnd-master/issues/179)
- 상태: `completed`
- 의존성: `038-3`

## 구현 목적

계획 단계에서 정의한 전투 진입·경보·증원·보스·보상·안개 해제·승패·이탈 트리거만 런타임 변화를 만들고, 공개된 과거를 바꾸지 않은 채 미래 미공개 단계만 개정한다.

## 범위

- 트리거 평가와 토큰·환경·가시성·보상·전이 효과를 구현한다.
- 공개 단계의 불변성과 미공개 미래 단계의 append-only revision history를 구현한다.
- AI 보완이 필요한 미래 개정은 근거 우선·3회 재생성 규칙을 다시 적용한다.

## 비범위

- 플레이어에게 GM 계획을 편집하도록 허용하지 않는다.

## 완료 기준

- 계획된 트리거만 runtime state와 분기를 바꾼다.
- 공개된 단계의 배치·결과는 모든 개정 명령에서 보존된다.
- 미래 단계 개정은 새 revision과 근거를 남긴다.

## 테스트 계약

- 정책 단위: 각 트리거 효과, 공개 단계 수정 거부, 미래 단계만 개정되는 이력을 검증한다.
- 통합: 안개 해제·보상 발견·증원·보스 전환과 전이의 Combat Map 반영을 검증한다.
- UI → 엔티티 E2E: 플레이어 행동이 계획된 트리거를 만족할 때 공개 상태만 변경되는 흐름을 검증한다.
