## 구현 목적

Rule Evidence와 Graphify가 동일 canonical tree를 projection만 하도록 바꾼다. parser tree나 heading을 재해석하는 두 번째 hierarchy authority를 제거한다.

## 구현 범위

- `CanonicalGraphProjector` port.
- Rule Evidence canonical input 전환.
- deterministic node/evidence/edge IDs.
- Graphify `CONTAINS` projection contract/adapter.
- parser-vs-canonical diagnostics.

## 수용 기준

- projected parent/containment edges가 confirmed canonical edges와 동일.
- projector에 TOC/heading/typography hierarchy inference 없음.
- random UUID 제거.
- source span과 resolver version 역추적 가능.

## 테스트 계약

- 정책 단위: projection identity, edge equivalence, unresolved handling, deterministic IDs.
- UI~entity E2E: canonical publication → evidence repository + Graphify projection artifact/entity.
- 회귀: evidence search and ancestor expansion.

## 제외 범위

- canonical hierarchy 결정 변경.
- consumer-wide cutover.
