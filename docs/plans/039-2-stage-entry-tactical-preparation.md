# 039-2 현재 맵 단계 진입 시 전술 장면 준비

- Status: `completed`
- Dependencies: `039-1`
- Product Spec: `docs/specs/product-spec.md`
- Architecture Spec: `docs/specs/architecture-spec.md`

## 구현 목적

모험 시작 후 사용자가 실제로 진입하는 현재 맵 단계 하나만 전술 장면을 준비한다. Shard CN 프로그레스바로 상태를 보여주고 완료 전에는 맵을 활성화하지 않는다.

## 범위

- 세션·단계별 전술 장면 준비 application service 추가
- typed candidate 검증과 최대 3회 재시도 재사용
- 현재 단계만 대상으로 하고 미래 단계는 준비하지 않음
- 준비 중 Shard CN 상태·진행률·단계명 제공
- 실패 시 맵 진입 차단과 구체적 사유·재시도 제공
- 동일 단계 중복 요청은 기존 작업 재사용

## 테스트 계약

- 현재 맵 단계만 준비하고 미래 단계는 호출하지 않는 단위 테스트
- 준비 성공 후 맵 활성화, 실패 후 재시도 가능한 상태의 통합 테스트
- Shard CN 진행 상태와 실패 사유의 UI 테스트

## 완료 조건

- 맵 단계 진입 시 준비 작업이 시작된다.
- 완료 전 맵 활성화가 실행되지 않는다.
- 성공하면 준비된 장면으로 맵이 활성화된다.
- 최대 재시도 실패는 계획을 BLOCKED로 바꾸지 않는다.
