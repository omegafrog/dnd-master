# 적 보유 능력 정의 준비와 전투 실행 연결

## 상태

## 의존성

[#363 배운 주문·기술 상세정보 준비와 GM 조회](../../../.scratch/issues/issue-363.md), [#372 전투 주문·기술 실행과 비용 확정](../../../.scratch/issues/issue-372.md)

## 구현 목적

현재 적 행동 경로는 출처가 있는 적 시트 행동을 선택하지만, 그 행동과 적이 실제 보유한 능력 식별자 및 모험별 능력 정의를 연결하지 않는다. 적 시트에 등록된 능력만 기존 파티 능력 정의의 저장·조회 및 규칙 처리 경로에 연결해, 적의 능력도 근거·지원 상태를 확인한 뒤 같은 사거리·대상·효과 규칙으로 실행한다.

## 범위

- 기존 적 시트의 실제 능력 식별자를 모험별 능력 정의 저장·조회 경계에 연결한다.
- 기존 적 행동 선택 경로가 선택한 능력을 정의 및 실행 지원 상태로 확인하게 한다.
- 정의 누락·미지원·조회 실패를 구분하고 능력 실행을 차단한다.
- 적의 내부 수치 공개 경계를 유지하고 기존 전투 결과 반영·중복 방지 경계를 재사용한다.

## 수용 기준

- 적 시트에 실제 등록된 능력만 준비한다. 전체 룰북·적 자료의 일괄 검색은 하지 않는다.
- 출처 위치와 실행 지원 상태를 현재 모험에 저장하고 같은 모험의 정의를 재사용한다.
- 활성 정의와 보유 능력을 확인한 행동만 실행한다. 미보유·준비 필요·미지원·오류를 서로 구분한다.
- 적 주문·기술의 행동 종류, 사용 시점, 자원 비용과 소모 시점, 시야 조건, 판정 방식과 효과, 지속시간, 집중, 발동 조건, 예외를 정의의 출처 규칙대로 각각 적용한다. 더 높은 등급 선택에 따른 변화가 정의에 있으면 같은 규칙으로 처리하고, 적 자료로 확인할 수 없는 필수 자원이나 선택은 추측하지 않고 해당 능력을 지원되지 않는 상태로 막는다.
- 적이 사용하는 능력의 사거리·대상·효과는 플레이어의 같은 능력과 같은 정의 및 규칙을 따르며, 비교 검증은 행동 종류·사용 시점·대상 유효성·판정 결과·효과·자원 변화·지속·집중·발동을 포함한다. 자원과 결과는 해당 적 참가자에게만 반영한다.
- 능력 정보나 오류 응답은 적의 비공개 전투 수치를 공개하지 않는다.
- 정의가 없거나 조회 오류가 나면 같은 능력 정의 준비·복구 흐름으로 넘긴 뒤 같은 행동 요청을 재개한다. 복구 재개나 중복 요청은 적 행동·효과·비용을 두 번 반영하지 않는다.

## 테스트 계약

- 단위/정책: 적 시트 능력 식별자에서 준비·저장·조회, 정의 항목별 출처 규칙 적용(행동 종류, 사용 시점, 비용·소모 시점, 시야, 판정·효과, 지속·집중·발동·예외), 미보유·미지원·오류 차단, 동일 능력의 파티·적 규칙 결과를 비교한다. 정의 복구 뒤 같은 행동 요청의 재개와 중복 요청에서 적 행동·효과·비용이 한 번만 반영되는지 확인한다.
- `ui ~ entity` E2E: 실제 능력을 보유한 적이 있는 전투에서 실제 AI의 행동 선택부터 화면 결과와 저장된 전투 상태까지 확인한다. 기존 실제 에이전트 실행 절차를 따르며 고정 응답을 사용하지 않는다.
- 성능: 별도 성능 목표가 없고 한 번의 전투 행동에서 보유 능력만 조회하므로 별도 성능 검증을 추가하지 않는다.

## 추적 정보

- Plan ID: `enemy-ability-preparation`.
- 요구사항 식별자: BR-01, BR-11, BR-12, BR-14, BR-17, G-01, AC-01, AC-02, AC-04, AC-11, ST-001.
- 수용 기준: 적의 실제 보유 능력만 준비하고, 같은 정의와 규칙으로 검증·실행한다.
- 반례: 적 자료를 일괄 준비하거나, 활성 정의가 없는 능력을 실행하거나, 정의 항목을 빠뜨리거나, 같은 능력을 파티와 적에게 서로 다른 규칙으로 처리하거나, 복구 재개로 비용·효과를 중복 적용한다.
- 검증 사례: 보유 능력 한정 준비, 정의 항목별 규칙 적용, 모험별 저장·재사용, 미보유·미지원·오류 차단, 복구 후 동일 요청 재개와 중복 방지, 동일 능력의 파티·적 결과 비교, 실제 적 행동부터 저장된 결과까지 확인.
- E2E disposition: 필요 — 적 행동 선택, 능력 정의 조회, 전투 상태 반영은 서로 다른 경계를 통과하며 저비용 검사만으로 실제 연결을 증명할 수 없다. 실제 에이전트 응답을 따르는 단일 전투 시나리오에서 화면·저장 상태를 대조한다.
