- 기존 모험별 정의 저장소, 적 행동 선택 경로, 전투 결과 반영 경계를 확장하고 새 서비스나 별도 능력 규칙을 만들지 않는다.

- 적 능력의 행동 종류·사용 시점·비용과 소모 시점·시야 조건·판정과 효과·지속·집중·발동 조건·예외 및 사거리·대상은 능력 정의의 출처 규칙을 따르며, 더 높은 등급 선택에 따른 변화도 동일하게 처리한다. 확인할 수 없는 필수 자원·선택은 추측하지 않고 지원 불가로 막는다.
- 정의 복구 뒤 같은 행동 요청을 재개해도 행동·효과·비용은 한 번만 반영되며, 파티와 적의 같은 능력 결과를 항목별로 비교한다.
- 정의 자료·오류 응답·행동 선택으로 적의 비공개 전투 수치가 공개되지 않는다.
- 금지 사례: 정의·보유·자원이 유효한 능력을 효과 엔진 미지원만으로 차단하거나, 적만 별도의 GM 효과·비용 규칙으로 실행한다. 적 자료 전체를 미리 준비하거나, 정의가 없는 능력을 실행하거나, 플레이어와 적에게 서로 다른 사거리·대상·효과 규칙을 적용한다.

## 테스트 계약

- 개발용 진단 검증 (Architecture Spec §9.1·INV-01): 이 계획이 바꾸는 각 시작·완료·대체 경로·재시도·실패 분기에서 기존 `DevelopmentDiagnostics`(개발 진단 기능)와 `dev_` 개발 로그 형식을 확인한다. `ADVENTURE_RUNTIME_DIAGNOSTICS_ENABLED`(개발용 상세 진단 로그 설정)가 꺼졌을 때 상세 로그가 없고, 켜졌을 때 식별자·입력 크기/개수·기대/실제 값·선택 분기·소요 시간·실패 종류와 다음 복구 동작이 드러나며, 프롬프트·응답·인증 정보·불필요한 플레이어 입력·비공개 지도 정보를 기록하지 않고 실제 동작도 바꾸지 않는지 검사한다.

- 파티·적 비교: 같은 유효 능력 정의의 효과를 엔진이 처리하지 못하게 하여 양쪽 모두 #372 GM 전체 효과 해결로 넘어가고, 검증된 결과·비용이 해당 캐릭터에게만 한 번 적용되는지 확인한다. GM 응답 유실·재시도와 같은 행동 요청 재개에도 효과·비용을 반복하지 않는다. 같은 능력이라도 미보유·근거 검증 불가·필수 자원 불명은 GM 위임으로 우회하지 않고 거부하며 적의 비공개 정의·전투 수치를 공개하지 않는다. (BR-32·BR-47·AC-11·AC-38·AC-39)

- 단위/정책: 적 시트 등록 능력만 준비하는지, 출처·지원 상태 저장, 반복 준비, 정의 항목별 출처 규칙 적용, 미보유·정의 검증 실패·필수 자원 불명·오류 차단과 유효 능력의 효과 엔진 미지원 시 GM 전체 해결, 복구 뒤 같은 행동 요청 재개와 중복 방지, 기존 적 행동 선택 및 전투 결과 반영을 검증한다. 파티와 적이 같은 능력 정의를 조회할 때 행동 종류·사용 시점·대상·판정·효과·자원·지속·집중·발동 결과가 일치하고 캐릭터별 자원·상태만 따로 반영되는지도 확인한다. 요구사항 식별자: BR-01, BR-11, BR-12, BR-14, BR-17, BR-32, BR-47, G-01, AC-01, AC-02, AC-04, AC-11, AC-38, AC-39, ST-001. 소유 경계와 실행 진입점: 모험별 능력 정의 준비 서비스(AdventureAbilityDefinitionPreparationService)와 기존 적 행동 처리 경계; 적 능력 정의·사용 여부·전투 결과를 같은 모험별 정의 및 공통 규칙으로 검증. 추적 수용 조건: 적 시트 보유 능력만 모험별로 준비하고, 적이 실제 선택한 능력을 기존 규칙 처리 경계에서 실행한다. 반례: 적 자료 전체를 미리 준비하거나, 정의가 없는 능력을 실행하거나, 플레이어와 적에게 서로 다른 사거리·대상·효과 규칙을 적용한다. 검증 사례: 적 시트 능력 등록과 정의 활성화, 반복 준비, 미보유·정의 검증 실패·필수 자원 불명·오류 거부와 유효 능력의 효과 엔진 미지원 시 GM 전체 해결, 동일 능력의 파티·적 규칙 결과 비교, 실제 적 행동 선택에서 저장 상태까지 확인.
