# KB-003: 계층형 Rule Evidence와 하이브리드 검색

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/137
- Dependencies: `KB-002`

## 구현 목적

룰북을 규칙 의미와 부모 관계를 가진 Evidence로 투영한다. Dense+lexical 검색 후 필요한 상위 규칙만 예산 안에서 확장한다.

## 구현 범위

- Rule `EvidenceUnit`/`EvidenceEdge`
- `RuleEvidenceProjector`, hierarchy persistence
- Evidence search index projection
- dense+lexical merge/rerank
- `AncestorExpansionPolicy`
- 기존 rule search endpoint 삭제

## 수용 기준

- Perception leaf가 Ability Check 근거와 연결.
- 모든 Evidence와 edge가 Source Span 보유.
- Scope 밖 문서 미반환.
- Ancestor expansion이 context budget 준수.

## 테스트 계약

- 정책 단위: hierarchy, rerank, expansion budget, conflicts
- UI~entity E2E: rule query → leaf → expanded Evidence Pack
- Persistence: graph/index round trip
