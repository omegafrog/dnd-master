# 035-4 모험 목록과 전체 용어·내비게이션 UX

- 상태: `completed`
- Issue: [#159](https://github.com/omegafrog/dnd-master/issues/159)
- 의존성: `035-1`, `035-3`
- 대상: `web-ui` 전반

## 구현 목적

사용자가 모험 자료와 실제 진행 중인 모험을 구분하고, UUID·revision·내부 enum 없이 다음 행동을 이해할 수 있게 한다. 저장 목록에서 재개하면 항상 실제 모험 화면으로 이동하도록 전체 내비게이션을 정리한다.

## 범위

- `모험 자료`, `진행 중인 모험`, `완료한 모험` 용어 통일
- 모험 자료 이름·룰북·자료 수·준비 상태 표시
- 모험 목록에서 이름·마지막 진행 상태·재개 버튼 표시
- 세션 자료 화면에서 raw status/document type/UUID 제거
- 오류 메시지와 복구 행동 문구 통일
- 게임 준비 팝업 포커스, Escape 닫기, 상태 알림 개선
- bundle/session/adventure 라우팅과 selected bundle 상태 정리

## 제외 범위

- 모바일 전용 재설계
- 새로운 게임 플레이 기능
- AI 응답 품질 개선

## 정책 테스트

- 진행 중 모험과 완료 모험의 상태 분류 검증
- 재개 가능한 세션만 재개 버튼을 제공하는지 검증
- 삭제 불가 자료가 모험 목록에서 일관되게 표시되는지 검증

## UI ↔ Entity 통합 테스트

- 모험 목록에서 재개를 누르면 올바른 adventure route로 이동하는지 검증
- 자료 설정 화면에서 사용자용 상태만 표시되는지 검증
- 팝업의 포커스와 Escape 동작을 검증
- 네트워크 오류가 다음 행동이 포함된 메시지로 표시되는지 검증

## 완료 조건

- 사용자가 자료 준비와 모험 진행을 화면 제목만으로 구분할 수 있다.
- 목록과 상세 화면에 UUID/raw enum이 기본 표시되지 않는다.
- 재개·삭제·게임 준비의 버튼 의미가 화면마다 일관된다.
- 접근성 테스트가 통과한다.
