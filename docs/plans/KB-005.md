# KB-005: Game Asset Catalog, Map Region, Player Handout

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/139
- Dependencies: `KB-002`

## 구현 목적

시각 자료를 text chunk가 아닌 Extraction Version 소유 Game Asset으로 저장한다. 지도는 공간 region/scale을, Handout은 player 원본과 GM Material 분리를 가진다.

## 구현 범위

- `GameAssetCatalog`, `GameAsset`, `AssetRole`, representations
- Opaque blob key와 원본 보존
- `MapRegion`, geometry, `MapScale`, features
- `PlayerHandout` projection과 GM Material relation
- Vision/OCR analyzer ports와 warnings
- Preparation-only asset inspection API

## 수용 기준

- 지도 원본, 설명, 5 ft scale, regions 동시 보존.
- API에 저장 경로 미노출.
- Player Handout projection에 solution/trigger/failure 없음.
- 불확실 geometry/visibility는 auto-display 불가.

## 테스트 계약

- 정책 단위: geometry, scale, role, fail-closed visibility
- UI~entity E2E: asset upload → persistence → safe projection
- 보안: owner isolation, storage-key leakage 방지

## 제외 범위

- Scenario scene binding
- Runtime display tool
