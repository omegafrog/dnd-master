# KB-007: Runtime Retrieval Router와 Typed Evidence Pack

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/141
- Dependencies: `KB-003`, `KB-004`

## 구현 목적

GM 질의를 단일 QueryIntent로 라우팅하고 잠긴 session 문서·버전 범위에서 Rule/Story/Entity Evidence를 검색한다. 근거 부족 시 추측 생성을 막는다.

## 구현 범위

- Shared `RULE/STORY/MIXED/UNKNOWN` contract
- Exact `(documentId, extractionVersion)` scope
- Dense/lexical/metadata routing과 typed groups
- Active scene/visibility filters
- Runtime `1L` fallback 제거
- `EVIDENCE_INSUFFICIENT` 처리
- 기존 API compatibility adapters

## 수용 기준

- Intent는 우선순위만 변경하고 scope 우회 불가.
- Session 밖/stale version Evidence 미반환.
- Rule ancestors와 typed Story Evidence 분리.
- Search 실패가 무근거 성공 narration으로 변환되지 않음.

## 테스트 계약

- 정책 단위: routing, scope, visibility, insufficient evidence
- UI~entity E2E: player action → runtime gateway → typed pack
- Adapter: exact versions 전달, `1L` 대체 없음

## 제외 범위

- Asset 표시 도구
- UI rendering
