# 036-4 설정 확정·게시·캐릭터 생성 연계

Issue: [#165](https://github.com/omegafrog/dnd-master/issues/165)
Parent: [#161](https://github.com/omegafrog/dnd-master/issues/161)
Status: `completed`
Dependencies: 036-1, 036-2, 036-3

## 구현 목적

모든 스토리북 제안이 결정된 뒤 룰북 기본 스키마와 사용하기로 한 제안만 확정·게시하고, 그 이후에만 실제 캐릭터 생성으로 이동하게 한다.

## 구현 범위

- 미결정 제안과 유효하지 않은 기본 스키마의 확정 차단
- 적용 projection만 게시하는 확정 명령
- 확정 결과 요약과 사용자 친화적 상태 표현
- 게시된 blueprint revision으로만 세션·캐릭터 생성 진입 허용
- 기존 세션 생성 경계와 재시도 가능한 오류

## 의존성과 변경 경계

- 036-1~036-3의 계약과 결정 상태를 통합한다.
- 기존 캐릭터 생성 화면과 세션 route는 유지한다.
- 캐릭터 시트 계산 규칙과 게임 플레이 화면은 변경하지 않는다.

## 테스트 계약

- 확정 precondition과 applied projection 단위 테스트
- 게시·세션 생성 API 계약 테스트
- 결정 완료 → 확정 → 캐릭터 생성 진입 `ui ~ entity` E2E

## 완료 조건

- 미결정 제안이 있으면 확정할 수 없다.
- 확정 결과에는 룰북 기본 스키마와 적용 제안만 포함된다.
- 확정 전에는 캐릭터 생성 진입이 제공되지 않는다.
- 세션 생성도 게시된 revision을 서버에서 검증한다.
