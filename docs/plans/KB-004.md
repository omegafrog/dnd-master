# KB-004: Adventure Evidence, Scene Graph, Planner Evidence Pack

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/138
- Dependencies: `KB-002`

## 구현 목적

스토리북에서 장면, NPC, 조우, 판정, 비밀, 전환을 추출해 source-grounded Scene Graph와 전체 모험용 Planner Evidence Pack을 제공한다.

## 구현 범위

- Adventure Evidence kinds와 visibility
- `AdventureEvidenceProjector`
- `SceneNode`, `SceneTransition` 후보
- player-visible/GM-only 분리
- whole-adventure Planner Evidence query
- incomplete graph raw-source fallback

## 수용 기준

- Scene/check/DC/secret/transition이 별도 Evidence로 연결.
- 원문 없는 transition/result 미확정.
- `UNKNOWN` visibility는 player projection 제외.
- 불완전 graph에서도 raw scene 검색 가능.

## 테스트 계약

- 정책 단위: visibility, transition provenance, fallback
- UI~entity E2E: STORYBOOK upload → Scene Graph/Planner Pack
- 보안 회귀: GM-only excerpt 미노출

## 제외 범위

- Scene→Asset 연결
- Runtime Story Plan 확정
