# KB-002: Docling 구조 추출과 Content Role 분류

- Status: `blocked`
- Issue: https://github.com/omegafrog/dnd-master/issues/136
- Dependencies: `KB-001`

## 구현 목적

Docling을 교체 가능한 adapter로 연결해 layout, hierarchy, table, image를 engine-neutral tree로 추출한다. 콘텐츠를 `KNOWLEDGE`, `GAME_ASSET`, `GM_MATERIAL`로 분류하고 불확실한 구조는 원문으로 강등한다.

## 구현 범위

- `DocumentExtractionPort`와 Docling adapter
- Document tree/node/table/image DTO
- 기존 PDFBox/OCR preview 단계적 호환
- `ContentRoleClassificationPolicy`
- warning severity와 raw fallback
- worker failure mapping

## 수용 기준

- 제목 계층, 표, 이미지, 페이지·좌표 보존.
- STORYBOOK 하나가 복수 Content Role 보유 가능.
- 모호한 구조는 추측하지 않고 warning/raw fallback.
- Docling 장애는 문서별 retryable failure.

## 테스트 계약

- 정책 단위: role classification, ambiguity downgrade, severity
- UI~entity E2E: PDF upload → Docling mapping → source tree publication
- Adapter: malformed, timeout, unsupported input

## 제외 범위

- Rule/Adventure semantic projection
- 자산 region 분석
