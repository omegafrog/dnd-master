# KB-006: exact-version Scene→Asset/Map Region 시나리오 컴파일

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/140
- Dependencies: `KB-004`, `KB-005`

## 구현 목적

Scenario Package가 정확한 Extraction Version의 Scene Graph와 Game Asset을 안정적인 ID로 연결하게 한다. 기존 regex marker와 JSON package는 호환한다.

## 구현 범위

- Stable `SceneId`, `SceneAssetLink`, `MapRegionRef`
- Exact document/extraction version 검증
- Scenario Package graph/link persistence
- `MapDefinitionCompiler` legacy bridge
- Ambiguous/missing link warnings
- 기존 package rehydration compatibility

## 수용 기준

- SceneId로 검색 없이 linked region/handout 조회.
- Wrong/stale version link compile 거부.
- Ambiguous link는 auto-display 불가.
- 기존 Scenario Package rehydrate 유지.

## 테스트 계약

- 정책 단위: direct link, exact version, ambiguity
- UI~entity E2E: compile API → persisted package → scene lookup
- Migration compatibility: legacy map JSON/markers

## 제외 범위

- GM display tool 실행
- Combat Map runtime state
