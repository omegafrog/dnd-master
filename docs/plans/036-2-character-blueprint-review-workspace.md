# 036-2 캐릭터 설정 검토 화면 재구성

Issue: [#163](https://github.com/omegafrog/dnd-master/issues/163)
Parent: [#161](https://github.com/omegafrog/dnd-master/issues/161)
Status: `completed`
Dependencies: 036-1

## 구현 목적

검토 화면을 실제 캐릭터 입력 폼이 아니라 룰북 기본 스키마를 읽고 스토리북 제안을 확인하는 작업 공간으로 재구성한다. 사용자가 무엇이 고정된 기본 내용이고 무엇을 결정해야 하는지 한눈에 이해하도록 한다.

## 구현 범위

- 읽기 전용 룰북 기본 스키마 패널
- 문서별 스토리북 제안 카드와 원문 근거
- 제안 없음·추출 실패·근거 부족·로딩 상태
- 내부 UUID·enum·Blueprint 용어 제거
- 적용 예정 설정 요약과 반응형 접근성

## 의존성과 변경 경계

- 036-1의 review read model을 사용한다.
- 제안의 실제 저장 명령은 036-3에서 연결한다.
- 기본 스키마 패널에는 mutation callback을 노출하지 않는다.
- 실제 캐릭터 값 입력은 캐릭터 생성 화면에 남긴다.

## 테스트 계약

- 기본 스키마가 읽기 전용으로 렌더링되는 UI 정책 단위 테스트
- 제안 없음·실패·근거 부족 상태 UI 테스트
- API fixture에서 화면의 기본 스키마·제안 카드까지 연결하는 `ui ~ entity` E2E

## 완료 조건

- 기본 스키마와 제안이 서로 다른 영역에 표시된다.
- 기본 스키마에는 입력·저장 버튼이 없다.
- 각 제안에 내용·출처·근거·현재 상태가 표시된다.
- 검토 화면에서 실제 캐릭터 값을 채우는 오해가 제거된다.
