# DHR-001: Lossless NormalizedDocument와 Docling shadow E2E

- Status: `completed`
- Issue: https://github.com/omegafrog/dnd-master/issues/144
- Parent Issue: https://github.com/omegafrog/dnd-master/issues/152
- Dependencies: 없음
- Specs: `docs/specs/product-spec.md`, `docs/specs/architecture-spec.md`

## 구현 목적

Docling 결과를 기존 node tree로 축약하기 전에 parser-independent `NormalizedDocument`로 무손실 보존한다. 기존 소비자를 유지하면서 shadow report를 제공해 이후 resolver가 신뢰할 입력 경계를 확보한다.

## 구현 범위

- `NormalizedDocument`, page, element, table, picture, outline, style/layout, parser relation, source span 계약
- extractor/schema version과 deterministic source identity
- Docling response의 lossless mapping
- 기존 `DocumentExtractionResult` compatibility projection
- source preservation validator와 shadow diagnostics

## 수용 기준

- addressable source node와 available source span preservation 100%.
- parser parent/level, table grid, picture, outline, style/layout/source-order를 가능한 범위에서 보존.
- 기존 extraction API와 downstream consumer 회귀 없음.
- resolver나 canonical hierarchy 추론은 포함하지 않음.

## 테스트 계약

- 정책 단위: normalized invariant, deterministic ID, lossless mapping, compatibility projection.
- UI~entity E2E: upload/extract API → Docling adapter → `NormalizedDocument` → shadow report.
- 회귀: `DoclingDocumentExtractionAdapterTest`, existing pipeline extraction tests.

## 제외 범위

- PyMuPDF adapter.
- structural evidence와 hierarchy resolution.
- persistence schema 전환.
