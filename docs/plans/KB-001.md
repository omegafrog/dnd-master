# KB-001: 불변 Extraction Version과 Source Span 정본

- Status: `ready-for-agent`
- Issue: https://github.com/omegafrog/dnd-master/issues/135
- Dependencies: 없음
- Specs: `docs/specs/product-spec.md`, `docs/specs/architecture-spec.md`

## 구현 목적

문서 처리 결과를 덮어쓰지 않는 Extraction Version으로 게시하고 모든 파생 결과가 Source Span까지 추적되게 한다. 문서별 실패와 재시도를 독립화해 이후 Evidence와 Asset이 안정적인 버전을 참조하게 한다.

## 구현 범위

- `KnowledgeDocument`, `DocumentProcessingJob`, `ExtractionVersion` 생명주기
- 페이지·좌표·읽기 순서를 포함한 Source Span
- append-only publication과 current published pointer
- 문서별 lease, 실패, 새 attempt 재시도
- 기존 registration/preview 호환 읽기
- migration과 처리 상태 API projection

## 수용 기준

- Published version 변경 불가.
- 모든 published projection이 Source Span 역참조.
- 같은 batch의 한 문서 실패가 다른 문서를 막지 않음.
- Retry가 기존 published version을 변경하지 않음.

## 테스트 계약

- 정책 단위: lifecycle, lineage, immutability, retry invariants
- UI~entity E2E: upload/status API → processing job → published version
- 회귀: batch, idempotency, indexing pipeline

## 제외 범위

- Docling 연동
- Evidence/Asset 의미 투영
