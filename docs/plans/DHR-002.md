# DHR-002: PyMuPDF adapter와 fallback E2E

- Status: `ready-for-agent`
- Issue: https://github.com/omegafrog/dnd-master/issues/145
- Parent Issue: https://github.com/omegafrog/dnd-master/issues/152
- Dependencies: DHR-001
- Specs: `docs/specs/product-spec.md`, `docs/specs/architecture-spec.md`

## 구현 목적

PyMuPDF fallback을 동일 `NormalizedDocument` 경계 뒤에 추가한다. 기존 PDFBox/OCR 경로는 유지하면서 engine별 정보 차이를 명시적으로 표현한다.

## 구현 범위

- `PyMuPdfAdapter`와 extraction selection.
- blocks, tables, pictures, outlines, bbox, source order 정규화.
- unavailable-evidence warning과 fallback failure classification.
- PDFBox/OCR compatibility 유지.

## 수용 기준

- 같은 synthetic PDF의 공통 의미가 Docling/PyMuPDF normalized contract에서 일치.
- 엔진이 제공하지 않는 feature는 조용히 생성하지 않고 명시적으로 부재 처리.
- fallback에서도 원문과 available provenance 보존.

## 테스트 계약

- 정책 단위: mapping, engine capability, fallback classification, reduced-evidence contract.
- UI~entity E2E: upload API → Docling failure → PyMuPDF → normalized entity.
- 회귀: PDFBox/OCR fallback tests.

## 제외 범위

- PDFBox/OCR 제거.
- hierarchy resolution.
