# KB-009: Player Asset UI와 Upload-to-Play 시스템 E2E

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/143
- Dependencies: `KB-008`

## 구현 목적

Solo Player가 장면에 허용된 Handout과 Map Region을 안전하게 보고 기존 Tactical Map과 상호작용하게 한다. 전체 upload-to-play 흐름을 증명한다.

## 구현 범위

- Player asset event/API client contracts
- Handout viewer와 display state
- Map Region focus/activation integration
- GM-only fields의 type/runtime 차단
- Loading/failure/text fallback UX
- Full system E2E와 ownership regression

## 수용 기준

- Linked Handout 원본 품질 표시.
- Browser payload에 solution/trigger/failure/hidden coordinates 없음.
- Region 표시 후 movement/fog flow 유지.
- Unsafe/unavailable asset이 text play를 막지 않음.

## 테스트 계약

- 정책/component: display state와 safe DTO rendering
- UI~entity E2E: upload → extract → compile → scene → show → rendered asset
- 회귀: CombatMapFlow, SoloAdventureE2E, OwnershipIsolationE2E

## 제외 범위

- 사용자 자산 편집기
- 새 asset 자동 생성
