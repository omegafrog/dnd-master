- Status: `completed`

## 구현 목적

Normalized document에서 outline, printed navigation, numbering, typography, indentation, layout, parser hierarchy, source order, locator를 독립적인 `StructuralEvidence`로 추출한다.

## 구현 범위

- evidence model과 extractor orchestration.
- `PrintedNavigationExtractor`의 table/plain-text/mixed/multi-column 지원.
- parser-independent `NavigationEntry`.
- document-relative `NumberingAnalyzer`, `HeadingFeatureExtractor`.
- evidence diagnostics와 independence guard.

## 수용 기준

- Contents 문구나 front-matter 고정 위치 없이 navigation 후보 탐지.
- 고정 font-size/Part/Chapter level 규칙 없음.
- malformed/absent signals가 source loss를 유발하지 않음.
- production code/config에 D&D title/page/offset 상수 없음.

## 테스트 계약

- 정책 단위: TOC table/plain/no TOC/outline-only/numbering-only/typography-only/malformed/multi-column/OCR fixtures.
- UI~entity E2E: extraction API → normalized input → evidence/navigation report.
- 회귀: adapter preservation contract.

## 제외 범위

- anchor-body matching.
- canonical parent 결정.
