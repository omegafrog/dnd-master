# KB-008: show_asset/show_map 권한과 Combat Map 활성화

- Status: `planned`
- Issue: https://github.com/omegafrog/dnd-master/issues/142
- Dependencies: `KB-005`, `KB-006`, `KB-007`

## 구현 목적

AI GM이 opaque Asset Reference만 사용해 Handout/Map Region 표시를 요청하게 한다. Adventure Runtime이 capability, active scene, exact version, link, visibility를 검증한다.

## 구현 범위

- `show_asset`, `show_map` tool schemas
- `AssetDisplayAuthorizationPolicy`
- Idempotent `AssetToolApplicationService`와 audit
- Player-safe asset projection event/API
- Asset/Region ref → Combat Map activation adapter
- Unsafe/unavailable text fallback

## 수용 기준

- Unlinked/wrong-version/GM-only/stale-scene 요청 거부.
- Handout 표시 응답에 GM Material 없음.
- Valid region이 Tactical Map 활성화.
- Combat Map이 source asset/GM Material 미소유.

## 테스트 계약

- 정책 단위: authorization matrix, safety, idempotency
- UI~entity E2E: GM tool → authorization → player projection/map
- 보안: capability, owner, hidden coordinates/solution

## 제외 범위

- Player UI component
