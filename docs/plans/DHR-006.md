## 구현 목적

고정 heading regex 대신 canonical hierarchy와 source spans를 사용해 검색 가능한 contextual RAG chunks를 생성한다.

## 구현 범위

- `HierarchyAwareChunker`와 `RagChunk` metadata.
- hierarchy path, source node IDs, page range, confidence.
- contextual embedding prefix.
- `RulebookChunk`와 persistence compatibility migration.
- tentative/unresolved semantic path policy.

## 수용 기준

- hierarchy resolution 전 hierarchy-aware chunk 생성 금지.
- confirmed ancestor path와 immutable source identity 포함.
- synthetic unresolved ancestor 미포함.
- 기존 chunk-size/split/search invariants 유지.

## 테스트 계약

- 정책 단위: path metadata, split boundaries, tentative exclusion, source coverage.
- UI~entity E2E: upload → canonical tree → chunk → vector persistence/search result.
- 회귀: existing indexing/search tests.

## 제외 범위

- Graphify projection.
- legacy contract 제거.
