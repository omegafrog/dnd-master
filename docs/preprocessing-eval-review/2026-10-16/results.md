- 라벨 상태: 사용자 검수 대기 초안
- 새 PDF 추출 실행: 하지 않음
- 비교 대상: 저장된 `/tmp/dnd-other-rulebooks-hybrid-ai-resolution/*/pages.json`
- 새 원본 검수 표본: D&D 5e 8페이지, Ironsworn 6페이지. 원본 PDF 렌더와 페이지 좌표 눈금으로 표 유무·영역을 라벨링함.
- 기존 파일럿 라벨: Basic Roleplaying 3페이지, Cairn Player 3페이지, Cairn Warden 3페이지. 이전 초안 상태를 유지함.

## 해석 한계

표 영역·셀 측정은 5개 PDF의 명시적으로 라벨된 18개 페이지에 대한 진단용 파일럿이고, 추가 페이지 표본은 93페이지임. 이전 구조 파일럿의 5페이지는 `tables` 라벨이 없어 표가 없다는 정답으로 간주하지 않았음. 둘 다 전체 룰북 정확도 추정치가 아님. 특히 셀 구조 점수는 이전에 작성한 사용자 검수 대기 라벨 9페이지에만 적용했고, 이번에 새로 검수한 D&D 5e·Ironsworn 페이지는 영역 수준까지만 라벨링함. 페이지 표본도 전체 책의 성능 추정에 충분하다고 볼 수 없고, 기존 및 신규 라벨 모두 최종 승인되지 않았음.

기계 판정 기준: 영역 대응은 IoU 0.50 이상. 표가 없는 페이지에 추출 표가 있으면 페이지 거짓양성으로 계산. 셀 문구는 공백 정규화 후 정확히 비교하며, 행 번호 이동 영향을 피하기 위해 완전한 셀 문자열 묶음으로 행을 대응함.
