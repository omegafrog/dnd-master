# MCP 도구 서버로 GM 에이전트의 백엔드 작업 연결

## 배경

GM 에이전트가 맵 토큰 이동, 토큰 생성·삭제, 영역 공개, 트리거 실행, 장면 전환처럼 백엔드 상태를 변경해야 하는 작업을 일관된 도구로 호출할 수 있어야 한다.

## 범위

- MCP 서버 또는 MCP 어댑터에서 GM 작업 도구를 제공한다.
- 백엔드의 명령 API를 도구로 노출한다.
- 권한, 세션 소유권, 맵 경계, 규칙 검증, 동시성, 멱등성은 백엔드가 최종 책임진다.
- AI가 데이터베이스나 저장소를 직접 변경하지 못하게 한다.

## 후보 도구

- 현재 장면과 맵 상태 조회
- 토큰 이동·생성·삭제
- 맵 영역 공개
- 트리거 실행
- 다음 모험 단계 진행

## 완료 조건

- 도구 계약과 오류 응답이 정의되어 있다.
- 백엔드 검증을 우회할 수 없다.
- 토큰 이동과 상태 변경이 감사 로그와 멱등 키를 보존한다.
- GM 에이전트의 도구 호출을 실제 브라우저 흐름에서 검증한다.
