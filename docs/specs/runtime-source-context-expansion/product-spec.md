# 런타임 근거 추적 및 같은 페이지 근거 확장

## 1. 문제와 배경

현재 규칙 검색은 관련 근거 후보를 찾더라도, 후보가 선택되는 과정과 최종 AI Game Master 입력에 포함되는 과정을 추적하기 어렵다. 기존 규칙 근거 조회가 `NOT_FOUND`를 반환했을 때 출처 위치가 가리키는 같은 페이지를 보완 확인하지 않으면, 이미 게시된 관련 근거가 최종 판정에 전달되지 않을 수 있다.

이 변경은 검색 모델을 교체하는 작업이 아니다. 허가된 모험 자료에서 찾은 근거가 최종 판정에 전달됐는지 추적한다. 기존 규칙 근거 조회(RuntimeFactLookup)가 `NOT_FOUND`를 반환할 때만 선택된 근거의 같은 페이지에 있는 추가 게시 근거를 확인하고, 조회를 한 번 더 시도한다. 재시도도 `NOT_FOUND`이면 규칙을 추측하지 않고 미해결로 둔다.

## 2. 목표와 기대 결과

- 검색 후보부터 AI Game Master에 전달되는 최종 입력까지 근거가 유지되었는지 확인할 수 있다.
- 기존 규칙 근거 조회가 `NOT_FOUND`를 반환한 경우에 한해, 선택된 근거의 원문 위치를 기준으로 같은 페이지의 추가 게시 근거를 한 번 조회한다.
- 추가 조회 뒤 한 번 재시도해도 `NOT_FOUND`이면 규칙을 임의로 확정하지 않는다.
- 근거의 문서와 추출 버전을 모험에서 허가된 범위 안에 유지한다.
- 진단 기록만으로 처리 단계와 선택 결과를 파악할 수 있으면서 원문과 프롬프트는 노출하지 않는다.

## 3. 사용자와 참여자

- **Solo Player**: 규칙 적용이 필요한 행동을 제출한다.
- **AI Game Master**: 전달된 근거를 이용해 행동을 판정하거나, 기존 규칙 근거 조회가 근거를 찾지 못하면 판정을 확정하지 않는다.
- **모험 런타임**: 허가된 자료 범위를 유지하고, 검색 근거의 전달 및 같은 페이지 근거 확장을 조정한다.
- **문서 지식 시스템**: 허가된 자료에서 검색 근거와 그 원문 위치를 제공한다.

## 4. 공통 언어와 용어

- **같은 페이지 근거 확장**: 기존 규칙 근거 조회가 정상적으로 `NOT_FOUND`를 반환했을 때만, 선택된 근거의 원문 위치가 가리키는 같은 페이지에서 추가 게시 근거를 한 번 확인하는 행위. 기술 오류에는 실행하지 않으며 다른 페이지로 넘어가지 않는다.

## 5. 핵심 사용 사례

### UC-01 검색 근거 확인 및 같은 페이지 확장

Solo Player가 행동을 제출하면 모험 런타임은 세션에 허가된 자료에서 기존 규칙 근거 조회를 수행한다. 결과가 `NOT_FOUND`일 때만 선택된 근거에 유효한 원문 위치가 있으면 같은 문서·같은 활성 추출 버전·같은 페이지의 추가 게시 근거를 한 번 확인하고 조회를 한 번 재시도한다. 재시도 결과가 `NOT_FOUND`이거나 유효한 원문 위치가 없으면 규칙을 확정하지 않고 미해결로 남긴다. 별도의 AI 근거 충분성 호출이나 무조건적인 같은 페이지 조회는 하지 않는다.

## 6. 업무 규칙과 불변 조건

- 기존 규칙 근거 조회 결과가 `NOT_FOUND`일 때만 같은 페이지 확장을 수행한다. 다른 결과에는 추가 조회를 하지 않는다.
- 검색과 확장은 해당 모험의 허가된 자료 범위 안에서만 수행한다.
- 현재 모험에서 허가된 활성 추출 버전만 사용한다. 과거 추출 버전은 조회하지 않으며 서로 다른 버전의 근거를 섞지 않는다.
- 확장은 선택된 근거의 정확한 원문 위치를 기준으로 같은 페이지에 한정한다.
- 확장 결과는 기존에 게시된 근거만 포함한다. 출처가 확인되지 않은 텍스트를 새 근거처럼 만들지 않는다.
- 같은 페이지의 추가 게시 근거를 한 번 확인하고 조회를 한 번 재시도한 뒤에도 `NOT_FOUND`이면 규칙을 추측하거나 확정하지 않는다.
- 별도의 AI 근거 충분성 호출은 확장 조건이나 재시도 결과를 결정하지 않는다.
- AI Game Master에 전달되는 근거와 원문 출처 연결은 보존한다.
- 진단 기록에는 원문, 프롬프트, AI 응답 본문 또는 불필요한 플레이어 입력을 남기지 않는다.
- 이 작업은 근거 검색·선택·전달의 진단과 보완을 다루며, 검색 결과만으로 게임 상태를 변경하지 않는다.

## 7. 상태와 상태 전이

사용 사례의 처리 결과는 다음과 같이 구분한다.

| 상태 | 의미 |
|---|---|
| 근거 발견 | 기존 규칙 근거 조회가 필요한 근거를 반환함 |
| 같은 페이지 확인 후 발견 | 최초 조회가 `NOT_FOUND`여서 같은 페이지의 추가 게시 근거를 확인한 뒤 재시도에서 근거를 찾음 |
| 미해결 | 최초 조회와 한 번의 같은 페이지 확장 재시도가 모두 `NOT_FOUND`이거나, 확장할 유효한 원문 위치가 없음 |

흐름: `기존 규칙 근거 조회 → NOT_FOUND 여부 확인 → (NOT_FOUND이고 위치가 유효하면) 같은 페이지 게시 근거를 한 번 조회 → 기존 조회 한 번 재시도 → 근거 발견 또는 미해결`.

## 8. 실패·예외·경계 조건

- 최초 조회가 `NOT_FOUND`이면 유효한 출처 위치가 있는 경우에만 같은 페이지 확장을 한 번 시도한다. 다른 자료 범위를 임의로 검색하지 않는다.
- 선택된 근거에 문서·추출 버전·페이지를 확인할 수 있는 위치가 없으면 확장하지 않고 미해결로 둔다.
- 위치가 가리키는 문서나 버전이 현재 모험의 허가 범위와 다르면 해당 위치를 사용하지 않는다.
- 같은 페이지에 추가 게시 근거가 없거나 재시도 결과도 `NOT_FOUND`이면 다른 페이지로 확대하지 않고 미해결로 둔다.
- 최초 조회가 기술 오류로 끝난 경우에는 이를 정상적인 `NOT_FOUND`로 취급하지 않으며, 같은 페이지 확장이나 재시도를 시작하지 않는다.
- 검색 또는 확장 단계에서 기술 오류가 발생하면 오류와 처리 단계를 구분해 기록하고, 근거가 확보된 것처럼 처리하지 않는다.
- 재시도도 `NOT_FOUND`이면 기존 미해결 처리로 남기며, 이번 변경에서 새 사용자 문구나 확인 절차를 정의하지 않는다.

## 9. 입력과 출력

**입력**

- 플레이어가 제출한 행동과 현재 판정 맥락
- 모험에서 허가된 문서 범위와 활성 추출 버전
- 검색 후보 및 선택된 근거의 출처 위치

**출력**

- 기존 조회 및 같은 페이지 보완 조회에서 얻어 최종 판정에 전달한 근거와 원문 출처
- `NOT_FOUND` 이후의 같은 페이지 확장 여부와 한 번의 재시도 결과
- 재시도도 `NOT_FOUND`인 경우의 미해결 결과
- 원문을 포함하지 않는 단계별 진단 정보: 처리 단계, 후보·선택 개수, 출처 식별 정보, 결정 결과, 실패 종류, 소요 시간

## 10. 범위와 제외 항목

**포함**

- 검색 후보부터 최종 AI Game Master 입력까지의 근거 전달 추적
- 선택된 근거의 위치를 사용한 같은 페이지의 추가 게시 근거 조회
- `NOT_FOUND`에 한정한 같은 페이지 확장 한 번 및 제한된 재시도
- 원문·프롬프트를 기록하지 않는 진단

**제외**

- 과거 추출 버전 조회 또는 버전 간 근거 결합
- 인접 페이지 확장, 페이지 전체 검색 색인, 출처 위치 없는 전역 페이지 검색
- 별도의 AI 근거 충분성 판단 호출 또는 무조건적인 같은 페이지 조회
- BM25 도입, 벡터 검색 교체, 리랭커 도입, 광범위한 질의 분해
- 원문에서 청킹되지 않은 텍스트의 별도 저장·조회
- AI Game Master의 규칙 해석 방식이나 게임 상태 변경 규칙의 변경

## 11. 우선순위와 절충

1. 허가 범위와 출처 위치의 정확성을 유지한다.
2. 검색된 근거가 최종 AI 입력까지 전달됐는지 확인한다.
3. 기존 규칙 근거 조회가 `NOT_FOUND`일 때만 같은 페이지의 이미 게시된 근거를 한 번 추가 확인한다.
4. 한 번 재시도해도 찾지 못하면 자동 확정보다 미해결을 우선한다.

이번 첫 범위는 페이지와 자료 검색을 넓혀 재현율을 올리는 것보다, 확인 가능한 출처 안에서 근거 손실을 찾고 안전하게 보완하는 데 우선순위를 둔다.

## 12. 성공 조건과 인수 기준

- [ ] 각 요청에서 검색 후보 수, 선택된 근거, 최종 전달 근거를 단계별로 구분해 확인할 수 있다.
- [ ] 검색 후보에 있던 근거가 선택 또는 최종 전달 과정에서 제외되면 해당 단계와 결과가 진단에 나타난다.
- [ ] 최초 규칙 근거 조회가 `NOT_FOUND`일 때만 같은 페이지 확장을 수행하고, 그 외에는 추가 조회하지 않는다.
- [ ] 선택된 근거의 정확한 위치를 사용해 같은 문서·같은 활성 추출 버전·같은 페이지의 추가 게시 근거만 한 번 조회한다.
- [ ] 허가되지 않은 문서, 과거 추출 버전, 다른 페이지의 근거가 결과에 포함되지 않는다.
- [ ] 같은 페이지 확장 뒤 기존 규칙 근거 조회를 한 번 재시도한다.
- [ ] 재시도도 `NOT_FOUND`이면 규칙을 만들어내거나 확정하지 않고 미해결 상태를 반환한다.
- [ ] 원문, 프롬프트, AI 응답 본문은 진단 기록에 남지 않는다.
- [ ] 진단으로 단계, 개수, 출처 식별 정보, 선택·제외 결정, 실패 종류와 소요 시간을 확인할 수 있다.
- [ ] 진단에서 로그에 남기지 않는 원문 값이 포함되지 않는지도 검증한다.
