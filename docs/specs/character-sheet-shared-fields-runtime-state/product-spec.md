# 제품 명세: 공통 캐릭터 시트 항목과 모험 중 상태

## 1. 문제와 배경

모험 준비 중 Solo Player는 현재 모험에 선택된 Rulebook(룰북)과 해당 모험에서 사용할 수 있는 Storybook(스토리북)의 근거를 함께 살펴 추가 캐릭터 항목을 추천받고, 파티의 캐릭터 시트에 넣을 항목을 선택한 뒤 각 PC의 값을 입력할 수 있어야 한다. 일부 캐릭터 시트를 이미 만들었더라도 이 과정은 동일하게 가능해야 한다. 모험이 시작된 뒤에는 임의의 직접 수정이 룰북에 근거한 상태를 덮어쓰지 않으면서, 해결된 게임플레이 결과가 캐릭터 시트에 일관되게 반영되어야 한다.

기존 D&D 5판 캐릭터 시트에는 종족·직업·배경 등 미리 정한 항목이 있다. 이번 기능은 그 항목을 대체하거나 룰북 전체를 처음부터 끝까지 분석해 새 시트를 만들지 않는다. 현재 모험의 Rulebook과 그 모험에 연결된 Storybook에서 관련 근거를 검색해 기존 시트에 더할 만한 항목을 추천한다. 각 추천에는 항목명, 필수 여부 판단, 출처를 확인할 수 있는 근거가 있어야 한다. 플레이어가 선택한 항목은 현재 준비 중인 모험의 모든 PC 시트에 적용한다. 이후 모험에는 자동 적용하지 않는다. 기존 저장 데이터의 마이그레이션은 범위에서 제외한다.

## 2. 목표와 기대 결과

- **G-01**: Solo Player가 룰북 근거가 확인되는 추가 캐릭터 항목의 제안을 살펴보고, 항목을 선택해 현재 준비 중인 모험의 모든 PC 캐릭터 시트에 적용할 수 있다.
- **G-02**: 이미 만든 시트를 포함해 모든 PC 캐릭터 시트가 같은 항목 구성을 유지하며, 갱신 중 실패가 발생해도 일부 시트에만 변경 사항이 적용되지 않는다.
- **G-03**: 룰북에 언급된 항목은 기본적으로 값 입력이 필수다. 룰북이 선택 사항이라고 명시한 경우에만 비워 둘 수 있으며, 필수 값이 하나라도 빠져 있으면 모험을 시작할 수 없다.
- **G-04**: 모험 시작 후 캐릭터 값은 해결되고 승인된 게임플레이 결과로만 바뀌며, 입력값이 바뀌면 파생 값도 다시 계산한다.
- **G-05**: 선택한 규칙에 명시된 부상 효과만 기계적 결과로 적용한다. 효과가 정의되어 있지 않으면 부상은 서술에 남기고 해결된 공격의 HP 피해만 적용한다.
- **G-06**: 추가 항목 추천 검색의 정확성을 고정된 질문, 예상 추천 결과, 출처 근거로 구성한 사례로 평가한다. 항목명 식별, 필수·선택 여부 판정, 출처 근거 일치를 각각 보고한다. 통과율 기준은 기준선을 측정한 뒤 Solo Player와 확정한다.
- **G-07**: 기존 D&D 5판 캐릭터 시트 항목에 더할 후보를 현재 모험의 Rulebook과 연결된 Storybook 양쪽에서 근거 검색해 추천한다. 추천은 전체 문서 추출이나 Game System Definition의 사전 추출 결과를 요구하지 않으며, 선택한 항목만 현재 모험의 모든 PC 시트에 적용한다.

## 3. 사용자와 참여자

- **Solo Player**: 추가 항목 제안을 살펴보고 선택하며, 시작 전에 PC별 값을 입력하고, 게임 안의 행동을 시작하고, 해결 결과를 확인한다.
- **AI Game Master**: 선택한 규칙에 따라 게임플레이를 진행하고 결과를 제안한다. 정본 캐릭터 시트에는 해결되고 승인된 결과만 반영된다.
- **Game System Definition (게임 시스템 정의)**: 준비와 게임플레이에 쓰이는 룰북 기반 캐릭터 항목과 적용 규칙을 제공한다.
- **Game System Review (게임 시스템 검토)**: 잠금 전에 캐릭터 시트 미리보기, 진단, 신뢰도, 출처 근거를 보여 주어 Solo Player가 선택한 룰북의 지원 내용을 검토하게 한다.
- **Shared Rulebook Catalog (공유 룰북 목록)**: Solo Player가 선택한 공개 Rulebook을 제공한다.
- **Bundle Lock (번들 잠금)**: 캐릭터 생성을 위해 번들의 룰북과 관련 준비 입력을 고정한다.
- **Adventure Start Lock (모험 시작 잠금)**: 모험 시작 시 파티와 런타임 구성을 고정한다. 시작 후 공통 캐릭터 시트 구성을 확장할 수 없다.
- **Runtime Rule (런타임 규칙)**: 적용 가능한 게임플레이 상태 변경을 결정한다.
- **Rule Support Severity (규칙 지원 심각도)**: 지원되지 않는 핵심 규칙이 승인을 막는지, 경고로 처리되는지를 기존 제품 규칙에 따라 나타낸다.
- **Character Management (캐릭터 관리)**: 준비와 플레이 중 캐릭터 시트 상태를 표시하고 유지한다.

## 4. 공통 용어

`CONTEXT.md`의 기존 용어를 사용한다: Solo Player, AI Game Master, Game System Definition, Game System Review, Shared Rulebook Catalog, Bundle Lock, Adventure Start Lock, Runtime Rule, Rule Support Severity, Character Management. 이 문서에서 **추가 캐릭터 항목**은 현재 모험의 Rulebook과 연결된 Storybook을 검색해 찾은 근거를 바탕으로, 기존 D&D 5판 캐릭터 시트에 더하도록 추천하는 공통 항목을 뜻한다. 이 항목은 이 작업에만 적용되며 프로젝트 공통 용어로 추가하지 않는다.

## 5. 주요 사용 사례

### UC-01 — 룰북 근거가 있는 추가 캐릭터 항목을 살펴보고 적용하기

**주 사용자:** Solo Player

**시작 조건:** Solo Player가 Shared Rulebook Catalog에 공개된 Rulebook을 선택했다. 현재 모험은 아직 준비 중이며 시작하지 않았다. 기존 D&D 5판 시트와 현재 모험의 Rulebook·Storybook 검색 근거를 확인할 수 있다.

**기본 흐름:**

1. 현재 모험에 설정된 Rulebook과 그 모험에서 사용할 수 있는 Storybook을 검색 대상으로 정한다. 다른 소유자의 Storybook은 검색하지 않는다.
2. 검색은 두 문서 유형에서 캐릭터 시트에 더할 후보의 근거를 찾는다. 룰북 전체를 순차 분석하거나 모든 항목을 추출하지 않는다.
3. 추천 결과는 기존 D&D 5판 캐릭터 시트의 미리 정한 항목을 유지한 채 추가 후보로 제시한다. 각 후보에 이름, 필수·선택 판단, 근거 문서 유형과 위치를 함께 보여 준다.
4. 고정 평가 사례로 후보 이름, 필수 여부, 출처 근거가 맞는지 측정하고 기준선을 보고한다. 통과율 기준은 기준선을 확인한 뒤 정한다.
5. Solo Player는 근거를 확인하고 추가할 후보를 선택한다.
6. 선택한 항목을 이미 만든 PC를 포함해 현재 준비 중인 모험의 모든 PC 시트에 한 번에 적용한다. 한 시트라도 실패하면 전체 적용을 취소하고 이유와 재시도 방법을 안내한다.
7. 각 PC의 필수 값을 따로 입력한다. Rulebook이 항목을 정하고 선택 사항이라고 명시하지 않았다면 값은 필수다. Storybook은 세계관상 추가 항목의 근거가 될 수 있지만, 출처에 없는 게임 규칙이나 기본값을 만들어 내지 않는다.
8. 모든 PC의 필수 값이 입력되면 모험을 시작할 수 있다. 누락된 값이 있으면 모험 시작을 막고 해당 PC와 항목을 표시한다.

**실패 흐름:** 어느 PC 캐릭터 시트의 갱신이라도 실패하면 어떤 PC 시트도 갱신하지 않는다. 실패 이유와 재시도 방법을 Solo Player에게 보여 준다. 재시도에 성공할 때까지 선택한 변경 사항은 적용되지 않은 상태로 둔다.

**완료 후 상태:** 현재 모험의 모든 PC 캐릭터 시트가 선택된 공통 항목 구성을 공유하고, 각 PC는 별도 값을 가진다. 같은 설정이나 Rulebook을 사용하는 다음 모험에도 추가 항목을 자동으로 가져오지 않는다. 모험이 시작되면 공통 구성을 고정한다.

### UC-02 — 캐릭터 상태를 바꾸는 게임플레이 결과 해결하기

**주 사용자:** Solo Player

**지원 역할:** AI Game Master

**시작 조건:** 모험이 시작되어 Adventure Start Lock이 파티와 런타임 구성을 고정했다.

**기본 흐름:**

1. Solo Player가 게임 안의 행동을 시작하거나 AI Game Master가 적용 가능한 Runtime Rule에 따라 게임 이벤트를 해결한다.
2. 게임플레이 결과가 해결되고 승인된 뒤에만 캐릭터 시트가 바뀐다.
3. 적용 가능한 캐릭터 값이 갱신된다. 규칙에 따라 HP, 자원, 상태, 부상, 아이템 획득·사용·상실, 화폐 변화, 새 기술이나 능력의 획득 같은 레벨 진행이 포함될 수 있다.
4. 입력값이 바뀌면 파생 값을 다시 계산한다.
5. Solo Player에게 결과 캐릭터 상태를 보여 준다. 적용 여부는 선택한 규칙에 따르며, 예시가 모든 시스템에 해당 값이나 이벤트가 있음을 뜻하지는 않는다.

**부상 규칙:** 눈 부상 같은 부상에 대해 구체적인 기계적 결과를 적용하는 경우는 Rulebook이 그 결과를 정의할 때뿐이다. 정의가 없으면 부상을 서술에 남기고 해결된 공격에서 발생한 HP 피해만 적용한다. 근거 없이 지속되는 능력치 감소나 다른 기계적 페널티를 추가하지 않는다.

**거부되는 요청:** 모험 시작 후 캐릭터 시트 값을 임의로 직접 수정하려는 요청은 거부하며 상태를 바꾸지 않는다. Solo Player는 아이템 사용이나 화폐 소비 같은 게임 안의 행동을 시작할 수 있지만, 시트는 그 행동의 해결 결과로만 바뀐다.

**완료 후 상태:** 캐릭터 시트는 선택한 규칙에 따라 해결되고 승인된 게임플레이를 반영하며, 시작 후 직접 수정 요청으로 상태가 바뀌지 않았다.

## 6. 업무 규칙과 불변 조건

- **BR-11 — 근거 검색과 추가 추천:** 현재 모험에 선택된 Rulebook과 연결된 Storybook의 기존 검색 기능을 사용해 관련 근거를 찾는다. 룰북 전체를 전수 분석하거나 모든 항목을 Game System Definition에 추출·보존하지 않는다. 기존 D&D 5판 시트의 미리 정한 항목은 유지하고 추천된 추가 항목만 선택적으로 더한다. Storybook 검색은 현재 모험과 소유자 권한으로 제한한다. (G-01, G-07, UC-01)
- **BR-12 — 추천 정확성 평가:** 고정 질문, 예상 추천 항목, 필수 여부 정답, Rulebook/Storybook 출처 근거를 사례로 관리한다. 실제 추천 검색 흐름의 항목명 식별, 필수 여부 판정, 출처 일치 결과를 각각 측정해 먼저 기준선을 보고한다. 통과율 기준은 결과를 확인한 뒤 정하며 이 명세에서 수치를 미리 정하지 않는다. (G-06, UC-01)

- **BR-01 — 출처 근거:** 현재 모험의 Rulebook과 연결된 Storybook에서 확인 가능한 근거가 있는 추가 항목만 제안하며 문서 유형·위치·발췌를 확인할 수 있게 한다. (G-01, UC-01)
- **BR-02 — 현재 모험에만 적용:** 선택한 추가 항목을 이미 만든 시트를 포함해 현재 준비 중인 모험의 모든 PC 시트에 적용한다. 이후 모험에는 자동 적용하지 않는다. (G-01, G-02, UC-01)
- **BR-03 — 전체 적용 또는 미적용:** 어느 PC 시트의 갱신이라도 실패하면 어떤 시트에도 해당 항목을 반영하지 않으며, 실패 이유와 재시도 방법을 보여 준다. (G-02, UC-01)
- **BR-04 — 기본 필수:** Rulebook이 언급한 항목은 Rulebook이 선택 사항이라고 명시하지 않는 한 필수다. 기본값을 만들어 내지 않는다. 필수 값은 PC별로 따로 입력한다. (G-03, UC-01)
- **BR-05 — 시작 조건:** PC별 필수 값이 하나라도 누락되면 모험을 시작할 수 없다. (G-03, UC-01)
- **BR-06 — 구성 고정 시점:** 시트를 만든 뒤에도 준비 중에는 공통 항목을 추가할 수 있지만, 모험이 시작되면 공통 캐릭터 시트 구성을 고정한다. (G-02, UC-01)
- **BR-07 — 게임플레이 결과만 반영:** 모험 시작 후 캐릭터 값은 선택한 규칙에 따른 게임플레이 결과가 해결되고 승인된 경우에만 바뀐다. 직접 수정은 거부하며 상태를 유지한다. (G-04, UC-02)
- **BR-08 — 파생 값:** 입력값이 바뀌면 파생 값을 다시 계산한다. (G-04, UC-02)
- **BR-09 — 부상 근거:** 부상의 기계적 결과는 Rulebook이 정의한 경우에만 적용한다. 정의가 없다면 부상을 서술에 남기고 해결된 공격의 HP 피해만 적용한다. (G-05, UC-02)
- **BR-10 — 게임 안의 행동:** 플레이어는 캐릭터 상태에 영향을 줄 수 있는 행동을 시작할 수 있다. 시트는 승인된 해결 결과에 따라서만 바뀐다. (G-04, UC-02)

### 추가 공통 캐릭터 항목

- **미선택** → Solo Player가 출처를 확인할 수 있는 제안을 선택하면 **추가 선택됨**.
- **추가 선택됨** → 모든 시트 갱신에 성공하면 **현재 모든 PC 시트에 적용됨**.
- **추가 선택됨** → 어느 시트 갱신이든 실패하면 **미적용, 재시도 가능**. 일부 시트에는 변경 사항이 보이지 않는다. 재시도에 성공하면 **현재 모든 PC 시트에 적용됨**으로 전이한다.
- **모험 준비 중** → 모험이 시작되면 **공통 구성 고정**. 이 전이 이후에는 공통 항목을 추가할 수 없다.

### 필수 값과 모험 시작

- 필수 캐릭터 항목은 해당 PC의 값이 입력될 때까지 **누락**, 입력된 뒤에는 **입력됨** 상태다.
- 필수 값이 하나라도 누락된 동안 모험은 **시작 불가** 상태다. 모든 PC의 필수 값이 입력되면 **시작 가능** 상태로 전이할 수 있다. 시작하면 모험을 시작된 상태로 전이하고 공통 구성을 고정한다.

### 플레이 중 캐릭터 상태

- 시작 후 직접 수정 요청은 거부되며 캐릭터 값은 바뀌지 않는다.
- 해결되고 승인된 게임플레이 결과는 선택한 Runtime Rule에 따라 해당 캐릭터 상태를 전이시키며, 영향을 받은 파생 값도 다시 계산한다.
- Rulebook이 부상의 결과를 정의하면 그 결과를 적용한다. 정의가 없으면 부상은 서술에 남기고 해결된 공격의 HP 피해만 기계적으로 적용한다.

## 8. 실패, 예외와 경계 조건

- 제안에 확인 가능한 Rulebook 또는 현재 모험에 연결된 Storybook 근거가 없으면 근거가 있는 제안으로 제공하지 않는다. (BR-01)
- 추가 항목은 기존 D&D 5판 시트에 더할 수 있도록 현재 모험의 Rulebook과 연결된 Storybook 검색 결과에서 추천한다. 룰북 전체 추출이나 Game System Definition 사전 추출을 요구하지 않는다. (BR-11)
- 추천 시점에 기존 검색 기능으로 Rulebook과 Storybook 근거를 찾으며, 문서 전체를 전수 분석하지 않는다. Storybook은 현재 모험과 소유자 권한 범위로 제한한다. (BR-11)
- 추천 정확성 평가 사례는 고정 질문, 예상 추천 항목, 필수 여부 정답, Rulebook/Storybook 출처 근거를 포함하고 실제 추천 검색 흐름의 항목명 식별, 필수/선택 여부 판정, 출처 근거 일치를 평가해야 한다. 통과율은 기준선 측정 후 Solo Player와 확정하며, 그 전에는 수치 기준을 가정하지 않는다. (BR-12)
- 어느 PC 시트 갱신이라도 실패하면 이유와 재시도 방법을 알리고, 전체 적용이 가능해질 때까지 어떤 시트에도 새 항목을 반영하지 않는다. (BR-03)
- 어느 PC의 필수 값이라도 누락되면 누락 값을 표시하고 모험 시작을 막는다. 선택 사항 여부는 Rulebook에 명시되어야 한다. (BR-04, BR-05)
- 모험 시작 후에는 공통 항목 추가나 캐릭터 값 직접 수정을 거부한다. 직접 수정 거부 시 시트 상태는 바뀌지 않는다. (BR-06, BR-07)
- 게임플레이 결과가 해결되고 승인되지 않았다면 캐릭터 시트를 바꾸지 않는다. (BR-07, BR-10)
- Rulebook이 부상의 기계적 결과를 정의하지 않으면 지속되는 페널티를 추론하거나 추가하지 않는다. (BR-09)
- HP, 자원, 상태, 아이템, 화폐, 기술, 능력 등의 예시는 선택한 규칙에 해당하는 경우에만 적용한다. (UC-02)

## 9. 입력과 출력

**입력:** 현재 모험의 Rulebook과 연결된 Storybook 검색 범위 및 출처 근거, 기존 D&D 5판 캐릭터 시트 항목, 추천 정확성 평가를 위한 고정 질문·예상 항목·필수 여부·출처 근거 사례, 제안된 항목에 대한 Solo Player의 선택, PC별 값, 모험 시작 요청, 게임 안의 행동, 적용 가능한 Runtime Rule에 따른 해결·승인 결과.

**출력:** 기존 D&D 5판 시트에 추가할 추천 항목과 Rulebook/Storybook 근거, 추천 흐름의 정확성 기준선 및 항목명·필수/선택·출처 일치별 결과, 기준선 결과를 바탕으로 확정할 통과율 기준, 현재 준비 중인 모든 PC의 공통 시트 구성 갱신, PC별 필수 값 상태와 모험 시작 가능 여부, 갱신 실패 이유와 재시도 안내, 승인된 게임플레이를 반영한 시작 후 캐릭터 상태 및 파생 값, 상태 변경 없이 직접 수정을 거부했다는 안내.

## 10. 범위와 제외 항목

**포함:** 기존 D&D 5판 시트 항목을 유지하면서 현재 모험의 Rulebook과 연결된 Storybook을 검색해 추가 항목 추천, 문서 유형·위치·발췌 근거 표시, 고정 질문·예상 항목·필수 여부·출처 근거 사례를 사용하는 추천 정확성 기준선 평가, 기준선 측정 후 통과율 기준 확정, 출처 확인, 플레이어 선택, 현재 준비 중인 모든 PC 시트에 적용, PC별 값과 필수 여부, 전체 적용 또는 미적용 처리, 필수 값 누락 시 시작 제한, 시작 후 게임플레이에 따른 시트 변경, 파생 값 재계산, 룰북에 명시된 부상 규칙 적용, 시작 후 임의의 직접 수정 거부.

**제외:** 룰북 전체를 처음부터 끝까지 분석하는 일, 모든 항목을 미리 추출해 저장하는 일, 기존 저장 데이터 마이그레이션, 기준선 측정 전에 통과율 수치를 정하는 일, 이 작업에 한정된 추가 항목을 다음 모험에 자동 적용하는 일, 기본값·규칙·부상 페널티를 만들어 내는 일, 모든 게임 시스템에 동일한 항목이나 게임플레이 예시가 있다고 보는 일, Solo Player가 Rulebook을 업로드하거나 공개하는 일. 현재 고정 슬롯 구현에는 두 문서 유형의 근거를 사용하는 추가 항목 추천이 없으므로, 이 명세는 기존 검색과 캐릭터 시트 준비 흐름을 확장하는 요구를 정의한다.

## 11. 우선순위와 상충 시 기준

추천은 기존 D&D 5판 시트 항목을 유지하면서 현재 모험의 Rulebook과 연결된 Storybook을 검색해 근거를 제시한다. 룰북 전체 추출은 하지 않는다. 추천 정확성 기준선은 고정 사례로 항목명, 필수 여부, 출처 근거 일치를 측정하며 통과율 기준은 결과 확인 뒤 정한다. 그 기준선과 기준 확정은 출처 근거에 따른 정확성과 모든 PC 시트의 일관성을 지키기 위한 우선 조건이다. 지원되지 않거나 임의인 수정은 허용하지 않는다. Rulebook의 근거를 확인할 수 있어야 한다. 필수 여부가 기본이며 선택 사항은 Rulebook의 명시가 있어야 한다. 게임플레이 상태 변경은 선택한 규칙을 따르며, 빠진 규칙을 추론으로 채우지 않는다. 준비 중에는 모험 시작 직전까지 공통 항목을 추가할 수 있고, 시작 후에는 공통 구성을 고정한다.

## 12. 성공 조건과 수용 기준

- **AC-11 (G-07, BR-11, UC-01):** 기존 D&D 5판 캐릭터 시트 항목은 유지되고, 추가 후보는 현재 모험의 Rulebook과 연결된 Storybook 검색 근거에서 추천된다. 룰북 전체를 분석하거나 모든 항목을 사전 추출하지 않는다.
- **AC-12 (G-07, BR-11, UC-01):** 후보마다 이름, 필수·선택 여부 판단, 문서 유형, 위치와 근거를 확인할 수 있다. Storybook 검색은 현재 모험에 연결되고 사용 권한이 있는 문서로 제한된다.
- **AC-13 (G-06, BR-12, UC-01):** 고정 질문·예상 추천 항목·필수 여부·Rulebook/Storybook 근거 사례로 실제 추천 흐름을 평가해 항목명, 필수/선택, 출처 근거 정확도를 각각 보고한다. 먼저 기준선을 측정하고 CI 통과율 기준은 이후 확정한다.

- **AC-01 (G-01, BR-01, BR-11, UC-01):** 준비 중 Solo Player는 기존 D&D 5판 항목에 추가할 후보를 Rulebook과 연결된 Storybook 근거와 함께 보고, 출처를 확인한 뒤 선택할 수 있다.
- **AC-02 (G-01, G-02, BR-02, BR-06, UC-01):** 모험 시작 전에 항목을 선택하면 먼저 만든 시트를 포함해 현재 준비의 모든 PC 시트에 추가된다. PC별 값을 따로 입력할 수 있으며, 같은 설정이나 Rulebook을 쓰는 이후 모험에는 자동으로 추가되지 않는다.
- **AC-03 (G-02, BR-03, UC-01):** 어느 PC 시트 갱신이 실패하면 어떤 PC 시트에도 새 항목이 보이지 않는다. Solo Player는 실패 이유와 재시도 안내를 받고, 재시도 성공 시 현재 모든 PC 시트에 적용된다.
- **AC-04 (G-03, BR-04, UC-01):** Rulebook에서 정한 항목은 Rulebook이 선택 사항이라고 명시하지 않는 한 필수로 처리된다. UI가 기본값을 임의로 채우지 않으며 값은 PC별로 입력한다.
- **AC-05 (G-03, BR-05, UC-01):** 어느 PC 시트든 필수 값이 빠져 있으면 모험 시작을 막고 누락 값을 표시한다. 모든 필수 값이 입력되면 기존의 다른 시작 조건을 충족하는 한 시작할 수 있다.
- **AC-06 (G-02, BR-06, UC-01):** Solo Player는 PC 시트를 하나 이상 만든 뒤에도 모험 시작 전까지 근거가 있는 공통 항목을 추가할 수 있다. 시작 후에는 공통 시트 구성을 확장할 수 없다.
- **AC-07 (G-04, BR-07, BR-10, UC-02):** 시작 후 임의의 직접 수정은 거부되고 거부 안내를 표시하며 캐릭터 시트 상태를 바꾸지 않는다. 게임 안의 행동은 계속 시작할 수 있고 시트는 그 행동의 해결·승인 결과로만 바뀐다.
- **AC-08 (G-04, BR-07, UC-02):** 해결되고 승인된 게임플레이 결과는 선택한 규칙에 해당하는 캐릭터 값을 갱신한다. 지원되는 예로 HP·자원·상태·부상, 아이템 획득·사용·상실, 화폐, 레벨 진행을 포함할 수 있지만, 해당하지 않는 예시가 모든 시스템에 적용된다고 보지 않는다.
- **AC-09 (G-04, BR-08, UC-02):** 승인된 결과로 파생 값의 입력이 바뀌면 해당 파생 값을 다시 계산해 일관되게 표시한다.
- **AC-10 (G-05, BR-09, UC-02):** 부상의 기계적 결과가 Rulebook에 정의되어 있으면 그 결과를 적용한다. 정의가 없으면 서술에 부상을 남기고 해결된 공격의 HP 피해만 시트에 반영하며, 지속되는 능력치 감소나 다른 기계적 페널티를 만들어 내지 않는다.

### 제품 다이어그램 목록

변경된 두 사용자 흐름은 링크된 UC-01과 UC-02 사용 사례 및 활동 흐름 다이어그램으로 표현한다. 추가 항목 추천과 정확성 평가는 UC-01의 일부이며, Solo Player의 상호작용 흐름을 별도로 만들지 않으므로 새 다이어그램은 필요하지 않다. 별도 업무 상태 다이어그램도 적용하지 않는다. 독립된 결정 사항이 두 사용자 흐름에 모두 표현되어 있으며, 별도로 업무 상태를 검토할 필요가 없기 때문이다.
