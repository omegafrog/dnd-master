# 요청 원문

> 롤20같은 다른 서비스들을 참고해서 플레이어의 이동을 어떻게 하는지 알고싶은데? 지금 턴 사이에 플레이어 이동을 하고, 이동을 하는 도중에 GM 서술이 들어가는 경우가 있잖아
>
> 맞아. 그렇게 해야돼. 그러면 스펙을 수정하자. [$spec-me] 로 해당 기능 변경사항 반영할거야

## 확인된 사용자 요구

- 플레이어가 자기 차례에 캐릭터를 직접 이동하고, 이동 도중 필요한 GM 서술이 이어지는 흐름을 명세에 반영한다.
- 기존 전투 이동·주문 사거리 범위의 Product Spec을 수정한다.
- 이동 중단 사건의 GM 판정·서술은 기존 전투/비전투 응답을 재사용하지 않고 전용 고정 계약으로 명세한다.
