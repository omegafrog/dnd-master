> 선택지마다 판정값 포함

## plan-368 전투 토큰 전환 승인 원문 (2026-10-23)

질문 원문:

> 이 규칙으로 명세를 확정할까요? 그룹 토큰 위치를 기준으로 가장 가까운 적 방향을 대열 앞쪽으로 하고 FRONT→MIDDLE→REAR 순서로 서로 다른 유효 칸에 둡니다. 가까운 적이 없으면 북쪽, 방향 동률은 서버 식별자 순서를 씁니다. 전 칸을 한 번에 확보할 수 없으면 지도는 바꾸지 않고 대기 상태를 저장해 Solo Player가 기존 전투 지도 화면에서 전체 배치를 고른 뒤 재개합니다. 지도 소유자는 제출한 화면의 지도 버전이 최신인지 검증합니다. 진입·종료 변환은 지도 서비스의 단일 멱등 작업으로 저장해 중복·부분 변환을 막고, 종료 후 그룹 토큰은 FRONT 캐릭터 위치로 복원합니다.

사용자 답변 원문:

> 권장안 승인

원문의 `FRONT`·`MIDDLE`·`REAR`는 기존 대열 저장값인 전열·중열·후열이다. 위 질문과 답변이 사용자 명시 승인 범위다. 깊이 0·1·2, 수직 옆 간격 0, -1, +1, … 및 같은 대열의 식별자 순서는 이후 승인된 동작을 결정적으로 구현하기 위한 기계적 설계 선택이며, 사용자가 해당 수치까지 직접 승인한 원문은 아니다. 상세 설계는 Architecture Spec과 `runtime-decisions.md`에 기록한다.
