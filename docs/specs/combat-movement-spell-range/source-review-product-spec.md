# 공용 룰북 전처리 페이지 관리자 검토 보충 제품 계약

이 계약은 [#376](https://github.com/omegafrog/dnd-master/issues/376)의 승인된 선행 복구에만 적용한다. 기존 [제품 명세](product-spec.md)의 플레이어 모험 준비 요구와 사용자가 지정한 `DnD_BasicRules_2018.pdf` 원본 경계는 유지한다.

- 관리자는 공용 룰북 목록의 등록 건에 속한 문서에 한해 검토 대기 페이지, 읽기 순서 후보, 원본 페이지의 내용을 확인한다. PDF 23, 31, 35, 48, 51, 52, 55, 57, 111, 178쪽이 현재 재현 대상이다.
- 관리자는 실제 원본 PDF와 대조한 후보를 선택하고 확인을 명시한 뒤 해당 페이지를 재시도한다. 시스템은 확인한 관리자, 페이지, 후보, 등록 문서와 추출 버전을 남긴다. 오래되거나 존재하지 않는 후보와 다른 등록 문서의 페이지는 거부한다.
- 일반 사용자의 개인 문서는 기존 소유자만 검토한다. 관리자용 기능은 인증된 목록 관리자에게만 허용하며 문서 소유자를 바꾸거나 타인의 ID로 접근하지 않는다.
- 수동 확인은 애매한 열·읽기 순서와 낮은 통계 신뢰도의 판단에만 사용한다. 자동 신뢰도 기준, 글자 완전성·좌표·원본 근거 등 내용 무결성 검사는 그대로 실행한다. 남은 오류가 있으면 검토 대기를 표시한다.
- 등록한 PDF의 바이트와 해시, 문서 및 추출 버전 식별자는 보존한다. 주문 목록인 PDF 87~110쪽의 출처나 항목을 이 복구에서 바꾸지 않는다.

검증: 인증 실패와 권한 없는 접근, 관리자 조회·확인·재시도, 다른 등록 건/오래된 후보 거부, 내용 오류의 검토 대기, 원본 해시와 버전 보존을 확인한다.
