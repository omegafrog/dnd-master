- 범위 ID: `combat-movement-spell-range`
- 문서 상태: **READY** — 요구사항 범위 추적 및 Product 다이어그램 검토 완료
- 대상: 모험 내 능력 습득, 그룹 탐험 이동, 전술 이동, 조우, 전투 이동·행동·주문 및 자원
- 결정 출처: 기존 Product 결정과 `runtime-decisions.md`의 2026-10-17 사용자 합의; BR-44·BR-45·AC-36의 전투 배치·복구는 2026-10-23 plan-368 사용자 승인 결정

## 1. Problem and Context

전술 지도에서 이동, 주문, 원거리 공격과 투척을 처리할 때, 플레이어는 이동 가능량, 지형, 벽과 문, 점유, 행동 시점, 사거리, 시야와 효과 범위를 함께 판단해야 한다. 규칙에 근거한 전투 행동 미리보기와 실행 전 검증이 없으면 이동·공격·시전 가능 여부를 잘못 판단하거나, 대상 지정과 범위 효과가 각 행동 정의를 따르지 않을 수 있다.

모험 진행에는 그룹별 탐험 위치, 상황의 맵 필요 여부, 위협·사건 처리, 전투 토큰별 이동과 능력 자원이 함께 관여한다. 능력 상세 규칙은 모험 시작 전에 이미 캐릭터가 가진 능력을 모험 시작 시 준비하고, 이후 새 능력을 배울 때 습득 흐름에서 준비한다.

룰북이나 시나리오 묶음의 전체 능력을 미리 추출·검토하지 않는다. 준비 대상은 캐릭터 시트의 실제 능력 식별자로 한정한다. 현재 모험에 이미 저장된 정의는 재사용하며 다시 검색하지 않는다.

## 2. Goals and Desired Outcomes

- **G-01 — 시트 보유 능력의 근거 있는 정의:** 파티와 적 캐릭터 시트에 실제로 있는 능력만 정의하고, 원문 출처 위치를 보존한다.
- **G-02 — 모험별 능력 정의:** 각 능력의 고정 구조 정의는 현재 모험에만 저장하며 모험 시작 시 초기 능력과 이후 새 능력을 배울 때 필요한 정의를 준비한다.
- **G-03 — 규칙에 맞는 이동:** 이동 시점, 속도와 남은 이동량, 경로 비용, 지형·점유·상태 조건을 반영한다.
- **G-04 — 안전한 미리보기와 실행:** 전투 행동 미리보기는 읽기 전용이며 숨겨진 정보를 노출하지 않는다. 확정 시 최신 상태를 다시 확인하고, 오래된 요청은 비용 없이 거부한다.
- **G-05 — 주문 규칙을 충실히 표현:** 시전 시간, 자원, 구성요소, 집중, 지속시간, 발동 조건, 공격·내성·자동 효과와 주문별 예외 및 더 높은 등급의 주문 슬롯 사용에 따른 변화를 출처 규칙대로 처리한다.
- **G-06 — 위치 표현 확장:** 평면 지도와 수치 지면으로부터의 높이를 사용해 비행, 거리, 장애물, 효과 포함 여부를 다룬다. 3차원 지도 편집은 포함하지 않는다.
- **G-07 — 입력 방식 일관성:** 지도 조작과 자연어 선언은 같은 규칙 검증과 숨김 정보 경계를 따른다.
- **G-08 — 자료 기반 조준:** 주문·원거리 공격·투척이 캐릭터 토큰 기준의 같은 지도 조준 흐름을 사용하고, 사거리·형상·차단 특성을 룰북 출처가 연결된 정의 자료만으로 추가·조정·비활성화할 수 있다.
- **G-09 — 그룹 탐험 이동:** 그룹 토큰과 대열을 사용하고, 사건 발생 시 이동을 멈춰 해결한 뒤 경로를 다시 확인한다.
- **G-10 — 순차 전술 이동:** 맵이 필요한 비전투 상황에서 그룹 우선권에 따라 순차 이동하고 매 순환 6초의 환경 변화를 처리한다.
- **G-11 — 결정적 자원 처리:** 능력 비용, 소모 시점, 캐릭터별 현재량·최대량과 회복 조건을 일관되게 적용한다.

## 3. Users and Actors

- **A-01 Solo Player:** 유일한 인간 사용자. 모험 파티의 모든 캐릭터를 직접 조종하며 이동·전투 행동·능력 습득·캐릭터 시트 설정과 수정 결정을 선택하고 확정한다.
- **A-02 AI Game Master:** 세계와 NPC·적을 조종하고, 장면·규칙 판정·결과를 서술한다. 파티 캐릭터의 선택이나 실행을 대신하지 않으며, 선택된 능력의 근거 있는 상세정보만 준비해 제공한다. 파티의 일상 대화와 대사를 생성할 수 있다.
- **A-03 적:** AI Game Master가 조종하는 적 전투 참가자. 동일한 런타임 규칙을 따르며, 내부 수치는 공개 필터를 따른다.
- **A-04 모험 진행 규칙:** 상황에 따라 맵을 준비하고, 배운 능력의 정의·자원 및 출처를 제공한다.

## 4. Ubiquitous Language and Terminology

- **기본 룰북:** `CONTEXT.md`의 `RULEBOOK`. 이번 범위에서는 D&D 5판(2014) Basic Rules다.
- **추가 룰북:** `CONTEXT.md`의 `STORYBOOK` 등 기본 룰북 외에 선택된 규칙·시나리오 자료.
- **능력 상세 정의:** 파티나 적이 배운 주문·기술 하나의 고정 구조 설명. 사용 조건, 비용, 사거리·대상·효과·판정·지속·예외와 원문 출처 위치를 포함한다. 적용되지 않는 항목은 비어 있음을 명시한다.
- **규칙 근거:** 구조화된 주문·행동 정의 또는 판정이 유래한 자료의 출처 참조.
- **주문 효과 범위:** 주문의 규칙이 지정한 대상 또는 공간에 적용되는 범위. 주문의 모양이나 투사체 외형만으로 결정하지 않는다.
- **시전 거리:** 시전자가 주문 대상을 지정할 수 있는 거리에 관한 규칙.
- **대상 가시성:** 주문이 요구하는 시야 조건.
- **명확한 경로와 엄폐:** 시전자와 대상 또는 효과 사이에 적용되는 경로·엄폐 규칙.
- **지면으로부터의 높이:** 평면 전술 지도의 위치와 함께 기록하는 수치 높이. 비행 이동, 대상까지의 거리, 장애물 차단, 주문 효과 범위에 포함되는지 판정하는 데 사용한다.
- **전투 행동 미리보기:** 이동 또는 주문·원거리 공격·투척을 선택한 뒤 마우스 위치에 따라 경로·비용·사거리·효과 범위와 공개된 대상을 보여주는 읽기 전용 표시. 주문·원거리 공격·투척의 경로 칸은 붉게 표시한다. 위치·자원·전투 상태를 바꾸지 않으며 미공개 정보를 드러내지 않는다.

## 5. Core Use Cases

### UC-001 모험에 필요한 능력 정의를 준비하고 조회한다

1. Solo Player가 파티 캐릭터의 초기 시트 설정과 능력 선택을 확정하면, 모험 시작 시 파티원의 캐릭터 시트에서 확정된 능력 ID만 모은다. 해당 ID 중 현재 모험에 정의가 없는 능력만 준비한다. 모든 능력 목록이나 ScenarioPackage 전체를 훑지 않는다.
2. 모험 중 Solo Player가 파티 캐릭터의 새 능력 습득을 선택·확정하면 습득 완료 전에 같은 준비 절차를 수행한다. 정의가 없을 때 현재 세션의 허가된 자료만 검색하고, 기본 룰북과 적용되는 추가 자료는 각각 독립 검색한다.
3. 고정 구조·스키마·출처 위치를 검증한다. 근거 부족·충돌·검색 또는 구조화 실패는 재시도·복구하고, 최후에는 원문 입력을 요청한다. 검증한 정의만 현재 모험에 저장한다. 새 능력의 원문 입력 취소 시 습득은 완료되지 않는다.
4. GM MCP 조회는 요청 캐릭터 시트에 실제로 배운 능력 ID만 허용하고, 현재 모험에 저장된 정의 또는 명시적 상태만 반환한다.

### UC-002 이동·행동·주문을 미리 보고 실행한다

1. Solo Player는 파티의 행동할 캐릭터를 정하고 이동, 주문, 원거리 공격 또는 투척을 선택한다. 자연어 선언도 같은 규칙 검증으로 처리한다.
2. 플레이어 캐릭터의 전투 턴에는 행동 전·사이·후에 이동을 이어 쓸 수 있다. Solo Player가 캐릭터 토큰을 클릭·드래그해 경로를 정하고 확인하면 실제 이동을 한 칸씩 반영한다.
3. 주문·원거리 공격·투척은 선택 후 캐릭터 토큰에서 커서까지의 사거리와 경로를 미리 본다. 경로에 해당하는 지도 칸은 붉은색으로 표시한다. 대상이 하나이고 선택만으로 충분하면 클릭으로 실행한다.
4. 정의된 효과 모양이 있는 경우 룰북 근거에 맞는 원뿔·정육면체·원기둥·선·구 등의 효과 칸을 함께 표시한다. 효과의 모양과 경로 차단·확산 규칙은 해당 행동 정의를 따른다.
5. 마법 화살 같은 대상 지정 주문은 유효한 대상을 보여준다. 여러 대상이나 투사체 배분이 필요한 경우 대상·배분을 선택한 뒤 명시적으로 시전한다.
6. 주문 효과 범위의 전투 행동 미리보기는 아군이 영향을 받을 수 있음을 알리지만 별도 확인 단계를 추가하지 않는다. 실제 영향 대상은 주문별 대상 지정 규칙으로 정한다.
7. 실행 시점에 최신 상태를 다시 확인한다. 상태가 바뀌어 실행할 수 없으면 비용 없이 실패 처리하고 화면을 갱신한다.
8. 이동 중 새 적 발견, 함정, 반응처럼 GM 처리가 필요한 사건에 도달하면 해당 칸에서 멈추고 실제 토큰 위치와 이미 소비한 이동량을 보존한다. GM이 사건을 판정·서술한 뒤 Solo Player의 다음 입력을 기다린다.
9. Solo Player는 이동량이 남고 규칙이 허용하면 새 경로를 확인해 이동을 이어 가거나, 다른 가능한 행동을 하거나, 명시적으로 턴을 종료한다. 멈춘 경로의 나머지는 자동 실행하지 않으며 GM의 서술만으로 턴을 끝내거나 플레이어 토큰을 옮기지 않는다. (BR-05, BR-08, BR-16, BR-18, BR-19)

### UC-004 주문 효과를 환경에 응용한다

1. Solo Player는 주문을 선언할 때 주문 효과를 주변 환경에 응용하려는 뜻을 함께 말할 수 있다. 별도의 시전 후 입력 단계는 요구하지 않는다.
2. 추가 응용을 계획하기 전에 AI Game Master는 현재 사용 가능한 환경 작업, 각 작업의 입력 형식과 제약을 받는다.
3. AI Game Master는 제공된 목록에 있는 작업만 골라 조합한다. 목록에 없는 작업은 호출하지 않으며, 임의 코드를 만들어 실행하지 않는다. 예를 들어 물을 만들어 함정을 무력화하려는 시도를 검토할 수 있지만, 모든 함정이 물에 취약하다고 가정하지 않는다.
4. 환경 작업의 호출이 실패하면 오류 내용이 AI Game Master에 전달된다. AI Game Master는 오류를 참고해 입력이나 작업 선택을 고쳐 재시도할 수 있다. 재시도 횟수의 고정 한도는 정하지 않는다.
5. 판정이 필요하면 AI Game Master는 기존 플레이어 굴림 제출 흐름으로 굴림을 요청한다.
6. 추가 환경 응용이 실패해도 이미 적용된 주문 기본 효과와 소비된 자원은 유지하고, 실패한 응용만 실패로 처리한다. 재시도는 기본 주문 효과를 다시 실행하거나 기본 비용을 다시 소비하지 않는다.
7. 제안·호출·판정은 플레이어가 알지 못하는 함정·상태 등 숨겨진 정보를 공개하지 않는다.
8. 추가 환경 응용이 실패하고 플레이어가 관찰할 추가 변화가 없으면 그 실패나 숨겨진 내부 상태를 서술하지 않고 넘어갈 수 있다. 이미 적용된 주문 기본 효과와 소비한 자원은 기존 UI 규칙에 따라 플레이어에게 보인다. 숨겨진 함정 상태나 내부 실패 사유는 공개하지 않는다.

### UC-003 지도를 확대하고 위치 관계를 확인한다

1. Solo Player는 모험 시작 후 지도를 확대하거나 축소한다.
2. 포인터, 범위 겹침과 화면 오버레이는 확대 배율에 맞춰 지도 위치와 일치한다.
3. 비행 위치는 평면 위치와 수치 지면으로부터의 높이로 표현하고 거리, 장애물 및 주문 효과 포함 여부를 판단한다.

### UC-005 그룹으로 탐험하고 사건을 해결한다

1. Solo Player가 파티의 그룹 구성·이동 경로를 선택하고 확인한다. GM은 파티의 이동을 선택하거나 실행하지 않는다.
2. 그룹은 구성원, 위치, 전열·중열·후열을 가지며 탐험 지도에서 토큰 하나를 사용한다. 그룹 속도는 가장 느린 구성원 기준이다.
3. 시츄에이션 진입 시 저장된 `mapNeeded` 속성으로 지도 필요 여부를 결정한다. 맵이 필요한 경우 시작 위치를 먼저 제안하고, 대상 시츄에이션의 진입 서술·관련 근거·지도와 대조한다. 제안 위치가 이에 맞지 않으면 진입을 보류하고, 일치하는 시작 위치가 확인된 뒤에만 진입 서술을 저장·공개한다. 맵이 필요하지 않으면 지도 준비를 건너뛴다.
4. 이동 중 위협 발견 여부를 캐릭터별로 판정한다. 발견 가능한 대열 위치, 지각 능력, 이동 방식과 숨김 상태를 반영한다. 발견한 캐릭터만 먼저 그 사실을 안다. 발견한 캐릭터가 동료에게 알리면 그룹도 알게 되며, 알리는 소리가 적에게 들리는지는 상황에 따라 GM이 판정한다.
5. 적이 먼저 일행을 발견하면 GM이 적의 행동을 정해 서술하고 사용자가 대응한다. 위협을 발견한 것만으로 전투를 시작하지 않는다. 조우한 쪽은 공격·대화·도주·대기를 선택할 수 있다.
6. 함정·발견 등 이동을 멈춰야 할 사건이 생기면 해당 위치에서 모든 그룹 이동을 중단하고 사건을 해결한다. 적대 행동으로 전투가 시작되면 위협을 알아차리지 못한 개체만 기습 상태가 될 수 있다. 양쪽 모두 숨으려 하지 않았다면 서로 자동으로 알아차린다. 비전투 사건 뒤에는 남은 경로를 자동 실행하지 않고 경로를 다시 확인한다.
7. 그룹은 명시적으로 나누거나 합칠 수 있다. 나누면 현재 위치에서 새 그룹과 대열을 정하고 각자 경로를 지정한다. 합치기는 명시적 선택으로만 한다.
8. 맵이 필요한 비전투 상황은 세계 시간을 멈추고 그룹 우선권에 따라 차례로 이동한다. 각 그룹은 토큰을 클릭·드래그해 경로를 정하고 확인한 뒤 한 칸씩 이동한다. 모든 그룹이 움직이면 환경을 6초 진행하며 적·순찰의 이동과 감지, 함정·환경 효과, 지속시간·제한 시간 갱신 순서로 처리한다. 조우가 생기면 환경 처리를 멈춰 해결한 뒤 남은 환경 단계를 이어간다. 이동 사건이 전투가 아닌 경우 해당 그룹 차례를 끝내고 다음 그룹부터 진행한다.
9. 전투가 시작되면 각 탐험 그룹 토큰 위치를 기준으로 가장 가까운 적 방향을 전열 방향으로 삼아 전열·중열·후열 순서로 서로 다른 유효 칸에 개인별 토큰을 배치한다. 적이 없으면 북쪽을 사용하고, 거리 동률은 서버 식별자로 결정한다. 전원을 배치할 수 없으면 지도를 그대로 두고 배치 대기를 저장한다. GM이 전원의 유효한 배치를 정한 뒤에만 전환을 재개한다. 전투 진입·종료의 토큰 교체는 각각 한 번에 적용하며 재시도·재시작으로 일부만 바뀌거나 중복 생성되지 않는다. 전투 종료 후 기존 그룹 구성·대열을 복원하고 그룹 토큰은 전열 캐릭터의 현재 칸에 둔다. 별도 그룹은 자동 병합하지 않는다. #367의 적 토큰·전투 참여자 대응과 개체별 인지·첫 차례 기습 상태는 유지한다.
### UC-006 파티 대화를 진행하고 중요한 선택을 확인한다

1. 파티가 일상 대화를 나누는 상황에서 AI Game Master는 파티 캐릭터들의 대사와 상호작용을 생성한다. 이 대사는 파티 상태를 바꾸지 않는다.
2. 대화가 전투 행동, 자원 소모, 그룹 분리·합류, 퀘스트 또는 관계의 방향을 결정하게 되면 AI Game Master는 진행을 멈춘다.
3. 동료의 중요한 대화 선택은 AI Game Master가 선택지를 제시하거나 Solo Player의 자연어 제안을 받는다. 자연어 동료 대화 제안은 현재 맥락에서 확인되는 해당 동료의 가치관·성격 묘사와 충돌하는지 검사한다.
4. 자연어 제안이 충돌하면 AI Game Master는 동료가 그 행동을 하지 않을 것이라고 설명하고, 그 대화 행동은 실행하지 않은 채 다른 선택을 기다린다. 충돌하지 않으면 Solo Player가 선택하거나 제안한 내용대로 대화를 진행한다. 현재 맥락에 근거가 없는 가치관은 덧붙이지 않는다.
5. 동료 대화 선택과 파티 행동 명령은 별개다. Solo Player는 파티 행동을 직접 선택·확정하고, 이 행동에는 동료 대화의 맥락 충돌 검사를 적용하지 않는다. AI Game Master는 확정된 행동의 규칙 결과를 판정·서술하고 런타임은 그 결과를 반영하며, 결과 반영마다 Solo Player의 추가 승인을 요구하지 않는다.

## 6. Business Rules and Invariants

- **BR-01:** 대상 능력은 파티 또는 적이 배우거나 보유한 주문·기술로 한정한다.
- **BR-02:** 능력 정의는 필요한 규칙 항목마다 근거 출처 위치를 연결하고 고정 구조를 충족해야 한다.
- **BR-03:** 상세 정의를 준비할 수 없는 능력은 사용하지 않는다. 근거가 해결되지 않으면 원문 입력을 요청하고, 비활성 능력은 비용 없이 거부한다.
- **BR-04:** 상세 정의 저장 범위는 현재 모험으로 한정하며 다른 모험에 자동 공유하지 않는다.
- **BR-05:** 플레이어 캐릭터의 전투 턴 중 이동은 행동 전·사이·후 어느 시점에도 남은 이동량과 적용 규칙이 허용하는 범위에서 이어 쓸 수 있다. 현재 속도, 사용량과 남은 이동량을 표시한다.
- **BR-06:** 도달 가능한 영역과 실제 경로 비용은 벽, 문, 모서리, 어려운 지형, 점유, 상태 조건을 반영한다. 질주, 이탈 및 기회 공격 반응을 적용 룰북에 따른다.
- **BR-07:** 지도는 평면이며 비행체의 지면으로부터의 높이를 피트 단위 수치로 표현한다. 거리의 칸 수는 가로·세로 칸 차이 중 큰 값과 높이 차이를 지도 한 칸의 거리로 나누어 올림한 값 중 큰 값으로 계산한다. 높이 자료가 없는 벽과 닫힌 문은 모든 높이에서 막는다. 벽 높이에 따른 통과 판정과 3차원 지도 편집은 제공하지 않는다.
- **BR-08:** 전투 이동은 캐릭터 토큰을 클릭하고 드래그해 경로를 정한 뒤 확인해 실행한다. 확인 전에는 위치와 전장의 안개를 바꾸지 않는다. 확인하면 실제 이동을 한 칸씩 반영하고, 새 적 발견·함정·반응처럼 GM 처리가 필요한 사건에 도달하면 해당 칸에서 멈춰 GM이 사건을 판정·서술한다.
- **BR-09:** 주문·행동 조작은 `선택 → 가리켜 사거리·효과 전투 행동 미리보기 → 필요한 선택 완료 → 명시적 시전` 순서다. 단일 선택만으로 충분한 경우 클릭이 시전을 확정한다.
- **BR-10:** 방향 지정은 규칙이 요구할 때만 커서 방향으로 결정한다. 대상 지정형 주문을 임의의 방향형 효과로 취급하지 않는다.
- **BR-11:** 주문의 시전 행동 유형, 주문 슬롯, 구성요소, 집중, 지속시간, 발동 조건, 공격·내성·자동 해결 방식 및 더 높은 등급의 주문 슬롯 사용에 따른 변화는 출처 규칙을 따른다. 외형, 투사체 또는 생성 분류로 규칙을 추론하지 않는다.
- **BR-12:** 시전 거리, 대상 가시성, 명확한 경로·엄폐, 효과 확산과 각 주문 예외를 서로 구분해 적용한다.
- **BR-13:** 전투 행동 미리보기는 아군 피해 가능성을 알리며 별도 확인을 요구하지 않는다. 영향을 받는 아군은 해당 주문의 대상 규칙으로 결정한다.
- **BR-14:** 전투 행동 미리보기는 읽기 전용이고 자원을 쓰지 않으며 숨겨진 정보를 누설하지 않는다. 최종 실행은 최신 상태 기준으로 다시 검증한다.
- **BR-15:** 오래된 상태에서 실행 요청이 들어오면 비용을 소비하지 않고 실패 처리한 뒤 최신 상태를 표시한다.
- **BR-16:** 실제 실행 중 중단은 사건이 발생한 위치에서 이동을 멈춘다. 이미 이동한 위치와 소비한 이동량은 유지하며, 비전투 사건 뒤에는 남은 경로를 자동 실행하지 않고 플레이어가 다시 확인한다. 플레이어 캐릭터의 전투 이동 중 GM 처리가 필요한 사건을 해결한 뒤에는 Solo Player의 다음 입력을 기다린다. Solo Player는 남은 이동량과 규칙이 허용하면 새 경로를 확인해 이동하거나, 다른 가능한 행동을 하거나, 턴 종료를 선택한다. 멈춘 경로의 나머지는 자동 실행하지 않는다.
- **BR-17:** Solo Player는 모험 파티의 모든 캐릭터에 대해 탐험 이동, 전투 선택·행동, 능력 습득, 캐릭터 시트 설정·수정을 직접 결정하고 확정한다. AI Game Master는 세계와 NPC·적을 조종하고 규칙을 판정·서술하며 파티 행동을 선택하거나 실행하지 않는다. 적은 동일한 런타임 규칙을 따르고, 내부 수치는 공개 필터로 감춘다.
- **BR-51:** 파티 일상 대화는 AI Game Master가 생성할 수 있으며 상태를 변경하지 않는다. 동료의 중요한 대화 선택은 AI Game Master가 선택지를 제시하거나 Solo Player의 자연어 제안을 받는다. 대화가 전투 행동, 자원 소모, 그룹 분리·합류, 퀘스트·관계 방향을 결정해야 하면 진행을 멈추고 Solo Player가 선택·확정한다. 이는 파티 행동·대화 선택의 확정이며, GM이 판정한 규칙 결과를 반영할 때마다 별도 승인을 요구하지 않는다.
- **BR-52:** 능력 습득과 캐릭터 시트 변경, 파티 행동과 중요한 동료 대화 선택은 Solo Player가 선택·확정한다. AI Game Master는 선택된 행동의 규칙 결과를 판정·서술한다. 런타임 시스템은 그 확정된 규칙 결과와 자원 변화를 반영하며, 결과마다 Solo Player의 추가 승인을 요구하지 않는다. 능력 상세정보는 선택된 능력에 대해 근거를 확인해 제공한다.
- **BR-53:** 동료의 대화에 대한 Solo Player의 자연어 제안이 현재 맥락에서 확인되는 해당 동료의 가치관·성격 묘사와 충돌하면 AI Game Master는 동료가 그 행동을 하지 않을 것이라고 설명하고 다른 선택을 기다린다. 그 대화 행동은 일어나지 않은 것으로 처리하며, 현재 맥락에 없는 가치관을 만들어 근거로 삼지 않는다. 이 규칙은 Solo Player가 직접 결정하는 전투 행동 명령이나 캐릭터 시트 변경에 적용하지 않는다.
- **BR-18:** 자연어 행동 선언에도 지도 조작과 같은 규칙 검증과 정보 공개 경계가 적용된다. 캐릭터가 이동했다는 서술만으로 플레이어 토큰을 옮기지 않으며, 전투 이동은 Solo Player가 확인한 경로의 실제 실행 결과로 반영한다.
- **BR-19:** 플레이어가 턴 종료를 명시적으로 선택하기 전까지 자신의 턴은 종료되지 않는다. 전투 이동 중 사건에 대한 GM의 판정·서술만으로 플레이어 턴을 종료하지 않는다.
- **BR-20:** 지도 확대 후 포인터와 오버레이는 지도 좌표와 계속 정렬된다.
- **BR-21:** 전장의 안개 아래 있는 벽도 기존 가시성·탐험 정책을 따라 표시 여부를 정한다. 숨겨진 벽 형상은 공개하지 않는다.
- **BR-22:** 능력 정의는 구조와 필수 규칙 항목별 근거를 검증한다. 근거가 불충분하거나 충돌하면 재검색·복구하고, 해결되지 않을 때 사용자 원문 입력을 요청한다.
- **BR-23:** AI Game Master는 플레이어가 주문 선언과 함께 전달하거나 별도로 제안한 환경 응용 의도를 상황에 맞게 판단하고, 필요하면 기존 플레이어 굴림 제출 흐름을 통해 굴림을 요청할 수 있다. 예시는 보편 규칙이나 자동 성공을 만들지 않으며 숨겨진 정보를 드러내지 않는다.
- **BR-24:** 추가 환경 응용이 실패해도 이미 적용된 주문 기본 효과와 소비된 자원은 유지한다. 실패하는 것은 추가 환경 응용뿐이다.
- **BR-25:** 추가 환경 응용이 실패하고 플레이어가 관찰할 추가 변화가 없으면 AI Game Master는 해당 실패를 서술하지 않고 넘어갈 수 있다. 이 생략은 추가 응용의 실패와 숨겨진 내부 상태에 한정한다. 주문 기본 효과와 소비한 자원은 기존 UI 규칙에 따라 표시하며, 숨겨진 함정 상태나 내부 실패 사유를 공개하지 않는다.
- **BR-26:** 추가 환경 응용을 계획하기 전에 AI Game Master에게 현재 지원되는 환경 작업의 목록, 각 작업의 입력 형식과 제약을 제공한다. AI Game Master는 제공된 작업만 사용하며, 목록에 없는 작업이나 임의 코드는 실행 요청하지 않는다.
- **BR-27:** 환경 작업 호출 실패 시 오류 내용을 AI Game Master에 전달해 입력이나 작업 선택을 수정할 수 있게 한다. AI Game Master는 수정 후 재시도할 수 있으며, 고정된 재시도 횟수는 요구하지 않는다.
- **BR-28:** 환경 작업 재시도는 이미 확정된 주문 기본 효과나 소비 자원을 다시 적용하지 않는다. 실행은 기존 런타임의 권한 및 지원 여부 확인을 따른다.
- **BR-29:** 정의 준비 대상은 캐릭터 시트에 실제로 있는 능력 ID로 한정한다. 룰북 전체, 모든 능력 목록 또는 ScenarioPackage 전체를 미리 추출·검토하지 않는다.
- **BR-30:** 주문, 원거리 공격, 투척은 동일한 지도 조준 흐름을 사용한다. 미리보기의 시작점은 행동하는 캐릭터 토큰이며, 커서가 가리키는 위치에 따라 사거리와 경로를 표시하고 클릭으로 실행한다. 경로 칸은 붉은색으로 표시한다.
- **BR-31:** 사거리, 일반·최대 사거리, 대상 선택 방식, 효과 모양과 크기, 시작점, 경로 차단 조건, 효과가 장애물 너머로 퍼지는 조건은 출처가 연결된 행동 정의의 자료로 관리한다. 정의를 추가·수정·비활성화·삭제할 때 행동 종류나 주문 이름별 코드 분기를 추가하지 않는다.
- **BR-32:** 실행 엔진은 지원하는 효과 모양과 차단 규칙을 정의 자료에 적용한다. 엔진이 처리하지 못하는 능력 효과는 미지원으로 숨기거나 거부하지 않고 GM이 전체 효과 판정과 상태 변경을 대신한다. 기본 룰북의 정의에서는 원뿔·정육면체·원기둥·선·구와 사거리·완전 엄폐·명확한 경로 근거를 보존한다.
- **BR-33:** 상세 정의는 배운 능력에 대해서만 능력 하나당 한 벌, 현재 모험 한정으로 둔다. 고정 스키마의 모든 필드를 포함하고 미적용 값은 `null`로 둔다. 정의되지 않은 추가 필드는 허용하지 않는다.
- **BR-34:** 모험 시작 시 파티 시트에 이미 있는 능력 ID와 모험 중 새로 배우는 능력 ID만 대상으로 삼아 누락 정의를 준비한다. 시츄에이션 선택이나 룰북·ScenarioPackage 전체를 대상으로 일괄 준비하지 않는다. 이미 현재 모험에 저장된 정의는 다시 검색하지 않는다. 현재 세션의 허가된 자료를 검색하고 기본 룰북과 적용되는 추가 자료를 각각 독립 검색하며, 고정 구조·필수 근거·출처 위치를 검증한다. 재검색·복구가 소진되면 원문 입력을 요청한다. 검증된 정의만 현재 모험에 저장하고, 습득 중 취소하면 습득을 완료하지 않는다.
- **BR-35:** 상세 정의는 원문을 복제하지 않고 출처 위치를 저장한다. 다른 모험과 자동 공유하지 않는다.
- **BR-36:** GM 조회는 현재 모험·요청 캐릭터 시트·능력 식별자 범위로 제한하며, 해당 캐릭터 시트에 실제로 배운 능력만 조회할 수 있다. 저장된 현재 모험 정의 또는 상세정보, 복구 필요, 미습득/미확인, 오류 상태를 반환한다. 저장된 정의가 없으면 추측하지 않고 사용을 멈춘 뒤 해당 능력의 준비·복구 절차를 거친다.
- **BR-37:** 캐릭터별 자원에는 식별자, 현재량·최대량, 회복 조건을 둔다. 능력 비용은 이 자원을 참조하며 선택에 따라 자원·효과가 달라지면 사용 전에 사용자에게 묻는다. 회복 조건 충족은 GM이 판정하고 저장된 회복 규칙대로 갱신한다. 사용에 필요한 현재량이 부족하면 실행하지 않고 자원도 소모하지 않는다.
- **BR-38:** 탐험은 그룹 단위다. 그룹 하나에 탐험 토큰 하나를 두며 개인별 탐험 좌표는 관리하지 않는다. 그룹 속도는 가장 느린 구성원 기준이다.
- **BR-39:** 그룹 분할은 현재 위치에서 새 그룹 토큰을 만들고 구성원·대열을 정한 뒤 별도 경로를 지정한다. 한 캐릭터만 따로 움직이는 경우도 1인 그룹으로 처리한다. 동일 위치에 도착해도 자동 병합하지 않으며 병합은 명시적으로 선택한다.
- **BR-40:** 맵 필요 여부는 시츄에이션의 속성이다. 맵이 필요한 시츄에이션에 진입할 때 대상 시츄에이션의 지도, 적·함정 배치, 문과 잠금 여부 등 초기 상태를 준비하고 근거 사실과 GM이 정한 배치를 구분한다. 해당 진입 서술과 관련 근거를 지도 자료와 함께 사용해 시작 위치를 제안하고, 유효한 위치가 확정되기 전에는 진입 서술을 저장하거나 공개하지 않는다. 맵이 필요하지 않은 시츄에이션은 지도 준비를 건너뛴다. 비공개 적·함정 배치는 플레이어에게 노출하지 않는다.
- **BR-41:** 맵이 필요한 탐험은 상황 시작부터 세계 시간을 멈추고 그룹별 차례로 진행한다. 그룹 토큰을 클릭·드래그해 이동 경로를 정하고 확인하면 한 칸씩 이동한다. 같은 그룹 차례에서 경로를 나눠 여러 번 확정할 수 있지만, 확정한 이동은 그 차례의 그룹 이동 속도를 함께 소모하며 남은 이동량을 넘을 수 없다. `현재 그룹 차례 완료`를 선택하면 그 그룹은 해당 순환에서 더 이동할 수 없고, 모든 그룹 차례가 끝난 뒤 환경을 진행한다. 그룹 우선권은 전열 구성원의 최고 우선권으로 정하고, 우선권이 같은 그룹의 순서는 무작위로 정한다. 한 번 정한 우선권은 상황 종료 또는 요약 이동 전환까지 유지한다.
- **BR-42:** 각 탐험 순환은 모든 그룹의 차례와 환경 6초 진행으로 이뤄진다. 환경 변화 순서는 적·순찰 이동 및 감지, 함정·환경 효과, 지속시간·제한 시간 갱신이다. 저장된 순찰 경로가 없으면 GM이 각 환경 단계에서 주변 적의 이동과 환경 변화를 판단한다. 도중 조우 시 환경 처리를 멈춰 해결한 뒤 이어간다.
- **BR-43:** 이동 중 함정·위협 발견·기습 등 멈춰야 하는 사건이 생기면 해당 위치에서 모든 이동을 멈추고 사건을 해결한다. 전투가 아닌 사건 해결 뒤에도 남은 경로는 자동 재개하지 않으며 현재 상태에서 경로를 다시 확인해야 한다. 사건을 일으킨 그룹의 차례는 끝내고 우선권 순서의 다음 그룹부터 진행한다. 전투가 시작되면 전술 이동 순서를 종료하고 전투 차례로 전환한다.
- **BR-44:** 전투 진입 시 각 탐험 그룹 토큰 위치를 기준으로 가장 가까운 적 방향을 전열 방향으로 정한다. 적이 없으면 북쪽을 사용하고, 같은 거리의 적은 서버 식별자로 순서를 정한다. 전열·중열·후열 순서로 모든 구성원을 서로 다른 유효 칸에 배치하며 벽·통과 불가 지형·다른 토큰의 점유를 침범하지 않는다. 전원의 배치를 확보하지 못하면 지도를 바꾸지 않고 배치 대기를 저장하며, GM이 전원의 유효한 배치를 정한 뒤에만 재개한다. 전투 진입의 토큰 교체는 한 번에 적용하고 재시도·재시작에도 중복·부분 교체를 허용하지 않는다. #367의 지도 적 토큰과 전투 참여자 대응, 적별·캐릭터별 인지 관계 및 참여자별 첫 차례 기습을 보존한다. 전투에서는 캐릭터별 전투 토큰과 개인 이동량을 사용한다. 각 칸에서 지형·벽·문·남은 이동량 및 발견·공간 요소 반응을 확인한다. 그룹 탐험 속도 규칙은 전투 이동에 적용하지 않는다.
- **BR-45:** 전투 종료 시 전투 전 그룹 식별자·구성원·대열을 복원한다. 그룹 토큰은 전열 캐릭터의 현재 칸을 사용하며, 전열이 여러 명이면 서버 식별자 순서로 기준 캐릭터를 정한다. 서로 다른 그룹을 자동 병합하지 않는다. 종료의 토큰 교체도 한 번에 적용하며, 재시도·재시작에도 중복·부분 교체 없이 같은 결과로 복구한다. 구성원과 적의 기존 식별자·인지 관계를 다른 개체에 옮기거나 합치지 않는다.
- **BR-46:** 사용 가능한 조건과 자원을 확인해 능력 실행이 확정되면 효과가 실패해도 정해진 자원을 소모한다. 같은 사용 요청의 재전송·재시도는 한 번만 소모하고, 별도 새 요청은 각각 처리한다.
- **BR-47:** 전투 중 정의된 효과는 규칙에 따라 처리한다. 엔진이 처리할 수 없는 효과는 GM이 전체 해결을 맡으며 자원 소모는 동일한 전투 처리에서 확정한다. 비전투 환경 응용은 GM이 판단하고 비전투 처리에서 자원을 확정한다.
- **BR-48:** GM은 MCP 조회 도구로 현재 모험·캐릭터·능력 식별자를 지정해 정의를 요청할 수 있다. 응답은 상세 정의와 출처 위치 또는 정해진 미습득·복구·오류 결과를 제공한다.
- **BR-49:** 위협 발견은 캐릭터별로 대열상 위치, 지각 능력, 이동 방식과 숨김 상태를 반영해 판정한다. 한 캐릭터가 발견하면 모든 그룹 이동을 멈추지만 처음 알게 되는 것은 발견한 캐릭터뿐이다. 그 캐릭터가 동료에게 알리면 그룹도 알게 되며, 알리는 방식이 적에게 들리는지는 GM이 판정한다. 적이 먼저 발견하면 GM이 적의 행동을 정해 서술하고 사용자가 대응한다. 발견만으로 전투를 자동 시작하지 않는다. 적대 행동으로 전투가 시작될 때 알아차리지 못한 개체별로 기습을 판정하며, 양쪽 모두 숨으려 하지 않았다면 서로 자동으로 알아차린다.
- **BR-50:** 능력 상세정보 검색은 현재 세션의 Session Knowledge Set에 고정된 문서만 대상으로 한다. 기본 룰북(`RULEBOOK`)과 추가 룰북(`STORYBOOK`)을 모두 검색해야 하는 질의는 각 자료 유형을 독립 검색하며, 한쪽 검색 결과로 다른 쪽의 질의어나 검색 범위를 좁히지 않는다. 세션 밖 문서는 검색하지 않는다.

## 7. States and State Transitions

### 능력 정의 준비·습득 상태

- **모험 시작 → 초기 파티 능력 확인:** 모험 시작 시 파티 시트에 이미 등록된 능력 ID만 확인하고 없는 정의만 준비한다.
- **새 능력 습득 → 정의 준비:** 능력 습득 완료 전에 없는 정의를 준비한다.
- **습득 요청 → 정의 재사용 또는 준비:** 이미 저장된 정의는 재검색 없이 재사용하며, 없으면 현재 모험에서 허용된 자료로 검증한다.
- **검증 성공 → 현재 모험에 저장:** 사용자 검토 대기 없이 저장한다. 새 습득 흐름에서는 준비 완료 후 습득을 확정한다.
- **검색·복구 실패 → 원문 입력 대기:** 사용자 입력을 검증해 저장한다. 사용자가 취소하면 습득을 완료하지 않는다.
- **정의 조회 → 복구 필요:** 정의가 없거나 조회 오류면 추측 사용을 중단하고 현재 모험의 정의 준비·복구 절차를 진행한다.

### 지도 상호작용 상태

- **선택 전 → 전투 행동 미리보기:** 이동, 주문 또는 행동을 선택하고 포인터를 지도 위로 옮긴다.
- **미리보기 → 실행:** 전투 이동은 경로를 정한 뒤 확인해 한 칸씩 실행한다. 충분히 지정된 단일 주문·행동은 클릭해 실행한다. (UC-002, BR-08)
- **미리보기 → 추가 선택 필요:** 복수 대상 또는 배분을 요구하는 주문·행동을 선택한다. 선택 후 명시적으로 시전한다.
- **실행 요청 → 최신 상태 검증 실패:** 기준 상태가 바뀌었다. 비용 없이 거부하고 새 상태로 전투 행동 미리보기를 갱신한다.
- **실행 중 → 규칙상 중단:** 실제 위치와 사용한 이동량을 보존하고 사건을 해결한다. 비전투 사건 뒤에는 남은 경로를 다시 확인한다.
- **ST-UC-002-01 전투 이동 실행 중 → GM 사건 처리:** 새 적 발견·함정·반응처럼 GM 처리가 필요한 사건에 도달한 칸에서 멈추고 실제 토큰 위치와 소비한 이동량을 보존한다. (UC-002, BR-08, BR-16)
- **ST-UC-002-02 GM 사건 처리 → 플레이어 입력 대기:** GM이 사건을 판정·서술한 뒤 같은 플레이어 턴에서 다음 입력을 기다린다. 남은 경로는 자동 실행하지 않는다. (UC-002, BR-16, BR-19)
- **ST-UC-002-03 플레이어 입력 대기 → 경로 확인 또는 다른 행동 또는 턴 종료:** 남은 이동량과 규칙이 허용하면 새 경로를 확인해 이동을 이어 가거나, 다른 가능한 행동을 하거나, 명시적으로 턴 종료를 선택한다. (UC-002, BR-05, BR-16, BR-19)
- **플레이어 턴 → 다음 턴:** Solo Player가 명시적으로 턴 종료를 선택한다.

### 주문 효과의 환경 응용

- **응용 계획 전 → 허용 작업 확인:** AI Game Master가 현재 지원되는 환경 작업 목록, 입력 형식과 제약을 받는다.
- **허용 작업 확인 → 호출:** 목록에 포함된 작업만 골라 요청한다. 적절한 작업이 없으면 호출하지 않는다.
- **호출 → 오류 조정:** 호출 실패 시 오류 내용을 AI Game Master에 전달한다. 입력 또는 작업을 수정해 재시도할 수 있다.
- **오류 조정 → 재시도 또는 추가 응용 실패:** 수정된 요청을 다시 시도하거나 추가 응용을 실패로 마친다. 어느 경우에도 이미 적용된 주문 기본 효과와 소비 자원을 다시 적용하지 않는다.

## 8. Failures, Exceptions, and Boundary Conditions

- **EX-01 능력 정의의 근거 부족 또는 충돌:** 재검색·복구 후에도 해결되지 않으면 원문 입력을 요청한다. 취소하면 습득을 완료하지 않는다.
- **EX-02 배운 능력 정의 조회 실패:** 상세정보를 추측하거나 노출하지 않고 사용 처리를 멈춰 복구 절차로 전환한다.
- **EX-03 자원 선택에 따라 비용 또는 효과가 달라짐:** 사용 전에 사용자에게 선택을 요청한다.
- **EX-04 비활성 주문 실행 요청:** 주문 슬롯이나 행동 자원을 소비하지 않고 거부한다.
- **EX-05 대상 지정 주문에 복수 대상·배분 필요:** 전투 행동 미리보기만으로 시전하지 않고 필요한 선택 뒤 명시적으로 시전한다.
- **EX-06 주문이 요구하지 않는 방향 지정:** 커서 방향이나 효과 외형에서 방향을 추론하지 않는다.
- **EX-07 실행 전 상태 변경:** 이전 전투 행동 미리보기는 실행 근거로 쓰지 않고, 비용 없이 거부한 뒤 최신 상태로 갱신한다.
- **EX-08 실행 중 반응·함정 등으로 이동 중단:** 실제로 도달한 위치와 소비한 이동량을 보존한다. 전투 이동에서는 GM이 사건을 판정·서술한 뒤 플레이어의 다음 입력을 기다리며, 남은 경로의 자동 실행이나 서술만으로 인한 토큰 이동·턴 종료를 하지 않는다. (UC-002, BR-16, BR-18, BR-19)
- **EX-09 숨겨진 벽:** 기존 공개 정책이 허용하지 않는 벽 형상은 지도 확대나 오버레이를 통해서도 드러나지 않는다.
- **EX-10 자연어 입력:** 정형 지도 입력과 동일한 규칙 검증을 적용한다.
- **EX-11 3차원 지도 편집 요구:** 지원 범위가 아니다. 비행 위치와 규칙 계산은 평면 지도 위 수치 지면으로부터의 높이로 처리한다.
- **EX-12 추가 환경 응용 실패로 관찰 가능한 변화가 없음:** 추가 응용 실패나 숨겨진 내부 상태는 서술하지 않고 넘어갈 수 있다. 주문 기본 효과와 소비 자원은 계속 표시하고, 숨겨진 함정 상태와 내부 실패 사유는 공개하지 않는다.
- **EX-13 허용 환경 작업 없음:** 사용할 수 있는 작업이 목록에 없으면 지원되지 않는 동작을 요청하거나 임의 코드를 실행하지 않는다.
- **EX-14 환경 작업 호출 실패:** 오류 내용을 AI Game Master에 전달해 수정·재시도할 수 있게 한다. 재시도 횟수의 고정 한도는 정하지 않으며 주문 기본 효과와 소비 자원을 중복 적용하지 않는다.

## 11. Priorities and Trade-offs

1. 배운 능력에 대한 근거와 출처, 실행 안전성을 우선한다.
2. 전투 행동 미리보기의 편리함보다 최신 상태 재검증, 자원 무소비, 정보 비공개를 우선한다.
3. 이동·주문·행동 조작은 짧은 선택·가리키기·클릭 흐름을 사용하되, 복수 대상·배분 주문에는 필요한 명시적 선택을 유지한다.
4. 전투 행동 미리보기는 아군 영향 위험을 알리되 확인 단계를 늘리지 않는다.
5. 그룹 탐험과 개인 전투 이동을 구분하고, 세계 시간·환경·자원 규칙을 명시된 순서대로 적용한다.

## 12. Success Conditions and Acceptance Criteria

### 적용 범위와 출처

- **AC-01:** 정의 준비 대상은 모험 시작 시점의 파티 캐릭터 시트와 이후 능력을 배우는 캐릭터 시트에 실제로 등록되는 능력 ID뿐이다. 모든 주문·기술이나 ScenarioPackage 전체를 사전 적재·일괄 검토하지 않는다. (G-01, BR-01, BR-29)
- **AC-02:** 모험 시작 시 초기 파티 능력과 새 능력 습득 흐름에서만 누락 정의를 준비한다. 필요한 규칙 항목은 출처 위치로 뒷받침되고 검증된 고정 구조만 사용자 확인 대기 없이 현재 모험에 저장된다. 근거를 해결할 수 없으면 원문 입력을 요청한다. (BR-33, BR-34)
- **AC-03:** 상세 정의는 모험 간 자동 공유되지 않고, 출처 원문 대신 출처 위치를 보존한다. (BR-35)
- **AC-04:** GM 조회는 현재 모험·캐릭터의 습득 능력에 한정되며, 성공·복구 필요·미습득/미확인·오류를 구별한다. (BR-36, BR-48)

### 파티 조종과 대화

- **AC-43:** Solo Player는 파티 모든 캐릭터의 탐험 이동·전투 행동·능력 습득·시트 설정 및 수정 결정을 선택하고 확정하며, GM은 이를 대신 결정하거나 실행하지 않는다. (BR-17, BR-52)
- **AC-44:** GM은 일상 파티 대화를 생성할 수 있고, 대화가 파티 상태를 바꾸지 않는다. 동료의 중요한 대화 선택에 선택지를 제시하거나 Solo Player의 자연어 제안을 받는다. 전투 행동·자원 소모·그룹 분리/합류·퀘스트/관계 방향을 정할 때 진행을 멈추고 사용자 선택·확정을 기다린다. (UC-006, BR-51)
- **AC-45:** Solo Player가 파티 행동을 선택·확정한 뒤 GM이 규칙 결과를 판정·서술하고, 런타임이 해당 결과와 자원 변화를 반영한다. 결과 반영마다 추가 플레이어 승인을 요구하지 않는다. 선택된 능력의 근거 있는 상세정보도 해당 능력을 선택한 뒤 준비한다. (UC-001, BR-52)
- **AC-46:** 동료 대화에 대한 자연어 제안이 현재 맥락에서 확인되는 그 동료의 가치관·성격 묘사와 충돌하면 GM은 불가 사유를 설명하고 다른 선택을 기다리며, 해당 대화 행동은 일어나지 않는다. 맥락에 없는 가치관을 근거로 만들지 않으며, 이 규칙은 Solo Player가 직접 정하는 전투 행동 명령이나 캐릭터 시트 변경에 적용하지 않는다. (UC-006, BR-53)

### 이동

- **AC-31:** 그룹 탐험은 그룹 토큰 하나와 구성원 중 최저 속도를 사용하며, 전투 이동은 캐릭터별 토큰·개인 이동량을 사용한다. (BR-38, BR-44)
- **AC-32:** 분할은 현재 위치에서 새 그룹·대열·개별 경로를 만들고, 병합은 명시적 선택에만 따른다. (BR-39)
- **AC-33:** 맵 필요 여부는 시츄에이션 속성으로 정한다. 맵이 필요한 시츄에이션은 시작 위치를 먼저 제안한 뒤, 진입 서술과 그 시츄에이션의 지도·근거에 맞는지 검증한다. 일치하지 않으면 진입을 보류하고, 일치하는 위치가 확인된 뒤 진입 서술을 저장·공개한다. 맵이 필요 없는 시츄에이션은 지도 없이 진입한다. 비공개 배치는 플레이어에게 드러나지 않는다. (BR-40)
- **AC-34:** 전술 탐험은 정해진 그룹 우선권의 순차 차례와 매 순환 6초 환경 처리를 지킨다. 환경은 적·순찰 이동과 감지 → 함정·환경 효과 → 지속시간·제한 시간 갱신 순서로 처리하며, 저장된 순찰 경로가 없으면 GM이 적 이동과 환경 변화를 판단한다. 조우 중에는 멈췄다가 해결 뒤 남은 환경 단계를 이어간다. 우선권 동률은 무작위 순서로 해결한다. (BR-41, BR-42)
- **AC-35:** 탐험 이동 사건에서 멈춘 뒤 비전투 해결이 끝나도 남은 경로를 자동 실행하지 않고 재확인을 요구한다. (BR-43)
- **AC-36:** 각 그룹 위치에서 가장 가까운 적 방향, 적 없음의 북쪽 대체, 동률의 서버 식별자 순서를 적용하여 전열·중열·후열 구성원이 벽·점유를 침범하지 않는 서로 다른 칸에 배치된다. 전원 배치가 불가능하면 지도는 그대로이고 배치 대기가 저장되며, GM의 전원 배치 검증 후 한 번에 전환된다. 진입·종료 각각 같은 서버 소유 작업 식별자로 재시도하거나 재시작해도 중복·부분 전환이 없고, 종료 후 기존 그룹 식별자·구성·대열과 전열 캐릭터 현재 칸이 복원되며 별도 그룹은 자동 병합되지 않는다. #367의 개체별 인지·참여자 대응·첫 차례 기습 상태도 보존된다. (BR-44, BR-45, BR-49)
- **AC-37:** 캐릭터 시트 자원 현재량·최대량·회복 조건에 따라 능력 비용과 회복을 결정적으로 갱신한다. (BR-37)
- **AC-38:** 확정된 능력 사용은 실패해도 비용을 소모하고, 같은 요청 재전송은 중복 소모하지 않는다. (BR-46)
- **AC-39:** 전투 능력의 지원 불가 효과는 GM이 전체 해결하며, 비전투 환경 응용은 전투 효과 처리와 구분해 GM이 판정한다. (BR-47)
- **AC-40:** GM은 MCP 조회 도구로 지정한 모험·캐릭터가 배운 능력 정의와 출처 위치를 조회할 수 있고, 오류·미습득·복구 필요는 정의 노출 없이 구분된다. (BR-48)
- **AC-41:** 탐험 조우는 위협 발견을 캐릭터별로 처리하고 발견자만 우선 인지한다. 동료에게 알리면 그룹이 인지하며, GM은 알리는 방식이 적에게 들릴지 판정한다. 적이 먼저 발견한 경우 GM이 적 행동을 제시한다. 발견 자체는 전투를 시작하지 않고, 적대 행동으로 전투가 시작될 때 미인지 개체만 기습 판정을 받는다. 양쪽이 숨지 않았다면 서로 자동으로 알아차린다. (BR-49)
- **AC-42:** 능력 정의 검색은 세션에 고정된 문서만 대상으로 한다. 기본 룰북과 추가 룰북을 모두 검색하는 질의는 각각 독립적으로 검색하며, 한쪽 결과가 다른 쪽 검색을 좁히지 않는다. (UC-001, BR-50)

- **AC-05:** 플레이어 캐릭터의 전투 턴에서 행동 전·사이·후에 남은 이동량과 규칙이 허용하는 이동을 이어 쓸 수 있고 현재 속도·사용량·잔여량을 확인할 수 있다. (G-03, UC-002, BR-05)
- **AC-06:** 전투 행동 미리보기와 경로 비용에 벽·문·모서리·어려운 지형·점유·상태가 반영되고, 질주·이탈·기회 공격 반응이 룰북에 따라 처리된다. (BR-06)
- **AC-07:** 전투 이동은 캐릭터 토큰을 클릭·드래그해 경로를 정하고 확인해야 실행된다. 실행 전 위치와 전장의 안개는 바뀌지 않으며, 경로는 한 칸씩 진행된다. (BR-08)
- **AC-08:** 실제 실행 중 규칙상 중단되면 도달한 위치와 이미 소비한 이동량을 유지한다. 전투 이동 중 새 적 발견·함정·반응처럼 GM 처리가 필요한 사건에 도달하면 해당 칸에서 멈추고, GM 판정·서술 뒤 같은 플레이어 턴에서 다음 입력을 기다린다. 플레이어는 남은 이동량과 규칙이 허용하면 새 경로를 확인해 이동하거나 다른 가능한 행동 또는 턴 종료를 선택할 수 있으며, 멈춘 경로의 나머지는 자동 실행되지 않는다. (UC-002, BR-08, BR-16, ST-UC-002-01~03)

### 주문과 행동

- **AC-09:** 선택 후 커서 위치에 따라 사거리와 효과 범위를 미리 볼 수 있다. 한 대상 선택으로 충분하면 클릭 시전하고, 복수 선택·배분이 필요하면 선택 완료 후 명시적으로 시전한다. (BR-09)
- **AC-10:** 방향이 필요한 원뿔·선은 시전자에서 커서 방향으로 향하며, 방향이 불필요한 대상 지정 주문은 유효 대상을 표시한다. 마법 화살은 복수 대상·투사체 배분 뒤 명시적으로 시전할 수 있다. (BR-10)
- **AC-11:** 주문 실행이 시전 행동 유형, 슬롯, 구성요소, 집중, 지속시간, 발동 조건, 공격·내성·자동 해결과 더 높은 등급의 주문 슬롯 사용에 따른 변화를 출처 규칙대로 적용한다. (BR-11)
- **AC-12:** 시전 거리, 가시성, 명확한 경로·엄폐 및 효과 확산은 서로 구분하여 판정되고 주문별 예외가 유지된다. (BR-12)
- **AC-13:** 범위 안에 들어오는 아군이 있으면 전투 행동 미리보기에서 경고하고, 추가 확인 없이 주문별 대상 규칙대로 영향을 판정한다. (BR-13)

### 상태·공개·지도

- **AC-14:** 전투 행동 미리보기만으로 위치, 자원 또는 전투 상태가 변하지 않고 숨겨진 정보를 알아낼 수 없다. (G-04, BR-14)
- **AC-15:** 전투 행동 미리보기 후 상태가 바뀌면 실행은 자원 소모 없이 거부되고 현재 상태에 맞게 새로고침된다. (BR-15)
- **AC-16:** Solo Player가 턴 종료를 명시적으로 선택하기 전에는 플레이어 턴이 자동 종료되지 않는다. 전투 이동 중 사건을 GM이 판정·서술한 직후에도 플레이어의 다음 입력을 기다린다. (UC-002, BR-19, ST-UC-002-02~03)
- **AC-17:** 비행 위치의 수치 지면으로부터의 높이가 거리·장애물·효과 포함 여부에 반영되고, 3차원 편집은 제공되지 않는다. (G-06, BR-07)
- **AC-18:** 모험 시작 후 확대·축소 시 포인터와 범위 오버레이가 지도상의 위치와 정렬된다. (BR-20)
- **AC-19:** 벽 형상 표시는 기존 가시성·탐험 정책을 따르고 숨겨진 벽을 드러내지 않는다. (BR-21)
- **AC-20:** 자연어로 선언한 이동·주문·행동은 직접 조작과 같은 규칙 검증 및 숨김 정보 정책을 따른다. 캐릭터가 이동했다는 서술만으로 플레이어 토큰은 이동하지 않으며, 확인한 전투 이동 경로의 실제 실행 결과만 토큰 위치에 반영한다. (G-07, UC-002, BR-08, BR-18)
- **AC-21:** 구조와 필수 항목별 근거를 검증하고, 해결되지 않는 근거 부족·충돌은 원문 입력 요청으로 이어진다. 사용자가 정의 입력을 취소하면 능력 습득은 완료되지 않는다. (BR-22, BR-34)
- **AC-22:** Solo Player가 주문 선언과 함께 또는 별도로 주문 효과의 환경 응용을 제안하면 AI Game Master가 상황별로 판단하고, 필요한 경우 기존 플레이어 굴림 제출 흐름으로 굴림을 요청할 수 있다. 물로 함정을 무력화하는 예는 자동 성공이나 함정 취약성의 보편 규칙을 뜻하지 않으며, 숨겨진 정보는 공개하지 않는다. (UC-004, BR-23)
- **AC-23:** 추가 환경 응용이 실패해도 이미 적용된 주문 기본 효과와 소비된 자원은 유지하고, 추가 환경 응용만 실패 처리한다. (UC-004, BR-24)
- **AC-24:** 추가 환경 응용이 실패하고 관찰 가능한 추가 변화가 없으면 해당 실패를 서술하지 않고 넘어갈 수 있다. 주문 기본 효과와 소비 자원은 기존 UI 규칙대로 표시하며 숨겨진 함정 상태와 내부 실패 사유는 공개하지 않는다. (UC-004, BR-25)
- **AC-25:** AI Game Master는 추가 응용을 계획하기 전에 지원되는 환경 작업 목록, 입력 형식과 제약을 받으며 목록에 없는 작업이나 임의 코드를 실행 요청하지 않는다. (BR-26)
- **AC-26:** 작업 호출 오류 내용이 AI Game Master에 전달되어 입력이나 작업 선택을 수정하고 재시도할 수 있다. 고정 재시도 횟수는 전제하지 않는다. 재시도는 주문 기본 효과나 소비 자원을 중복 적용하지 않는다. (BR-27, BR-28)
- **AC-27:** 능력 정의는 모험 시작 시 파티 시트와 새 능력 습득으로 실제 보유가 확인된 ID에 대해서만 근거 검증 후 자동 저장한다. 시츄에이션 선택만으로 능력 준비를 시작하지 않는다. 현재 모험에 이미 저장된 정의는 재검색하지 않으며 정의는 다른 모험과 공유하지 않는다. (UC-001, BR-29, BR-33~35)
- **AC-28:** 주문·원거리 공격·투척을 선택하고 지도에서 포인터를 움직이면 캐릭터 토큰을 시작점으로 사거리와 유효 경로를 미리 본다. 유효 경로의 지도 칸은 붉은색으로 표시되고 클릭 시 해당 행동의 실행이 제출된다. (UC-002, BR-30)
- **AC-29:** 룰북에 효과 모양이 정의된 행동은 해당 모양과 크기의 영향 칸을 미리 보여준다. 표적까지의 명확한 경로·완전 엄폐와 효과 모양의 장애물 차단/확산 판정은 서로 다른 근거 자료를 적용한다. (BR-12, BR-31, BR-32)
- **AC-30:** 기존 지원 형상·규칙 조합에 속하는 행동 정의는 행동 종류나 특정 룰북 항목 이름별 코드 분기 없이 추가·수정할 수 있다. 엔진이 효과를 처리하지 못하면 GM이 전체 해결을 대신한다. (BR-31, BR-32)
