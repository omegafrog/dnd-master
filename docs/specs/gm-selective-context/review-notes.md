# 아키텍처 검토 기록

상태: 구체 설계 계약 검토에서 미해결 설계 이의 없음. 구현·누출 검증·성능 측정은 별도이며 완료되지 않았다. 정식 Principle·Evidence 승인 기록을 작성한 것은 아니다.

## 검토 대상과 범위

제품 명세, 사용자와 합의한 설계, 아키텍처 초안의 내부 일관성을 검토했다. 새 외부 자료나 코드 조사 결과를 권위 있는 검토 근거로 추가하지 않았다. 정식 Principle·Evidence 승인 ID는 제공되지 않았으므로 만들거나 추정하지 않는다.

## 검토 이의 R-01과 정정

- 관련 요구: 제품 BR-06, AC-03. 숨겨진 사실은 엔진 공개 허가 전 플레이어에게 전달하지 않는다.
- 관련 설계: 아키텍처 8.2, 11.3, 13.1.
- 문제: 비공개 내용을 읽은 모델의 자유로운 서술은 같은 사실을 바꿔 말할 수 있다. 초안은 이를 검사해야 한다고만 기술하고, 실제로 어떤 경계가 응답을 차단하고 무엇으로 공개 여부를 판단하는지 확정하지 않았다.
- 영향: 아직 발견하지 않은 단서·사건·비밀이 NPC 대사나 묘사로 노출될 수 있다.
- 필요한 결정: 플레이어 서술을 만드는 경계, 그 경계에 전달할 정보, 공개 가능 여부를 확정할 수 없을 때의 동작.
- 사용자 답변: ‘원래 설계에서는 "봐도 되는 정보만 보고 서술하는 에이전트"가 따로 서술만 담당했었는데’.
- 반영: 기존 공개 정보 필터가 엔진에서 허가된 관찰 결과·공개 사실·캐릭터 지식만으로 `PlayerVisibleTurn`을 만들고, `TurnWriterPort`는 이 자료만 받는다. 내부 GM 서술을 `narrationSeed`로 넘기거나 서술 경계를 우회하는 경로를 사용하지 않는다. 도구 이력·비공개 기억·기존 GM 실행 문맥을 서술 입력에서 제외한다.
- 재검토: 이의는 설계 계약 수준에서 해결됐다. 기존 우회 경로 보완과 실제 누출 검증은 구현 검증 사항이며, 추가 설계 선택으로 남겨두지 않는다.
- 사용자 답변은 기존 경계를 지적한 사실 정정이다. 사용자 대신 선택 이유나 감수할 비용을 작성하지 않는다.

## 다른 검토 결과

기존 소유권 재사용, Codex만 변경, 읽기 전용 조회, 서버 반환 근거의 검증 연결, 시츄에이션 제안의 동일 턴 저장, 주사위 대기·중복 방지, 5초 초과 계속 처리에는 추가 개념 충돌이 발견되지 않았다. 실제 5초 달성 여부는 별도 구현·측정 사항이다.

제품·아키텍처 다이어그램 원본과 SVG가 존재하고 로컬 렌더 및 링크·내용 검토를 수행했다. 애플리케이션 코드는 수정하거나 시험하지 않았다.

검토자는 수정된 설계 계약 자체와 사용자 요구를 대조했다. 기존 설계 문서가 새 근거 자료로 승인됐다고 주장하지 않으며, 검토자가 새로 발견해 사용한 자료는 없다. 정식 Principle·Evidence 및 자료 사용 승인 ID는 제공되지 않았다는 한계를 유지한다.
