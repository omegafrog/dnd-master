# 모험 진행 컨텍스트 개선 — Product Spec

## 1. Problem and Context

Codex를 사용하는 모험 시작 이후 턴부터 AI Game Master는 현재 플레이에 필요한 상태와 과거 기록을 일관되게 참고해야 한다. 다른 AI 제공자의 입력·근거·응답 경로는 기존 방식을 유지한다. 현재 상황은 최신 저장 상태를 기준으로 유지하고, 장기 기록과 대화 요약은 그 역할에 맞게 활용해야 한다. 숨겨진 단서의 존재와 확인 조건은 AI Game Master가 알아야 하며, 공개 조건을 충족하고 게임 엔진이 공개를 허가한 뒤에만 플레이어에게 드러날 수 있다. 추가 정보가 필요한 경우 AI Game Master가 같은 실행 중 조회 대상을 정하도록 한다.

## 2. Goals and Desired Outcomes

- **G-01**: Codex를 사용하는 모험 시작 이후 각 GM Turn에 최신 현재 상황과 기본 진행 정보를 자동으로 제공한다.
- **G-02**: Codex를 사용하는 경우 AI Game Master가 필요할 때 추가 정보의 종류·대상·범위를 직접 정해 조회할 수 있다.
- **G-03**: 숨겨진 정보의 내부 활용과 플레이어 공개를 분리한다.
- **G-04**: 확정된 턴의 오래된 대화만 압축하고, 다음 턴은 최신 저장 상태에서 이어간다.
- **G-05**: Codex를 사용하는 전체 턴의 완료 목표를 서버 요청 접수부터 최종 응답까지 5초 이내로 둔다. 목표는 실측 전 달성된 것으로 간주하지 않는다.

## 3. Users and Actors

- **Solo Player**: 모험을 진행하고 행동을 입력하며, 필요한 경우 자신의 주사위 결과를 제출한다.
- **AI Game Master**: 기본 진행 정보를 바탕으로 행동을 해석하고, 필요 시 같은 실행에서 추가 정보를 조회해 결과와 서술을 만든다.
- **Adventure Runtime**: 게임 상태 변경을 검증·저장하고 공개 가능한 결과를 확정한다.

## 4. Ubiquitous Language and Terminology

- **GM Turn**: Solo Player의 입력 하나를 AI Game Master가 해석하고, 판정·서술·상태 변화·다음 상황을 하나의 진행 결과로 확정하는 단위.
- **Current Situation (현재 상황)**: 플레이에서 확인된 장소·문제·위협·목표를 나타내는 최신 상태.
- **Situation (시츄에이션)**: 현재 국면에 활용할 작은 목표·도전·사건 기회를 담은 준비된 재료.
- **GM Context Compaction (GM 대화 압축)**: 확정된 GM Turn의 오래된 대화 기록을 줄여 이후 턴이 이전 상황을 이어가게 하는 과정. 최신 현재 상황은 대화 요약으로 갱신하지 않는다.
- **NarrativeState**: 세계 사실, 공개된 사실, 캐릭터 지식, 관계, 서사 진행 상태를 보유하는 기존 세션 상태.
- **ConversationSummary / LongTermAdventureFact**: 각각 기존 대화 요약과 모험 장기 기록을 뜻하며, 각 데이터의 현재 소유권을 유지한다.
- **다섯 프롬프트 구역**: 기존 순서대로 ① 고정 지침·잠긴 자료, ② 현재 상황 관련 장기 기록, ③ 압축된 이전 대화, ④ 압축하지 않은 최근 대화, ⑤ 최신 캐릭터 시트·현재 상황·이번 턴 근거·플레이어 입력을 유지한다. 장면 개요와 선택된 시츄에이션은 최신 컨텍스트에 포함하고, 사용할 수 있는 조회 범주·대상도 제공한다. 잠긴 자료는 전체 시나리오가 아니라 세션에 고정된 범위의 개요만 제공한다.

## 5. Core Use Cases

### UC-01 — GM Turn 준비, 진행 및 추가 정보 조회

1. Solo Player가 행동을 입력하거나 기존 확정 대기 흐름을 이어간다.
2. AI Game Master는 지침, 최신 저장 상태, 현재 상황, 최근 원문 대화와 압축된 과거 대화, 장면 개요, 시츄에이션에 관련된 과거 사건·관계·약속을 우선한 장기 기록, 플레이어 입력, 사용할 수 있는 정보 범주와 대상을 받는다.
3. 기본 컨텍스트에는 선택된 시츄에이션이 있으면 그 항목과 목표·도전·조건·진행 상태를 최신 저장 상태 기준으로 포함한다. 선택된 시츄에이션이 없으면 만들거나 추측하지 않는다. 일반 탐험·대화·이동처럼 특정 시츄에이션을 필요로 하지 않는 턴은 현재 상황으로 진행한다. 관련 있는 다른 시츄에이션 후보는 짧은 개요만 제공할 수 있다.
4. 장면 개요에는 숨겨진 사건·단서의 존재와 확인 조건을 AI Game Master 전용 정보로 포함한다. 세부 정보는 필요한 경우 추가 조회한다.
5. 추가 정보가 필요하면 AI Game Master가 같은 실행 안에서 조회 종류·대상·범위를 정한다. 장소공간, 인물관계, 사건진행, 단서비밀, 규칙판정, 조우전투, 아이템자원, 과거기억 범주와 자연어 질의를 사용할 수 있다. 이 읽기 전용 조회로는 시츄에이션 상태를 바꾸지 않는다.
6. 기존 시츄에이션 선택 규칙에 따라 이번 GM 실행에서 활성화 또는 완료를 제안할 수 있다. 제안은 해당 턴의 상태 변경과 함께 기존 검증을 거쳐 반영한다. 플레이어 주사위 입력 대기 중이나 실패한 턴에서는 활성화·완료를 먼저 확정하지 않는다.
7. 게임 엔진은 기존 굴림·상태 변경 규칙에 따라 결과를 검증·저장하고, 판정 결과와 공개 허가된 관찰 가능 결과를 확정한다.
8. 기존 Narration Agent는 공개 허가된 정보만 받아 플레이어용 한국어 서술을 생성하고 전달한다.

### UC-02 — 확정 턴 압축과 다음 턴 연속성

1. GM Turn이 확정되고 응답이 전달된 뒤, 오래된 대화 기록의 압축을 비동기로 수행한다.
2. 압축은 확인된 턴만 대상으로 한다. 최신 현재 상황과 기타 확정 상태는 별도로 유지한다.
3. 다음 턴은 최신 저장 상태를 읽어 현재 상황과 선택된 시츄에이션의 진행 상태를 구성하며, 오래된 요약의 상태를 정본으로 사용하지 않는다. 시츄에이션이 끝난 뒤에도 그와 관련해 이미 확인된 대화 기록은 이후 맥락에 남긴다. 압축이 실패하면 유효한 기존 요약과 원문 대화를 보존하고 응답은 계속 진행한다.

### UC-03 — 근거 조회 실패 또는 5초 초과

1. 선택적 세부 정보가 없으면 확인된 정보만 사용해 진행한다.
2. 판정·비밀 공개에 필수인 근거를 얻지 못하면 해당 판정·공개와 턴 확정을 보류하고 재시도한다.
3. 턴이 5초 안에 끝나지 않더라도 같은 요청에서 완료까지 계속 처리한다. 5초는 중단 시점이 아니며 오류 응답으로 성공을 대신하지 않는다.

## 6. Business Rules and Invariants

- **BR-01**: 기본 컨텍스트는 지침, 최신 상태와 현재 상황, 최근 압축되지 않은 대화, 압축된 과거 대화, 장면 개요, 관련 장기 기록, 플레이어 입력, 정보 범주·대상을 포함한다.
- **BR-02**: 선택된 시츄에이션이 있을 때 매 턴 기본 컨텍스트에 포함하며, 목표·도전·조건·진행 상태는 최신 저장 상태에서 읽는다. 없으면 새로 만들어내지 않는다.
- **BR-03**: 다른 시츄에이션 후보는 관련성이 있을 때 짧은 개요로만 제공한다. 매 턴 새 시츄에이션 선택이나 활성화는 요구하지 않는다.
- **BR-04**: GM은 정본 게임 상태와 구조화된 시나리오를 우선 확인하고, 해결되지 않는 정보는 세션에 고정된 자료 범위에서 찾는다.
- **BR-05**: 별도의 LLM 판단 단계가 조회 필요성이나 조회 후보를 먼저 결정하지 않는다.
- **BR-06**: 숨겨진 정보는 AI Game Master 내부 판단에 사용할 수 있다. 공개 조건을 충족한 뒤에도 게임 엔진이 허가한 정보만 플레이어 결과에 포함한다.
- **BR-07**: 추가 정보 조회는 읽기 전용이며 상태를 변경하지 않는다. GM이 제안한 상태 변경은 기존 엔진의 검증과 저장을 거치며, 기존 요청 식별자 기반 중복 방지, 굴림 소유권, 대기 중인 굴림의 진행 차단, 공개 경계를 유지한다.
- **BR-08**: 시츄에이션이 없더라도 일반 탐험·대화·이동을 포함해 모든 플레이 턴은 진행할 수 있다. 시츄에이션이 없을 때 새 항목을 만들어내지 않는다.
- **BR-09**: 장기 기록은 가장 최근 항목만을 기준으로 삼지 않고, 현재 시츄에이션과 관련된 과거 사건·관계·약속을 우선 연결한다. 시츄에이션이 끝나도 확인된 대화 기록은 다음 턴 맥락에 보존한다.
- **BR-10**: 대화 압축 실패 시 유효한 기존 요약과 원문 대화를 보존하며, 그 실패만으로 플레이어 응답을 막지 않는다.
- **BR-11**: GM 대화 압축은 응답 이후 비동기로 확인된 턴만 처리한다. 최신 Current Situation은 늘 최신 저장 상태에서 구성한다.
- **BR-12**: 5초 목표의 측정 범위는 서버 요청 접수부터 준비·GM 처리·추가 조회·검증·저장·최종 응답까지의 성공한 전체 턴이다. 사람의 주사위 입력 대기는 제외한다.
- **BR-13**: 5초 초과 턴도 동일 요청에서 완료까지 처리하며, 느린 턴을 측정에서 제외하거나 이른 오류로 대체하지 않는다. 평균이나 빠른 일부 턴만으로 목표 충족을 판정하지 않는다.
- **BR-14**: Codex GM 실행은 기존 시츄에이션 선택 규칙을 사용해 활성화·완료를 제안할 수 있으며, 별도 선택 모델이나 규칙을 추가하지 않는다.
- **BR-15**: 추가 정보 조회는 읽기 전용이며 시츄에이션을 포함한 저장 상태를 변경하지 않는다.
- **BR-16**: 시츄에이션 활성화·완료 제안은 같은 GM Turn의 기존 상태 변경 검증·저장 절차로 반영한다. 해당 턴이 주사위 입력 대기 중이거나 실패하면 제안을 먼저 확정하지 않으며, 같은 요청의 재시도는 중복 적용되지 않는다.
- **BR-17**: GM의 내부 판단 및 선택적 비공개 조회 결과는 기존 Narration Agent 경계에서 제외한다. 게임 엔진이 공개를 허가한 관찰 가능 결과만 기존 공개 입력에 포함한다.
- **BR-18**: Narration Agent는 플레이어용 서술만 생성하며, GM 내부 대화·도구 이력·비공개 기억에는 접근하지 않는다. 별도 근거 선택기나 안전성 판단 단계는 추가하지 않는다.

## 7. States and State Transitions

독립된 업무 상태 다이어그램은 추가하지 않는다. 이 변경은 별도 업무 생명주기를 만들지 않으며, 기존 GM Turn 확정·굴림 대기·검증·공개 상태 전이를 따른다.

## 8. Failures, Exceptions, and Boundary Conditions

- **선택적 세부 정보 누락**: 확인된 정보만으로 진행한다.
- **필수 근거 조회 실패**: 판정, 비밀 공개 및 턴 확정을 보류하고 재시도한다. 무한 재시도는 보장하지 않으며 기존 최종 오류 처리는 유지한다.
- **5초 초과**: 요청을 조기 종료하지 않고 같은 요청에서 계속 처리한다.
- **플레이어 공개 경계**: 엔진의 공개 허가 전에는 숨겨진 정보와 내부 판정 정보를 플레이어 결과에 포함하지 않는다. Narration Agent는 허가된 공개 정보만 받는다.
- **공개 허가 정보 누락**: 필수 공개 근거를 엔진이 허가하지 못하면 해당 공개·판정·턴 확정을 보류하고 재시도한다.
- **주사위 입력 대기**: 성공 응답 시간 목표의 측정에서 제외한다.

## 9. Inputs and Outputs

**입력:** 플레이어의 행동, 기존 지침, 최신 저장 상태와 현재 상황, 선택된 시츄에이션이 있으면 그 상태, 최근 및 압축된 대화, 장면 개요와 관련 장기 기록, 정보 범주·대상 목록, GM이 같은 실행에서 정한 추가 조회 요청, 기존 주사위 제출.

**출력:** 엔진이 검증한 상태 변경과 공개 허가된 관찰 가능 결과, Narration Agent가 해당 공개 입력만으로 생성한 한국어 GM 응답, 필요한 경우 기존 굴림 대기 요청, 그리고 응답 후 수행되는 확인된 대화의 비동기 압축.

## 10. Scope and Non-goals

**범위:** Codex를 사용하는 모험 시작 이후 GM Turn의 컨텍스트 준비와 선택적 정보 조회. 확인된 전투 중 GM 서술 턴도 포함한다. Codex 이외의 AI 제공자는 기존 입력·근거·응답 경로를 유지한다.

**범위 밖:** 전투 참가자 선택 흐름 재설계, 모험 준비 흐름, 별도 조회 사전 판단 단계, 새로운 시츄에이션 선택 규칙이나 선택 모델, 시츄에이션이 없는 턴에 시츄에이션을 만들어내는 처리, 매 턴 의무적인 시츄에이션 활성화, 새 기억 소유권 또는 플레이어 공개 정보 저장소.

## 11. Priorities and Trade-offs

- 먼저 최신 정본 상태와 구조화된 시나리오로 답을 찾고, 부족한 경우 세션 고정 자료를 조회한다.
- 선택적 묘사 정보 누락은 확인된 정보로 처리한다. 필수 판정·공개 근거 누락은 턴 확정을 늦추더라도 보류한다.
- 5초는 전체 성공 턴의 목표다. 이를 맞추기 위해 처리 중인 턴을 조기 오류로 바꾸지 않는다.
- 현재 지연 실측은 없으므로 목표 달성 여부는 향후 검증 대상이다.

## 12. Success Conditions and Acceptance Criteria

- **AC-01**: 각 GM Turn의 기본 컨텍스트에 최신 Current Situation이 포함된다. 선택된 시츄에이션이 있을 때 최신 목표·도전·조건·진행 상태도 포함되며, 없으면 만들어내지 않는다. 특정 시츄에이션을 필요로 하지 않는 일반 탐험·대화·이동도 진행 가능하다.
- **AC-02**: 관련 있는 다른 시츄에이션은 짧은 개요만 제공되며, 매 턴 선택·활성화를 강제하지 않는다.
- **AC-03**: 숨겨진 사건·단서의 존재와 확인 조건은 AI Game Master가 볼 수 있으며, 공개 조건 충족 후에도 게임 엔진이 허가하기 전에는 플레이어 출력에 포함되지 않는다.
- **AC-04**: AI Game Master는 추가 조회의 종류·대상·범위를 같은 실행에서 정하며, 별도 LLM 선행 판단은 없다.
- **AC-05**: 조회는 정본 상태·구조화 시나리오를 우선하며 필요 시 세션 고정 자료를 사용한다.
- **AC-06**: 상태 변경 검증, 요청 중복 방지, 굴림 소유권·대기, 공개 경계가 유지된다.
- **AC-07**: 응답 뒤 확인된 턴의 오래된 대화만 비동기 압축되고, 다음 턴의 현재 상황은 최신 저장 상태에서 온다. 시츄에이션 종료 후에도 확인된 관련 대화는 유지되며 압축 실패 시 유효한 요약과 원문이 보존되고 응답은 진행된다.
- **AC-08**: 선택 정보 누락 시 확인된 정보로 진행하고, 필수 근거 실패 시 판정·공개·확정을 보류하고 재시도한다.
- **AC-09**: Codex를 사용하는 전체 성공 턴의 5초 이내 완료 목표에는 5초를 넘긴 성공 턴도 포함하며, 초과 시 동일 요청을 계속 처리한다. 평균이나 빠른 일부 턴만으로 충족을 판정하지 않고, 실측 전 달성을 주장하지 않는다.

- **AC-10**: Codex 이외의 AI 제공자는 입력·근거·응답 경로에 이번 변경으로 인한 동작 변화가 없다.
- **AC-11**: Codex GM 실행은 기존 시츄에이션 선택 규칙으로 활성화·완료를 제안할 수 있으며, 조회 자체는 상태를 바꾸지 않는다. 제안은 같은 턴의 검증된 상태 변경으로만 반영되고, 주사위 대기·턴 실패 시 선반영되지 않으며, 재시도에 중복 적용되지 않는다.
- **AC-12**: 일반·무판정·대화·주사위 대기·전투·요약 턴 모두 플레이어용 Narration Agent는 엔진이 공개 허가한 정보만 입력받는다. GM 내부 서술, 도구 이력, 비공개 기억은 전달되지 않으며, 허가되지 않은 정보는 플레이어 서술에서 제외된다. 기존 공개 경계 밖의 새 선택·안전성 LLM 단계는 추가하지 않는다.
- **AC-13**: GM 판단과 서술을 포함한 Codex 전체 성공 턴은 기존 5초 목표 범위에 계속 포함된다. 이 공개 경계 변경으로 별도 요청 수나 목표 시간을 약속하지 않는다.
