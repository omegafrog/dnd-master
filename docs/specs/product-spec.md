# Product Spec: AI Game Master Runtime

## 1. Problem and Context

Solo Player는 이미 준비된 Scenario Bundle, 검색 가능한 룰북·스토리북 근거, 캐릭터 시트, Adventure Story Plan, 누적 진행 상태를 가지고도 실제 모험을 일관되게 진행할 GM이 필요하다. AI Game Master는 단순 대화 생성기가 아니라 이 자료를 함께 읽고 장면 진행, NPC 반응, 규칙 판정, 상태 반영, 비밀 관리, 세션 재개를 담당해야 한다.

번들에 맵 이미지가 있으면 텍스트 설명만으로 진행하지 않고 적절한 장면에서 격자 맵을 제공해야 한다. Solo Player의 토큰 드래그와 맵 상호작용 자체가 입력이 되며, AI Game Master는 그 의미와 결과를 판단해야 한다. 장기 세션에서는 컨텍스트를 압축하되 최신 상황과 정본 상태를 잃어서는 안 된다.

## 2. Goals and Desired Outcomes

- **PR-001** AI Game Master는 잠긴 번들, Session Knowledge Set, 캐릭터 시트, Adventure Story Plan, 확정 진행 기록을 바탕으로 GM 역할을 수행한다.
- **PR-002** Solo Player는 자유 텍스트 또는 직접적인 맵 조작으로 모험에 참여한다.
- **PR-003** AI Game Master는 장면 서술, NPC 행동, 판정, 결과, 상태 변화, 다음 행동 요청을 일관된 GM Turn으로 제공한다.
- **PR-004** 예상 밖 플레이어 행동을 수용해 미공개 계획을 재구성하고 원래 줄거리로 강제 복귀시키지 않는다.
- **PR-005** 번들 맵을 적절한 장면에서 자동 활성화하고 격자, 토큰, 전장의 안개로 탐험과 전투를 지원한다.
- **PR-006** 모든 확정 결과를 저장해 재접속과 모델 변경 뒤에도 동일한 모험을 이어간다.
- **PR-007** 장기 세션을 compaction해도 캐릭터와 런타임 정본, 최신 장면, 해결되지 않은 상황을 보존한다.
- **PR-008** 로컬 모델로 시작하되 GM 품질이 합의된 기준에 미달하면 대체 모델로 전환할 수 있다.

## 3. Users and Actors

- **Solo Player**: 캐릭터 행동을 자유 텍스트로 입력하거나 Tactical Map에서 직접 조작한다. GM 비밀 정보에는 접근하지 않는다.
- **AI Game Master**: 모험을 진행하고 규칙과 서사를 판정한다. 플레이어 대신 캐릭터 의도를 결정하지 않는다.
- **Rule Authority**: 룰북에서 도출된 판정, 시간, 이동, 효과 규칙과 정식 주사위 결과를 제공한다.
- **Adventure Runtime**: 확정된 진행, 캐릭터·월드·맵 상태를 보존하고 GM Turn의 원자성을 보장한다.

## 4. Ubiquitous Language and Terminology

- **GM Turn**: 플레이어 입력 하나를 판정하고 서술과 상태 변화를 함께 확정하는 단위. 전투 턴 또는 게임 내 시간과 다르다.
- **Tactical Map**: 번들에서 감지되고 모험 계획의 장면·장소·조건과 연결된 정사각 격자 맵.
- **Map Interaction Candidate**: 확인 팝오버에서 승인되기 전의 토큰 이동 또는 맵 상호작용.
- **Fog of War**: 현재 가시, 과거 탐험, 미탐험 영역을 구분하는 맵 공개 상태.
- **Last Seen Token**: 시야에서 사라진 공개 몬스터의 마지막 칸에 최근 1턴 동안 표시하는 축소 토큰.
- **GM Context Compaction**: 확정 상태 저장 후 과거 진행을 내부 요약으로 줄이고 최신 상황을 원문으로 유지하는 과정.
- 나머지 공통 용어는 `CONTEXT.md`를 따른다.

## 5. Core Use Cases

### UC-001 자유 텍스트로 모험 진행

1. Solo Player가 자유 형식으로 캐릭터 행동을 입력한다.
2. AI Game Master가 현재 장면, 캐릭터, 계획, 진행 기록, 관련 RAG 근거를 함께 해석한다.
3. 필요한 경우 판정과 주사위 굴림을 수행한다.
4. AI Game Master가 장면 서술, 판정 결과와 근거, 상태 변화, 다음 행동 요청을 응답한다.
5. 전체 결과가 하나의 GM Turn으로 확정된다.

### UC-002 예상 밖 행동에 맞춰 계획 적응

1. Solo Player가 Adventure Story Plan의 예상 경로와 다른 행동을 한다.
2. AI Game Master는 이미 공개되거나 확정된 사실을 유지한다.
3. 아직 공개되지 않은 장면, 분기, NPC 행동, 결말을 새 상황에 맞게 재계획한다.
4. 원래 경로로 강제 복귀시키지 않고 결과를 진행 기록에 확정한다.

### UC-003 장면에 맞는 Tactical Map 표시

1. 번들 컴파일 과정에서 맵 이미지가 감지된다.
2. Adventure Story Plan 작성 시 맵이 장면, 장소, 진입 조건에 연결된다.
3. 런타임 진행이 연결 조건을 만족하면 AI Game Master가 별도 맵 창을 활성화한다.
4. 현재 장면의 공개 가능한 영역과 토큰만 표시한다.
5. 사용할 맵이 없으면 텍스트 진행을 계속한다.

### UC-004 토큰 드래그로 이동

1. Solo Player가 제어 가능한 파티 토큰을 정사각 격자의 다른 칸으로 드래그한다.
2. 드롭 위치에 이동 요약과 확인·취소를 제공하는 팝오버가 표시된다.
3. 취소하면 토큰이 원위치로 돌아간다.
4. 확인하면 맵 조작 자체가 플레이어 입력이 된다.
5. AI Game Master가 거리, 지형, 장애물, 턴 순서, 시야, 숨은 사건을 판단한다.
6. 허용하면 이동과 파생 결과를 확정하고, 보정 또는 거부하면 최종 위치와 이유를 응답한다.

### UC-005 맵 오브젝트와 상호작용

1. Solo Player가 문, 조사 오브젝트, 공개 대상 토큰 또는 맵 위치를 선택한다.
2. 확인 팝오버에서 행동을 확정하거나 취소한다.
3. 확정 시 AI Game Master가 관련 장면, 규칙, 비밀 정보, 발견 조건을 판정한다.
4. 문·안개·토큰·캐릭터 상태와 서술을 함께 확정한다.

### UC-006 Fog of War와 숨은 대상 관리

1. 플레이어 토큰의 시야와 벽, 문, 장애물을 기준으로 가시 영역을 계산한다.
2. 현재 보이는 영역은 선명하게, 과거 탐험 영역은 어둡게, 미탐험 영역은 완전히 숨긴다.
3. 숨은 몬스터와 함정은 발견 판정, 직접 노출 또는 서사 사건 전까지 표시하지 않는다.
4. 공개 몬스터가 시야에서 벗어나면 최근 1턴 동안 마지막 칸에 축소 토큰을 표시한다.
5. 발견한 함정은 계속 표시한다.

### UC-007 게임 시간과 지속 효과 계산

1. AI Game Master가 룰북의 턴, 라운드, 실시간 변환 규칙을 적용한다.
2. 비전투 행동은 실제 행동의 성격에 따라 필요한 턴 수만큼 시간을 진행한다.
3. 전투 시간, 효과 지속시간, 재사용, 제한시간, 이동을 누적 시간에 맞춰 판정한다.
4. 룰북에 변환 규칙이 없으면 5턴을 1분으로 사용한다.

### UC-008 세션 저장과 재개

1. GM Turn이 성공하면 행동, 판정, 상태 변화, 발견 정보, 모험 위치를 함께 저장한다.
2. Solo Player가 재접속하면 마지막 확정 지점부터 재개한다.
3. 실패한 GM Turn의 일부 결과는 남기지 않는다.

### UC-009 GM Context Compaction

1. compaction 전에 진행 중 GM Turn과 판정을 완료한다.
2. 캐릭터 시트, 자원, 효과, 위치, 게임 시간, 맵 상태를 저장한다.
3. 전투와 탐험의 과거 기록을 행동별 로그가 아니라 줄거리, 결정, 발견, 결과 중심으로 내부 요약한다.
4. 마지막 플레이어 입력 또는 맵 조작, 직전 장면, 마지막 GM 응답, 현재 턴·위치·토큰·안개, 미해결 위협과 선택은 압축하지 않고 그대로 보존한다.
5. 요약은 사용자에게 노출하지 않는다.

### UC-010 메타 질문

1. Solo Player가 규칙, 현재 상태, 판정 이유를 묻는다.
2. AI Game Master가 근거와 현재 상태를 설명한다.
3. 모험 턴, 시간, 상태는 진행하지 않는다.

### UC-011 모험 종료

1. 계획의 결말, 파티 전멸 또는 사용자의 명시적 종료가 발생한다.
2. AI Game Master가 최종 장면과 결과 요약을 제시한다.
3. Solo Player 확인 후 세션을 종료한다.
4. 종료 세션은 변경할 수 없고 기록만 열람할 수 있다.

## 6. Business Rules and Invariants

- **BR-001** 확정 사실의 우선순위는 진행 기록, 현재 캐릭터·월드 상태, 잠긴 번들·모험 계획, RAG 원문 근거 순이다.
- **BR-002** 규칙 자료와 서사 자료는 용도에 맞게 구분한다. 해결할 수 없는 충돌은 추측하지 않고 Solo Player에게 확인한다.
- **BR-003** 플레이어는 캐릭터 의도를 결정하고 AI Game Master는 세계, NPC, 규칙, 결과, 다음 전개를 결정한다.
- **BR-004** AI Game Master는 이미 발생한 결과와 공개된 세계 사실을 소급 변경할 수 없다.
- **BR-005** 실제 주사위 결과는 정식 굴림 결과를 사용한다. AI Game Master가 결과를 임의 생성할 수 없다.
- **BR-006** 판정 응답은 판정식, 결과, 성공·실패, 규칙 근거를 표시한다. 서사 스포일러가 되는 근거는 공개하지 않는다.
- **BR-007** HP, 자원, 효과, 진행 변화는 판정 결과와 같은 GM Turn에서 반영한다.
- **BR-008** 미래 분기, 결말, NPC 의도, 미발견 지도·함정·적은 발견 전 공개하지 않는다.
- **BR-009** 맵은 정사각 격자를 사용하며 토큰은 격자 칸 단위로 이동한다.
- **BR-010** 맵 조작은 확인 팝오버 승인 전까지 상태를 변경하지 않는다. 새 조작을 시작하면 기존 후보는 취소한다.
- **BR-011** 드래그 중 미리보기는 GM Turn을 만들지 않는다. 확인된 드롭 또는 상호작용만 GM Turn을 만든다.
- **BR-012** GM Turn 처리 중 추가 텍스트·맵 입력은 허용하지 않는다.
- **BR-013** 플레이어 파티 토큰만 Solo Player가 이동할 수 있다. NPC, 몬스터, 함정 토큰의 상태는 AI Game Master가 관리한다.
- **BR-014** 기본 토큰 세트는 플레이어 캐릭터, 우호 NPC, 중립 NPC, 적대 몬스터, 보스, 발견된 함정, 상호작용 오브젝트를 포함한다.
- **BR-015** 범례는 색상만이 아니라 아이콘, 테두리, 라벨로 토큰 종류를 구분한다.
- **BR-016** 숨은 대상의 이름, 이미지, 좌표는 발견 전 플레이어에게 제공하지 않는다.
- **BR-017** Last Seen Token의 1턴은 룰북의 턴 정의를 사용하고, 없으면 12초를 사용한다.
- **BR-018** GM 응답 횟수와 게임 시스템의 턴·시간은 별개다.
- **BR-019** 전투의 엄격한 턴 순서는 게임 규칙이 요구할 때만 적용한다.
- **BR-020** 맵은 탐험, 잠입, 추격, 전투에 사용할 수 있다.
- **BR-021** 맵 연결은 고정 턴 번호가 아니라 장면, 장소, 진입 조건을 사용한다.
- **BR-022** 모험 계획의 토큰 배치는 원문 좌표를 우선한다. 원문 좌표가 없으면 합리적 배치를 허용하되 원문 명시가 아님을 구분한다.
- **BR-023** GM Context Compaction은 사용자에게 노출하지 않는다.
- **BR-024** 미확정 맵 조작, 진행 중 판정, 처리 중 GM Turn이 있으면 compaction할 수 없다.
- **BR-025** 캐릭터 또는 런타임 상태 저장 실패 시 compaction을 중단하고 이전 컨텍스트를 유지한다.
- **BR-026** GM 모델이 바뀌어도 같은 자료, 상태, 규칙, 응답 계약을 사용해야 한다.

## 7. States and State Transitions

### GM Turn

`READY` → `PROCESSING` → `COMMITTED`

- 처리 실패: `PROCESSING` → `FAILED` → `READY`
- `COMMITTED` 결과만 진행 기록과 상태에 남는다.

### Map Interaction Candidate

`PREVIEWING` → `AWAITING_CONFIRMATION` → `CONFIRMED` → `PROCESSING` → `COMMITTED`

- 드래그 취소 또는 팝오버 취소: `PREVIEWING|AWAITING_CONFIRMATION` → `CANCELLED`
- GM 처리 실패: `PROCESSING` → `FAILED`; 후보와 기존 확정 상태는 유지한다.

### Tactical Map

`UNAVAILABLE` | `AVAILABLE` → `ACTIVE` → `INACTIVE`

- 연결된 장면 진입 시 `AVAILABLE` → `ACTIVE`.
- 다른 장소로 이동하거나 장면 종료 시 `ACTIVE` → `INACTIVE`.
- 다시 연결 조건을 만족하면 재활성화할 수 있다.

### Adventure Session

`ACTIVE` → `ENDING` → `ENDED`

- 종료 후보를 사용자가 거부하면 `ENDING` → `ACTIVE`.
- `ENDED`는 변경 불가다.

## 8. Failures, Exceptions, and Boundary Conditions

- **FR-001** GM 처리 실패 시 토큰, 문, 안개, 캐릭터, 진행 상태를 부분 확정하지 않는다.
- **FR-002** GM 처리 실패 응답의 일부를 노출하지 않고 오류와 동일 조작 재시도를 제공한다.
- **FR-003** 맵이 없거나 장면 연결에 실패해도 텍스트 모험을 계속한다.
- **FR-004** 미보정 또는 안전하게 공개할 수 없는 맵은 자동 표시하지 않는다.
- **FR-005** 스포일러가 포함된 GM용 맵을 안전하게 분리할 수 없으면 이미지 대신 텍스트로 진행한다.
- **FR-006** 이동이 규칙, 거리, 장애물, 턴 순서에 어긋나면 최종 위치를 확정하지 않고 이유를 알린다.
- **FR-007** RAG 검색 실패 시 근거 없는 규칙을 만들지 않는다. 현재 정본만으로 판단할 수 없으면 질문 또는 재시도를 제공한다.
- **FR-008** compaction 실패 시 기존 컨텍스트와 확정 상태를 유지한다.
- **FR-009** 맵 또는 텍스트 중복 입력은 하나의 GM Turn으로 중복 확정하지 않는다.
- **FR-010** 종료 확인 전에는 세션을 종료하지 않는다.

## 9. Inputs and Outputs

### Inputs

- 잠긴 Scenario Bundle Revision과 Scenario Package
- Session Knowledge Set의 RULEBOOK·STORYBOOK 근거
- 게시된 Game System Definition
- Adventure Story Plan과 현재 진행 단계
- 캐릭터 시트, 파티, 자원, 효과, 위치
- 확정 세션 기록과 게임 시간
- Solo Player의 자유 텍스트
- 확인된 토큰 이동, 문·오브젝트 클릭, 대상·위치 선택
- Tactical Map, 격자, 벽, 문, 장애물, 토큰, 안개 상태

### Outputs

- 장면 및 NPC 서술
- 규칙 판정식, 주사위 결과, 성공·실패, 공개 가능한 근거
- 확정 캐릭터·월드·진행·게임 시간 변화
- 맵 활성화·비활성화
- 확정 토큰 위치, 문·오브젝트 상태, Fog of War 변화
- 공개·은닉·Last Seen Token 변화
- 다음 행동 요청 또는 메타 질문 답변
- 내부 전용 compaction 요약과 압축하지 않은 최신 상황

## 10. Scope and Non-goals

### In Scope

- 단일 Solo Player와 AI Game Master의 모험 진행
- 자유 텍스트 및 별도 맵 창 상호작용
- 정사각 격자 기반 탐험·전투
- 기본 토큰 세트와 범례
- 자동 전장의 안개와 비밀 관리
- 룰북 기반 판정·게임 시간·효과 처리
- 저장, 재개, 내부 compaction, GM 모델 교체

### Non-goals

- 인간 GM용 관리 화면
- 멀티플레이어 동시 조작
- 육각 격자
- 자유 그림, 측정선, 지형 편집
- 사용자 임의 토큰 생성 또는 토큰 이미지 편집
- 번들에 없는 맵 자동 생성
- 플레이어에게 compaction 요약 표시
- 미공개 GM 정보 또는 전체 Adventure Story Plan 공개

## 11. Priorities and Trade-offs

1. 확정 상태와 규칙 정확성
2. GM 비밀과 스포일러 보호
3. 최신 상황과 모험 연속성
4. 플레이어 자유 행동과 계획 적응성
5. 맵 상호작용의 자연스러움
6. 응답 속도와 모델 비용

규칙 정확성, 상태 일관성, 비밀 보호가 응답 속도보다 우선한다. 로컬 모델을 우선 사용하지만 품질 기준을 만족하지 못하면 대체 모델로 전환한다. 모델 교체는 진행 정본이나 제품 동작을 바꾸지 않는다.

## 12. Success Conditions and Acceptance Criteria

- **AC-001 / PR-001, PR-003** 준비된 번들과 캐릭터로 시작한 세션에서 AI Game Master가 관련 계획·진행·근거를 사용해 연속된 GM Turn을 제공한다.
- **AC-002 / PR-004** 계획 밖 행동 뒤에도 공개 사실을 유지하며 새로운 유효 장면으로 진행하고 원래 경로를 강요하지 않는다.
- **AC-003 / PR-003** 규칙 판정이 필요한 응답마다 판정식, 정식 주사위 결과, 결과, 공개 가능한 근거가 일치한다.
- **AC-004 / PR-006** GM Turn 실패를 강제로 발생시켜도 캐릭터, 진행, 맵 중 일부만 변경되지 않는다.
- **AC-005 / PR-005** 번들 맵이 계획의 연결 조건을 만족하는 장면에서 별도 맵 창에 자동 표시된다.
- **AC-006 / PR-005** 토큰을 드래그한 뒤 확인 전에는 상태가 변하지 않고, 취소하면 원위치, 확인하면 GM 판단과 응답이 발생한다.
- **AC-007 / PR-005** 벽 너머와 미탐험 영역, 미발견 몬스터·함정 정보가 플레이어 응답과 맵 데이터에 노출되지 않는다.
- **AC-008 / PR-005** 공개 몬스터가 시야를 벗어나면 축소 토큰이 마지막 칸에 표시되고 룰북 기준 1턴 뒤 제거된다.
- **AC-009 / PR-005** 문 열기 또는 이동 뒤 시야와 Fog of War가 새 확정 상태에 맞게 갱신된다.
- **AC-010 / PR-003** 룰북의 시간 규칙이 있으면 해당 규칙, 없으면 5턴=1분 기준으로 지속 효과와 제한시간이 일관되게 계산된다.
- **AC-011 / PR-006** 재접속 또는 GM 모델 변경 뒤에도 마지막 확정 장면, 캐릭터, 게임 시간, 맵 상태에서 계속된다.
- **AC-012 / PR-007** compaction 뒤 과거 전투·탐험은 줄거리와 결과 중심으로 회상되며 마지막 입력·장면·응답·현재 상태는 원문 수준으로 보존된다.
- **AC-013 / PR-007** 상태 저장 실패 또는 진행 중 GM Turn에서는 compaction이 실행되지 않는다.
- **AC-014 / PR-008** 동일 평가 시나리오에서 규칙 정확성, 계획 일관성, 비밀 누출, 상태 변경 정확성을 측정해 로컬 모델의 유지 또는 대체 모델 전환을 판단할 수 있다.
- **AC-015 / PR-003** 메타 질문은 답변하지만 게임 시간과 모험 상태를 진행하지 않는다.
- **AC-016 / PR-006** 종료 후보는 사용자 확인 전 확정되지 않고, 종료 후 세션 기록은 변경되지 않는다.
