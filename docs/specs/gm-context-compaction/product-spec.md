# Product Spec: GM Context Compaction

## 1. Problem and Context

긴 모험이 진행될수록 AI Game Master가 한 번의 codex exec 호출에 전달하는 프롬프트에는 이전 대화, 현재 상황을 이해하는 데 필요한 오래된 기록, 캐릭터 시트, 이번 턴 근거가 함께 쌓인다. 이 정보가 서로 구분되지 않고 매번 전달되면 이전 상황을 이어가기 어려워지고, 반복되는 입력의 재사용 성능과 전체 입력 비용이 나빠질 수 있다.

이번 범위는 모험 진행 중 시작 장면 구성, 일반 GM Turn, 전투 중 AI Game Master 서술에 사용할 입력을 정리한다. 확정된 Current Situation을 기준으로 현재 상황에 관련된 장기 기록을 구성하고, 고정된 순서의 단일 프롬프트 안에 최근 대화와 최신 정본 상태를 담는다. 시나리오 사전 구성은 범위에 포함하지 않는다. Stage를 사전 진행하는 모델을 전제로 하지 않는다.

## 2. Goals and Desired Outcomes

- **G-01** 매 호출에서 codex exec를 한 번만 사용하고, 모든 입력 정보를 하나의 프롬프트에 정해진 순서로 제공한다.
- **G-02** 이전 상황 이해에 필요한 기록을 보존하면서 확정된 GM Turn 이후 오래된 대화만 압축해 이후 턴부터 반영한다.
- **G-03** 최신 캐릭터 시트와 Current Situation, 이번 턴 근거, 플레이어 입력을 최신 정본에 따라 제공하고, 대화 요약으로 정본 수치를 변경하지 않는다.
- **G-04** 반복 입력의 재사용 성능과 모험 전체 입력 비용을 기존 방식보다 개선하면서 사실 정확성과 판정 근거를 지킨다.
- **G-05** 비공개 사실이나 내부 처리 계획을 플레이어에게 누설하지 않는다.

## 3. Users and Actors

- **Solo Player**: 모험 중 행동을 입력하고 AI Game Master의 응답을 받는 유일한 인간 플레이어다.
- **AI Game Master**: 시작 장면, 일반 GM Turn, 전투 중 서술을 위해 전달된 프롬프트를 사용한다. 전달된 근거 범위를 지키며 장면을 진행한다.
- **GM Context Compaction**: 확정된 GM Turn 후 오래된 대화만 줄여 이후 턴의 맥락으로 제공하는 과정이다. 캐릭터 시트와 Current Situation 같은 확정 상태를 대화 요약으로 갱신하지 않는다.
- **Adventure Runtime**: GM Turn과 Current Situation 등 확정된 모험 상태를 제공하고, 플레이어에게 보일 결과를 확정한다.

## 4. Ubiquitous Language and Terminology

- **GM Context Compaction**: 확정된 GM Turn 후 오래된 대화 기록만 줄여 이후 대화에서 이전 상황을 이어가게 하는 과정이다. 캐릭터 시트와 Current Situation 같은 확정 상태는 대화 요약으로 갱신하지 않고 최신 정본을 별도로 전달한다.
- **Current Situation**: 현재 플레이에서 확인된 장소·문제·위협·목표를 나타내는 현재 상황이다.
- **GM Turn**: Solo Player의 텍스트 입력 또는 확정된 맵 상호작용 하나를 AI Game Master가 해석하고, 판정·서술·상태 변화·다음 상황을 하나의 원자적 결과로 확정하는 진행 단위다.

프롬프트에서 각 정보의 위치와 역할은 5절에서 평이한 설명으로 구분한다.

### UC-01 단일 프롬프트를 구성한다

모험 진행 중 시작 장면, 일반 GM Turn 또는 전투 중 AI Game Master 서술을 요청할 때, 시스템은 매번 codex exec를 한 번 호출한다. 하나의 프롬프트에 다음 구역을 이 순서로 둔다.

1. 고정 지침·잠긴 자료
2. 현재 상황 관련 장기 기록
3. 압축된 이전 대화
4. 압축하지 않은 최근 대화
5. 최신 캐릭터 시트·Current Situation·이번 턴 근거·플레이어 입력

각 구역에는 모델이 실제로 사용할 수 있는 입력 한도 대비 최대 비율과 최소 보장량을 둔다. 정확한 비율과 토큰 수는 Architecture 단계에서 정한다. 구역에 배정된 공간을 사용하지 않으면 남은 공간은 이번 턴 근거와 최근 대화에 제공한다. 모델 응답에 필요한 여유 공간도 확보한다.

### UC-02 확정된 GM Turn 후 오래된 대화를 압축한다

GM Turn이 확정되면 오래된 대화만 압축하고, 새 요약은 다음 턴부터 사용한다. 최근 입력, 장면, 응답 및 진행 중인 굴림·선택은 원문 그대로 보존한다. 요약은 인물 발언과 장면 흐름, 이전 상황 이해에 필요한 결과와 미해결 문제를 남긴다. HP, 자원, 위치, 전투 상태 같은 정본 수치는 대화 요약으로 갱신하지 않는다.

이후 플레이에 영향을 주는 확정 사건·관계·목표·위협이 바뀐 경우에만 현재 상황 관련 장기 기록을 갱신한다. 단순 대화마다 갱신하지 않는다. 장기 기록은 모험별로 보존하며 캐릭터 시트 정본을 복제하지 않는다.

### UC-03 요약을 재압축하고 관련 기록을 선택한다

압축된 대화 요약이 고정 구역에 모두 들어가지 않으면 오래된 요약을 재압축한다. 재압축 후에도 기록 전체가 프롬프트에 들어가지 않으면 전체 기록을 보존한 채 현재 상황과 관련된 오래된 요약만 선택해 제공한다. 압축하지 않은 최근 대화는 이 과정에서 줄이지 않는다.

### UC-04 압축 실패를 복구한다

확정된 GM Turn 후 압축에 실패해도 그 턴의 플레이어 응답은 전달한다. 마지막 정상 요약과 원문을 보존하고 압축을 재시도한다. 적절한 분량의 재시도 결과는 다음 GM 요청부터 사용한다. 다음 GM 요청을 준비할 때도 필수 정보가 들어오지 않으면 그 요청에 대해 재시도 가능한 오류를 반환한다. 요약이 정확하지 않거나 근거가 부족하면 캐시 성능을 위해 채택하지 않는다.

## 6. Business Rules and Invariants

- **BR-01** AI Game Master 호출은 한 번의 codex exec이며, 입력 구역은 단일 프롬프트 안에 정해진 순서로 배치한다.
- **BR-02** 구역의 순서는 고정 지침·잠긴 자료, 현재 상황 관련 장기 기록, 압축된 이전 대화, 압축하지 않은 최근 대화, 최신 캐릭터 시트·Current Situation·이번 턴 근거·플레이어 입력 순이다.
- **BR-03** 각 구역은 모델의 실제 가용 입력 한도에 대한 최대 비율과 최소 보장량을 갖는다. 정확한 값은 Architecture 단계에서 결정한다.
- **BR-04** 미사용 입력 공간은 이번 턴 근거와 최근 대화에 제공하며 응답 생성 공간을 남긴다.
- **BR-05** 캐시 성능은 순서 고정만으로 보장되지 않으며 실측 결과로 판단한다.
- **BR-06** 압축 대상은 확정된 GM Turn보다 오래된 대화뿐이며 압축 결과는 다음 턴부터 적용한다.
- **BR-07** 최근 입력·장면·응답과 진행 중인 굴림·선택은 원문으로 보존한다.
- **BR-08** 대화 요약은 인물 발언, 장면 흐름, 이전 상황 이해에 필요한 결과와 미해결 문제를 보존한다.
- **BR-09** HP·자원·위치·전투 상태 등 정본 수치는 요약으로 갱신하지 않고 최신 정본을 별도로 전달한다.
- **BR-10** 현재 상황 관련 장기 기록은 확정 사건·관계·목표·위협이 이후 플레이에 영향을 주도록 바뀔 때에만 갱신한다.
- **BR-11** 장기 기록은 모험별로 보존하며 캐릭터 시트 정본을 복제하지 않는다.
- **BR-12** 대화 요약은 고정 구역에 누적한다. 공간이 부족하면 오래된 요약을 재압축하고, 그래도 넘치면 전체 기록을 보존하면서 현재 상황과 관련된 오래된 요약만 프롬프트에 선택한다.
- **BR-13** 압축 실패 시 마지막 정상 기록과 원문을 보존하고 재시도한다. 필수 정보가 계속 들어오지 않으면 재시도 가능한 오류를 반환한다.
- **BR-14** 사실 정확성과 판정 근거가 캐시 성능보다 우선한다.
- **BR-15** 내부 계획과 플레이어에게 공개되지 않은 사실은 사용자에게 누설하지 않는다.

## 7. States and State Transitions

해당 없음 — 독립된 업무 상태가 없다. 압축과 재압축은 플레이어가 별도 업무로 수행하거나 검토하는 흐름이 아니라 GM Turn 입력을 준비하는 내부 과정이다.

## 8. Failures, Exceptions, and Boundary Conditions

- 확정된 GM Turn 후 압축 결과가 실패하거나 유효하지 않아도 해당 턴의 플레이어 응답은 전달한다. 마지막 정상 요약과 원문을 보존하고 재시도한다.
- 다음 GM 요청을 준비할 때 재시도 후에도 필수 정보와 최신 입력을 보장할 수 없으면 그 요청에 대해 재시도 가능한 오류를 반환한다.
- 전체 기록을 프롬프트에 담을 수 없을 때는 기록 자체를 삭제하지 않고, 현재 상황에 관련된 오래된 요약만 골라 제공한다.
- 정본 수치의 최신 값이 요약과 다르면 캐릭터 시트와 Current Situation 등 별도 전달되는 최신 정본을 따른다.
- 캐시 성능 개선과 정보 정확성 또는 판정 근거가 충돌하면 정확성과 근거를 우선한다.
- 프롬프트 내용에 내부 계획이나 비공개 사실이 섞여 플레이어에게 전달될 위험이 없어야 한다.

## 9. Inputs and Outputs

**입력**은 고정 지침과 잠긴 자료, 현재 상황 관련 장기 기록, 압축된 이전 대화, 압축하지 않은 최근 대화, 최신 캐릭터 시트, Current Situation, 이번 턴 근거, 플레이어 입력이다.

**AI Game Master에 제공하는 결과**는 고정 순서와 구역별 입력 한도·최소 보장량을 적용한 단일 프롬프트다. 요약 갱신이 필요한 경우 확정된 GM Turn 뒤 생성된 대화 요약과 조건을 만족할 때 갱신된 현재 상황 관련 장기 기록을 다음 턴부터 사용한다.

**플레이어가 받는 결과**는 GM Turn의 응답 또는 필수 정보가 계속 부족할 때의 재시도 가능한 오류다. 내부 처리 계획과 비공개 사실은 포함하지 않는다.

## 10. Scope and Non-goals

이번 범위에는 모험 진행 중 시작 장면, 일반 GM Turn, 전투 중 AI Game Master 서술을 위한 단일 프롬프트 구성, 오래된 대화의 압축·재압축·관련 요약 선택, 상황에 따른 장기 기록 갱신, 압축 실패 복구가 포함된다.

다음은 범위에 포함하지 않는다.

- 시나리오 사전 구성
- Stage 사전 진행 모델
- 캐릭터 시트나 Current Situation을 대화 요약으로 갱신하는 것
- 단순 대화마다 장기 기록을 갱신하는 것
- 플레이어에게 내부 계획 또는 비공개 사실을 공개하는 것
- 구역별 최대 비율과 최소 입력량의 정확한 수치 결정 (Architecture 단계에서 정한다)

## 11. Priorities and Trade-offs

1. 사실 정확성과 판정 근거를 입력 재사용 성능보다 우선한다.
2. 정본 수치와 최신 상황을 정확히 전달하면서 오래된 대화의 맥락을 보존한다.
3. 최근 입력·장면·응답 및 진행 중인 굴림·선택의 원문 보존을 압축량보다 우선한다.
4. 고정된 구역 순서로 반복 입력의 재사용을 돕되, 개선 여부는 실측으로 확인한다.
5. 장기 기록은 이후 플레이에 영향을 주는 확정 변화에 한정해 갱신하고, 대화가 늘어날 때는 오래된 요약을 재압축하거나 관련 기록을 선택한다.

## 12. Success Conditions and Acceptance Criteria

- **AC-01** 시작 장면, 일반 GM Turn, 전투 중 AI Game Master 서술의 각 호출이 codex exec 한 번과 단일 프롬프트를 사용한다.
- **AC-02** 프롬프트 구역이 고정 지침·잠긴 자료 → 현재 상황 관련 장기 기록 → 압축된 이전 대화 → 압축하지 않은 최근 대화 → 최신 캐릭터 시트·Current Situation·이번 턴 근거·플레이어 입력 순으로 배치된다.
- **AC-03** 각 구역에 실제 가용 입력 한도에 대한 최대 비율과 최소 보장량이 적용되고, 미사용 공간은 이번 턴 근거와 최근 대화에 제공되며 응답 여유가 남는다. 구체 수치는 Architecture 단계에서 정해진다.
- **AC-04** 확정 GM Turn 후 오래된 대화만 압축되고 압축 결과는 다음 턴부터 반영된다. 최근 내용과 진행 중인 굴림·선택은 원문으로 남는다.
- **AC-05** 대화 요약은 인물 발언, 장면 흐름, 이전 상황 이해에 필요한 결과와 미해결 문제를 보존하며 HP·자원·위치·전투 상태 등 정본 수치를 변경하지 않는다.
- **AC-06** 현재 상황 관련 장기 기록은 이후 플레이에 영향을 주는 확정 사건·관계·목표·위협이 바뀔 때 갱신되고, 단순 대화만으로는 갱신되지 않는다. 장기 기록은 모험별로 보존하고 캐릭터 시트 정본을 중복 저장하지 않는다.
- **AC-07** 누적 요약이 고정 구역에 들어가지 않으면 오래된 요약을 재압축한다. 그래도 전체 기록이 들어가지 않으면 기록 전체를 보존하고 현재 상황과 관련된 오래된 요약만 선택한다.
- **AC-08** 확정된 GM Turn 후 압축이 실패해도 해당 턴의 플레이어 응답이 전달되고 마지막 정상 요약과 원문이 보존된 채 재시도된다. 적정 분량의 재시도 결과는 다음 GM 요청부터 사용한다. 다음 GM 요청 준비 중에도 필수 정보가 들어오지 않으면 그 요청에 대해 재시도 가능한 오류가 반환된다.
- **AC-09** 동일한 긴 모험과 시나리오에서 기존 방식과 비교했을 때 입력 재사용량이 늘고 모험 전체 입력 비용이 줄어든다. 비교는 실측한다.
- **AC-10** 긴 모험에서도 확정 사실과 최근 상황이 보존되어 다음 응답이 이전 장면을 이어가며, 내부 계획과 비공개 사실은 플레이어에게 노출되지 않는다.
