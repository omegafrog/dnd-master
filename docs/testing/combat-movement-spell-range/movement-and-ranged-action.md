# 실제 모험에서 지도 이동과 원거리 행동 확인

## 목적

실제 모험 세션에서 지도 이동의 미리보기·확정·저장 결과와, 캐릭터가 실제로 가진 원거리 공격 또는 주문의 조준 미리보기·실행 결과를 확인한다. 에이전트 응답이 없는 화면 준비는 headed Chromium의 Playwright CLI로 한 단계씩 조작할 수 있다. 에이전트 응답이 필요한 요청은 매번 요청 전후 스크린샷과 실제 UI를 확인하고, 화면에 나타난 응답에 따라 진행한다. Playwright 테스트 코드, 고정 응답, 직접 API 호출을 사용하지 않는다.

## 준비

1. [저장소 E2E 실행 절차](../../agents/EXEC.md), [브라우저 연결 절차](../../agents/BROWSER.md), [ADR-024](../../adr/ADR-024-agent-driven-runtime-e2e.md)을 읽는다.
2. 활성 체크아웃과 서버 소유 경로를 확인한다. 이미 열린 사용자 세션이 있으면 서버·브라우저를 재시작하거나 데이터베이스를 초기화하지 않는다.
3. 저장소 E2E 안내의 산출물 보호 절차를 실행한다. 로그와 화면 증거는 Harness 세션 디렉터리 `runtime/e2e/` 아래에만 둔다.
4. [공통 E2E 안내](./README.md)에 적힌 세 원본 PDF를 새 시나리오 자료 묶음에 순서대로 넣고 각 파일에 지정된 역할을 선택한다. 화면에서 파일명과 역할이 모두 맞는지 확인한 뒤 자료 준비와 시나리오 생성을 마친다. 룰북은 이미 추출된 `DnD_BasicRules_2018.pdf` 자료를 재사용한다.
5. 생성된 시나리오 자료에 사용 가능한 지도 정의가 하나 이상 있는지 확인한다. 지도 파일이 자료 목록에 있어도 지도 정의가 없으면 모험을 시작하지 말고 준비 실패로 기록한다.
6. Chromium에서 열린 모험 세션을 다시 읽는다. 모험 ID, 세션 ID, 지도 ID, 플레이어 그룹 위치, 현재 차례와 이동 상태를 기록한다. 연결이 끊겼다면 저장된 상태를 먼저 확인하며 제출을 재전송하지 않는다.
7. 현재 캐릭터 시트와 모험에서 사용할 수 있도록 저장된 능력 정의를 확인한다. 시트에 없는 무기·주문·대상을 가정하지 않는다.

## 지도 이동

1. 지도에서 조종 가능한 플레이어 또는 현재 탐험 그룹 토큰을 선택한다.
2. 현재 시야 또는 이미 탐험한 칸 중 벽·닫힌 문·점유에 막히지 않은 목적지를 하나 고른다. 미탐험 칸을 눌러 숨겨진 정보를 추측하지 않는다.
3. 서버가 반환한 경로, 거리, 이동 비용과 미리보기 전 토큰 위치·이동량을 기록한다. 미리보기만으로 저장 위치나 이동량이 바뀌지 않는지 확인한다.
4. 목적지가 의도한 위치이고 남은 이동량 안에 있을 때 한 번만 확정한다. 완료까지 실제 에이전트 응답을 기다린다.
5. 새로 읽은 지도와 저장 상태에서 토큰이 서버 결과의 마지막 도달 칸에 있는지, 이동 비용·중단 사유가 응답과 일치하는지 확인한다. 사건이나 판정으로 이동이 끊기면 반환된 후속 절차를 따른다.
6. 같은 그룹 차례에서 이동 경로를 나눠 확정한다. 각 이동 비용이 누적되고, 남은 이동량 이하의 경로는 허용되며 초과하는 경로는 GM 턴 제출 전에 거부되는지 확인한다. 초과 안내가 표시되고 지도 버전 충돌로 오인해 새로고침·재시도하지 않는지도 확인한다. 같은 이동 결과를 복구·재요청해도 누적 비용이 중복되지 않는지 확인한다.

## 원거리 공격 또는 주문

1. 최신 지도에서 실제로 보이는 적 또는 합법적인 대상을 확인한다. 캐릭터 시트와 현재 모험의 저장된 정의에서 사용할 수 있는 원거리 공격·투척·주문을 하나 고른다.
2. 그 행동의 조준 화면에서 캐릭터 토큰을 시작점으로 사거리와 경로를 확인한다. 커서를 옮겨도 위치·자원·전투 상태가 바뀌지 않고, 공개되지 않은 대상이나 지도 정보가 드러나지 않는지 확인한다.
3. 실제 대상이 사거리·시야·경로 조건을 충족할 때만 한 번 실행한다. 여러 대상이나 배분 선택이 필요한 행동은 필요한 대상을 먼저 선택하고 명시적으로 실행한다.
4. 실제 에이전트 응답과 새로 읽은 저장 상태를 확인한다. 행동 결과, 적중·판정 결과, 자원 변화가 해당 행동 정의와 일치하고 비용이 한 번만 적용되는지 확인한다.

## 중단 조건

- 사용할 수 있는 원거리 능력이나 공개된 유효 대상이 없으면 다른 행동을 만들어 내거나 지도를 바꾸지 않는다. 관찰한 상태를 기록하고 원거리 확인은 `inconclusive`로 끝낸다.
- 입력 문자가 깨져 보이면 제출하지 않는다. 필드에 표시되는 문자열을 먼저 확인하고, 저장된 결과가 불분명하면 다시 제출하지 않는다.
- 이동·조준 또는 GM 요청에서 5xx, 명시적 실패, 연결 오류가 나오면 해당 E2E를 즉시 멈추고 화면과 오류를 기록해 사용자에게 보고한다. 사용자가 계속하라고 하기 전에는 재시도하거나 브라우저·서버를 종료하지 않는다.
- 원거리 실행이 플레이어의 턴·자원·상황을 바꾸므로 임의의 능력·대상을 선택하지 않는다. 합법적인 선택지가 확인되지 않으면 사용자에게 상황을 보고한다.

## 통과 기준

- 지도 이동 미리보기가 읽기 전용이고 경로·비용이 화면에 보인다.
- 확정된 이동의 서버 결과와 다시 읽은 위치·이동 상태가 일치한다.
- 원거리 행동의 사거리·경로·대상 표시가 실제 캐릭터 정의 및 지도 시야에 맞는다.
- 실행 결과와 저장된 자원·전투 상태가 일치하며 비용이 중복 적용되지 않는다.

이동과 원거리 행동을 모두 확인해야 전체 시나리오가 통과다. 사용할 수 있는 대상이나 능력이 없어 실행하지 못한 범위는 통과가 아니라 `inconclusive`로 기록한다.

## 증거

Harness 세션 `runtime/e2e/` 아래에 체크아웃 경로와 revision, 실행 명령·프로필, 서버 PID와 작업 디렉터리, 프런트엔드 URL, 세션·지도 식별자, 이동 전후 위치, 미리보기·실행 결과, 원거리 행동·자원 결과, 연결 복구 및 artifact cleanup 결과를 기록한다. 프롬프트 원문·인증정보·불필요한 플레이어 입력은 기록하지 않는다.
