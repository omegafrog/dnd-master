# 운영

이 프로젝트의 실행 기준은 Java 21과 Spring Boot 기반 서비스 묶음이다. 데이터 계층은 PostgreSQL과 pgvector를 사용하며, 로컬과 검증 환경은 동일한 계약과 포트 배치를 따른다.

## 실행 환경

| 항목 | 내용 |
| --- | --- |
| 런타임 | Java 21 |
| 애플리케이션 프레임워크 | Spring Boot, Spring AI |
| 데이터베이스 | PostgreSQL + pgvector |
| 서비스 간 통신 | 내부 HTTP |

## 운영 메모

- CI와 로컬 검증은 동일한 서비스 경계를 기준으로 맞춘다.
- UI는 별도 포트로 노출되며, Swagger UI와 runtime API 문서 확인 경로를 함께 사용한다.
- 롤백은 스키마 변경과 런타임 상태가 분리된 전제로 다룬다.
- AI 응답은 스트리밍이 포함되므로, 모니터링 시 단발성 요청보다 흐름 단위로 본다.
