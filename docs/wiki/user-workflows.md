# 사용자 흐름

이 문서는 UC-001부터 UC-010까지의 사용자 흐름을 요약한다. 모든 흐름의 출발점은 플레이어이며, AI GM은 별도 애그리게이트가 아닌 오케스트레이션 계층으로 동작한다.

## 유스케이스 요약

| UC | 흐름 | 결과 |
| --- | --- | --- |
| UC-001 | 플레이어가 로그인한다. | 인증된 플레이어 식별자가 만들어지고 이후 요청의 기준이 된다. |
| UC-002 | 플레이어가 PDF, DOCX, TXT 룰북을 등록한다. | 룰북이 추출, 분할, 인덱싱 가능한 상태로 준비된다. |
| UC-003 | 플레이어가 모험 시나리오를 등록한다. | 모험에 사용할 시나리오가 저장되고 준비 상태가 관리된다. |
| UC-004 | 플레이어가 적용할 룰 에디션을 고른다. | D&D 5e 2014 또는 2024 기준의 적용 룰셋이 확정된다. |
| UC-005 | 플레이어가 적용 룰셋을 관리한다. | 모험에 사용할 룰북 조합과 선택 규칙이 유지된다. |
| UC-006 | 플레이어가 AI GM과 모험을 진행한다. | 장면 진행, NPC, 서술, 판정, 스트리밍 응답이 이어진다. |
| UC-007 | 플레이어가 근거가 표시된 룰 답을 확인한다. | 질의에 대한 답, 근거 위치, 후보 규칙이 제공된다. |
| UC-008 | 플레이어가 주사위를 굴린다. | 판정용 주사위 결과가 저장되고 AI GM 흐름에 반영된다. |
| UC-009 | 플레이어가 전투 맵에서 전투를 진행한다. | 전투 토큰, 이동, 가시성, AI 상태가 맵 기준으로 관리된다. |
| UC-010 | 플레이어가 저장한 모험을 다시 열거나 삭제한다. | 저장된 모험을 재개하거나 삭제 상태로 전환한다. |

## 흐름 메모

- UC-002는 단순 업로드가 아니라 추출, 일부 실패 확인, 분할, 인덱싱까지 포함한다.
- UC-006은 AI GM의 대화형 진행, NPC 처리, 판정 연계를 포함한다.
- UC-007은 답만 주는 흐름이 아니라 근거 위치와 후보 규칙 공개를 포함한다.
- UC-010은 SAVED 상태의 재개와 DELETED 상태의 제거를 분리해서 다룬다.
