# ADR-019: 서버가 먼저 수락한 요청은 전투 후속 처리까지 유지한다

## Status

Accepted

## Context

같은 Adventure Session에서 채팅·행동 요청과 전투 후속 처리가 겹치면, 게임 상태가 플레이어가 의도한 순서와 다르게 반영될 수 있다. 서버가 요청을 처음 받아들였을 때 기록한 진행 중 요청 ID를 중간에 지우면 다음 요청이 이전 요청의 최종 결과보다 먼저 수락될 수 있다.

전투는 서버가 이어서 처리하는 단계가 있을 수 있다. 이 단계가 별도 새 요청으로 취급되면, 같은 Adventure Session에서 처리 중 요청 하나만 허용하는 규칙을 지킬 수 없다.

## Decision

- Adventure Session에서 서버가 처음 조건부로 받아들인 채팅 또는 행동 요청이 진행 중 요청 ID를 가진다.
- 그 요청에서 시작된 전투 후속 처리는 같은 요청 ID를 유지한다. 별도 새 요청으로 수락하지 않는다.
- 같은 요청 ID가 유지되는 동안 새 채팅 또는 행동 요청은 거절하고 저장하거나 대기열에 넣지 않는다.
- 성공한 요청은 전투 후속 처리와 최종 게임 상태 처리가 끝난 뒤에만 같은 요청 ID를 지운다.
- 최종 결과 전 실행 실패, 시간 초과, 사용자 PC 에이전트 연결 끊김은 게임 상태를 바꾸지 않고 같은 요청 ID를 지운다.

## Consequences

- Solo Player가 먼저 요청한 순서가 Adventure Session 안에서 유지된다.
- 전투 후속 처리 중에는 새 채팅 또는 행동 요청이 거절된다.
- 결과 반영 도중 오류의 저장 상태 보존 정책은 ADR-020에서 결정한다.
