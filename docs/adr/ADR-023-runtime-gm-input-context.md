# ADR-023: GM 턴 입력 컨텍스트 구성

## Status

Accepted

## Context

현재 GM 입력 컨텍스트는 모험과 지도 자료, 대화 이력, 근거 자료 등을 넓게 포함하는 구조다. 모험 진행은 필수 상황과 필수 상황 사이에서 선택되는 중간 상황 후보를 중심으로 이루어지므로, GM에게는 현재 장면과 필요한 진행 상태를 전달하면서도 모험 자료 전체를 매번 넣지 않아야 한다.

모험 시작 직후의 첫 GM 요청은 플레이어 입력과 이전 대화가 없다. 첫 요청만 별도 흐름이나 출력 계약으로 취급하지 않고, 빈 대화 이력을 포함한 같은 입력 컨텍스트 구조로 처리할 수 있다. GM은 대화 이력이 비어 있는 것을 보고 오프닝 서술을 판단한다.

대화 압축은 컨텍스트 전체를 요약하는 작업이 아니다. `GM Context Compaction`은 이미 정해진 범위대로 오래된 대화 기록만 줄이고, 최근 대화는 원문으로 유지한다. 최신 시츄에이션, 모험 진행 상태, 확정된 플레이 사실, 캐릭터 정보, 이번 턴 근거는 대화 요약으로 대체하지 않는다.

## Decision

- 모험 시작 직후와 이후 턴은 같은 GM 입력 컨텍스트 구조를 사용한다. 첫 요청은 이전 대화와 플레이어 입력이 비어 있다. GM은 빈 대화 이력을 오프닝 판단에 사용한다.
- 플레이어 입력이 있는 턴은 입력을 받은 뒤 컨텍스트를 만들기 전에 오래된 대화 기록을 압축할 필요가 있는지 확인한다. 한도를 넘으면 오래된 대화만 압축하고 최근 대화는 원문으로 둔다. 다른 컨텍스트 자료는 이 압축에 포함하지 않는다.
- GM 입력 컨텍스트에는 다음 자료를 넣는다.
  - 현재 시츄에이션의 내용
  - 필수 시츄에이션 목록과 각 진행 상태
  - 이미 선택된 중간 상황 후보 중 현재 상황과 관련된 내용
  - 이전 턴에서 확정된 플레이 사실
  - 압축된 오래된 대화와 압축하지 않은 최근 대화
  - 캐릭터 개요
  - 이번 플레이어 입력. 오프닝 요청에서는 비어 있음
  - 이번 상황과 입력에 필요한 모험 자료 및 룰북 근거
- 일반 턴의 룰북·모험 근거는 기존 RAG로 조회한다. 독립된 각 자료 검색 요청은 최대 40개 후보를 반환한다. 검색 결과를 모은 뒤 리랭커가 관련도 순으로 최대 20개를 충분성 판단 단계에 전달한다. 점수 하한으로 후보를 미리 버리지 않는다.
- 충분성 판단 단계는 선택된 작업에 필요한 사실과 조건을 뒷받침하는 근거만 고르고, 결론에 영향을 줄 미해결 누락이나 충돌이 있으면 그 상태를 표시한다. GM 입력에는 선택된 근거만 넣는다. 20개는 리랭킹 결과 상한이며 GM 입력 근거 개수가 아니다.
- 기본 룰북과 추가 룰북 자료는 각각 검색한다. 한 자료의 결과로 다른 자료의 검색어를 만들거나 검색 범위를 좁히지 않는다. 관련 없는 RAG 결과나 모험 자료 전체를 무조건 포함하지 않는다.
- 리랭커와 충분성 판단 단계는 별도 리랭커 제품을 전제하지 않는다. AI Game Master의 현재 설정 모델을 사용한다.
- GM이 컨텍스트에 없는 자료를 직접 추가 조회할 수 있는 도구는 별도 후속 작업으로 둔다. 이번 결정에는 도구의 동작이나 인터페이스를 포함하지 않는다.
- 고정 지침과 출력 응답 계약은 위 게임 진행 자료와 별도로 전달한다.

## Consequences

- 오프닝과 일반 턴이 같은 입력 구조를 사용하므로, 오프닝 여부를 판별하기 위한 별도 입력·출력 계약 분기를 없애는 방향으로 구현해야 한다.
- GM 입력에는 현재 장면과 진행에 필요한 자료만 전달하고, 오래된 대화는 요약으로, 최근 대화는 원문으로 이어간다.
- 일반 턴은 각 독립 RAG 검색에서 최대 40개 후보를 모으고, 리랭킹 결과를 최대 20개로 제한한 뒤 충분성 판단에서 선택된 근거만 GM에게 전달한다. 다른 작업 종류의 기존 근거 획득 한도는 이 결정으로 바꾸지 않는다. 이 흐름의 정답률과 전체 응답 시간을 Golden 정답 테스트로 비교해야 한다.
- 컨텍스트에 없는 자료를 추가로 읽는 기능은 이 결정의 구현 범위가 아니며, 후속 결정과 작업이 필요하다.
