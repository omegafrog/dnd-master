# ADR-020: 결과 반영 도중 오류가 나도 이미 저장된 상태를 되돌리지 않는다

## Status

Accepted

## Context

AI 실행의 최종 결과를 Adventure Runtime에 반영할 때 맵·전투·이벤트 같은 여러 저장 작업이 이어질 수 있다. 일부 저장 뒤 오류가 나면 전체 결과를 되돌리는 방법은 복잡하고, Solo Player에게 이미 끝난 것으로 보인 모험 결과를 과거 상태로 되돌릴 수 있다.

## Decision

- 최종 결과를 받기 전 실행 실패, 시간 초과, 사용자 PC 에이전트 연결 끊김은 게임 상태를 바꾸지 않는다.
- 최종 결과 반영 도중 오류가 나면 이미 저장된 게임 상태를 되돌리거나 보상 작업을 실행하지 않는다.
- 서버는 오류를 기록하고 Solo Player에게 오류를 반환한다.
- 오류가 확정되면 같은 요청 ID를 조건부로 해제한다. 자동 재시도하지 않는다.

## Consequences

- 결과 반영 오류 뒤 일부 게임 상태가 저장된 채 남을 수 있다.
- 운영자는 오류 기록으로 복구 판단을 한다.
- 구현은 전체 되돌림을 위한 새 경계나 보상 작업을 만들지 않는다.
